# UI Design System Overview

Welcome to the **Innostes UI Design System**. The `@innostes/ui` package provides a modern, accessible, and themeable set of React UI components designed specifically for the Innostes ERP platform. Built on top of **Base UI primitives**, **Tailwind CSS v4**, **Class Variance Authority (CVA)**, and **Lucide React icons**.

---

## Installation & Setup

All UI components are distributed via the `@innostes/ui` workspace package.

<Tabs items={['pnpm', 'npm', 'yarn']}>
  <Tab value="pnpm">
```bash
pnpm add @innostes/ui
```
  </Tab>
  <Tab value="npm">
```bash
npm install @innostes/ui
```
  </Tab>
  <Tab value="yarn">
```bash
yarn add @innostes/ui
```
  </Tab>
</Tabs>

### Styling Setup

Import `@innostes/ui/styles.css` in your entry file (e.g. `src/main.tsx` or `src/app/layout.tsx`):

```tsx
import "@innostes/ui/styles.css";
```

<Callout type="info">
  Components support dark mode and custom color palette variables via Tailwind CSS configuration tokens defined in `@innostes/ui/preset`.
</Callout>

## Component Catalog

### Action Components

| Component | Description | Primitives / Specs |
| :--- | :--- | :--- |
| **[Button](/docs/button)** | Primary action trigger with multiple variants, sizes, icon slots, and loading states. | Base UI Button, CVA |

## Key Design System Principles

1. **Accessibility First**: Built using Base UI primitives to guarantee WAI-ARIA compliance, focus trapping, keyboard navigation, and screen reader announcements.
2. **Integrated Form Validation**: Form controls seamlessly bind to `<Field />` to display consistent labels, helper text, and error messages without extra boilerplate.
3. **TypeScript Safety**: Fully typed props with explicit TS exports for all component variant types.
