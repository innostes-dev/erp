# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within the Innostes repository (including applications, server APIs, and packages), please report it responsibly by contacting:

**security@innostes.com**

Please do NOT create public GitHub issues for security vulnerabilities.

### Response SLAs

- Initial response within 24 hours.
- Vulnerability assessment within 72 hours.
- Coordinated patch release within 7 business days.
