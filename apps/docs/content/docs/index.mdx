Welcome to the official developer and architecture documentation for **Innostes ERP**—a modular, open-source enterprise resource planning ecosystem built as a TypeScript monorepo using `pnpm` workspaces, Hono, React 19, and Drizzle ORM.

<Callout type="info" title="Modular Core Philosophy">
  Innostes ERP is designed with strict **Inversion of Control (IoC)** and **Loose Coupling**. Host applications are thin runtime shells that hardcode no business logic. Feature slices, database schemas, API routes, and frontend views are co-located in pluggable modules managed by the **Innostes Plug & Play Engine**.
</Callout>

---

## High-Level System Architecture

The host runtime shell (`apps/api-server`) boots up, creates a shared infrastructure context (`ModuleContext`), and delegates all domain registration to the **Innostes Engine**. The engine dynamically mounts routes, executes boot-time lifecycle hooks, and seeds initial data across mandatory platform slices (`kernel/*`) and optional business domains (`modules/*`).

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        HOST RUNTIME SHELLS                             │
│     [ apps/api-server (Hono Backend) ]     [ apps/web (React 19 Frontend) ]│
└───────────────────┬──────────────────────────────────┬─────────────────┘
                    │                                  │
┌───────────────────▼──────────────────────────────────▼─────────────────┐
│                 INNOSTES ENGINE (Runtime Orchestrator)                 │
│      Context Creation ➔ Dynamic Module Mount ➔ Boot & Seed Hooks       │
└──────────┬─────────────────────────┬─────────────────────────┬─────────┘
           │                         │                         │
┌──────────▼──────────┐   ┌──────────▼──────────┐   ┌──────────▼──────────┐
│    Kernel: Auth     │   │     Module: HRMS    │   │    Module: Inventory│
│  (Backend+Frontend) │   │  (Backend+Frontend) │   │  (Backend+Frontend) │
└─────────────────────┘   └─────────────────────┘   └─────────────────────┘
```

## Key Platform Characteristics

1. **Zero-Coupling Plug & Play:** Business modules (HRMS, Invoicing, Inventory, CRM) are vertical slices. Enabling or disabling a module is as simple as adding or removing it from the Innostes Engine registry array.
2. **Context Injection:** Global resources like `node-postgres` connection pools, Drizzle ORM database instances, loggers, and event buses are injected dynamically into modules via `ModuleContext`.
3. **Co-located Vertical Slices:** Each module owns its database tables, DTO validations, repositories, backend Hono controllers, and frontend UI components.
4. **Unified Database Layer:** Centralized `node-postgres` (`pg.Pool`) factory with Drizzle ORM, aggregating domain schemas without tight monolithic dependencies.

## Technology Stack Matrix

| Layer | Technology | Description |
| :--- | :--- | :--- |
| **Monorepo Manager** | `pnpm` + Turborepo | High-performance workspace orchestration and build caching |
| **Backend Framework** | Hono | Ultra-fast TypeScript web framework with OpenAPI / RPC capabilities |
| **Frontend Framework** | React 19 + Vite | Modern UI framework with co-located module views |
| **Database & ORM** | PostgreSQL + Drizzle ORM | Type-safe SQL ORM connected via `node-postgres` (`pg.Pool`) |
| **Design System** | `@innostes/ui` + Tailwind | Shared accessible design tokens and component library |
| **Documentation** | Fumadocs + MDX | Fast, type-safe MDX documentation engine |
