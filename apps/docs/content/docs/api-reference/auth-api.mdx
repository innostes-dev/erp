The Authentication Kernel Service (`/api/auth`) manages user accounts, password security, and JSON Web Token (JWT) session issuance.

---

## Endpoint Summary

| Method | Endpoint | Auth Required | Description |
| :--- | :--- | :---: | :--- |
| `POST` | `/api/auth/register` | No | Register a new user account |
| `POST` | `/api/auth/login` | No | Authenticate credentials and receive Bearer JWT |
| `GET` | `/api/auth/me` | **Yes** | Fetch current authenticated user profile |
| `POST` | `/api/auth/logout` | **Yes** | Terminate active user session |

---

## 1. User Login (`POST /api/auth/login`)

Exchanges user credentials for a signed JWT access token.

### Request Body Schema
| Field | Type | Required | Constraints |
| :--- | :--- | :---: | :--- |
| `email` | `string` | **Yes** | Valid email format |
| `password` | `string` | **Yes** | `min: 6` characters |

### Request Code Example
<Tabs items={['cURL', 'TypeScript (Fetch)']}>
  <Tab value="cURL">
    ```bash
    curl -X POST http://localhost:3000/api/auth/login \
      -H "Content-Type: application/json" \
      -d '{
        "email": "admin@innostes.com",
        "password": "Admin123!"
      }'
    ```
  </Tab>
  <Tab value="TypeScript (Fetch)">
    ```typescript
    const response = await fetch('http://localhost:3000/api/auth/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        email: 'admin@innostes.com',
        password: 'Admin123!',
      }),
    });
    const result = await response.json();
    console.log('JWT Token:', result.data.token);
    ```
  </Tab>
</Tabs>

## 2. Get User Profile (`GET /api/auth/me`)

Retrieves profile data for the authenticated Bearer token.

```bash
curl -X GET http://localhost:3000/api/auth/me \
  -H "Authorization: Bearer <jwt_access_token>"
```
