The workflow is in `.github/workflows/ci.yml`. It runs on pushes to `main` and on every pull
request.

## What it checks

```bash
pnpm nx format:check --base="remotes/origin/main"
pnpm nx run-many -t lint test contract-test build typecheck e2e docs-check docs-e2e verify-checklist openapi-check openapi-lint arch-docs-check
pnpm run arch-check
```

Nx distributes and parallelises tasks across GitHub Actions workers with pnpm caching and task caching enabled.

## Environment & setup

The CI workflow uses:
- **Package manager**: `pnpm/action-setup@v4` with `pnpm install --frozen-lockfile`
- **Node runtime**: Node.js 24 with pnpm caching (`cache: 'pnpm'`)
- **Python runtime**: Python 3.11/3.12 with `pnpm nx run api-server:install` for backend virtual environment setup
- **Browser automation**: Chromium installed via `pnpm exec playwright install --with-deps chromium` for e2e and visual regression testing
- **Architecture fitness**: `pnpm run arch-check` enforcing all 6 architectural fitness functions and import rules

## Run the same checks locally

```bash
pnpm nx format:check
pnpm nx run-many -t build typecheck
```

Fix formatting with `pnpm nx format:write`.
