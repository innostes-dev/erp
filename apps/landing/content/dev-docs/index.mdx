innostes is built as a single **Nx monorepo** managed with **pnpm**. All apps and shared packages
live in one repository, share one lockfile, and are built and tested with the same commands.

## What's in the repo

<Cards>
  <Card icon={<Rocket />} title="landing" href="/docs/apps/landing">
    Public website and documentation (this site). Next.js + Fumadocs.
  </Card>
  <Card icon={<Boxes />} title="web-app" href="/docs/apps/web-app">
    The UI engine. React + Vite. Renders the pages that frontend plug-ins provide.
  </Card>
  <Card icon={<Server />} title="api-server" href="/docs/apps/api-server">
    The backend engine. Python + FastAPI. Loads backend plug-ins.
  </Card>
  <Card icon={<Cpu />} title="kernel" href="/docs/architecture/kernel">
    The shared foundation plug-in: database, security, base classes, tenancy.
  </Card>
  <Card icon={<Layers />} title="@innostes/ui" href="/docs/packages/ui">
    The design system. React components on Base UI and Tailwind CSS, published to npm.
  </Card>
</Cards>

## Tech stack

| Area | Tools |
| --- | --- |
| Monorepo | Nx 23, pnpm workspaces |
| Language | TypeScript 6, Python 3.12+ |
| Front end | React 19, Vite 8, Next.js 16 |
| Styling | Tailwind CSS v4, `@innostes/ui` |
| Docs | Fumadocs (MDX) |
| Backend | FastAPI |
