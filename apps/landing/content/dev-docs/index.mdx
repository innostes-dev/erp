innostes is built as a single **Nx monorepo** managed with **pnpm**. All apps, domain business modules, extensible plugins, and shared libraries live in one repository, share one lockfile, and are built and tested with uniform commands.

## Tech Stack

| Area | Tools & Versions |
| --- | --- |
| Monorepo | Nx 23, pnpm workspaces |
| Languages | TypeScript 6, Python 3.12+ |
| Front End | React 19, Vite 8, Next.js 16 |
| Styling | Tailwind CSS v4, `@innostes/ui` |
| Documentation | Fumadocs (MDX) |
| Backend | FastAPI, SQLAlchemy 2 (async), Pydantic v2, Alembic |
| Database | PostgreSQL 16+ |
