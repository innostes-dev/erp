## Setup

The API uses its own Python virtual environment in `apps/api-server/.venv`.

```bash
pnpm nx run api-server:install   # create .venv and install requirements.txt
pnpm nx serve api-server         # http://localhost:8000
```

FastAPI serves interactive API docs at http://localhost:8000/docs.

<Callout type="warn" title="Windows paths">
  The Nx tasks in `apps/api-server/project.json` call `.venv/Scripts/python`, which is the Windows
  layout. On macOS and Linux the path is `.venv/bin/python`. Update `project.json` before running it there.
</Callout>

## Adding a Python package

Add it to `requirements.txt` (and `pyproject.toml`), then reinstall:

```bash
pnpm nx run api-server:install
```

## Adding an endpoint

```py title="app/main.py"
@app.get("/items/{item_id}")
def read_item(item_id: int) -> dict[str, int]:
    return {"item_id": item_id}
```

The dev server reloads on save.
