<ApiEndpoint method="POST" path="/users" auth="BearerAuth" />

Registers a new user identity with envelope-encrypted PII.

Requires Bearer authentication. Encrypts sensitive fields (email, mobile)
and generates blind search indexes.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Request body

Payload model: [UserCreate](/api-reference/schemas/user-create)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `first_name` | string | Yes | User given name. |
| `last_name` | string \| null | No | User family name. |
| `email` | string | Yes | Primary user account email address. |
| `password` | string | Yes | Initial account password. |
| `mobile` | string \| null | No | User mobile telephone number. |
| `is_super_admin` | boolean | No | Flag granting platform-wide super administrator privileges. |

### Request example

```json
{
  "first_name": "Arjun",
  "last_name": "Mehta",
  "email": "arjun.mehta@northwind.example",
  "password": "UserSecurePassword2026!",
  "mobile": "+919876543211",
  "is_super_admin": false
}
```

```json
  "email": "priya.shah@northwind.example",

  "id": "3f2b1c9e-5d8a-4f6b-9c2e-1a3b5c7d9e0f",
  "is_super_admin": true,
  "last_name": "Shah",
  "mobile": "+919876543210",
  "status": "active",
  "token_version": 1,
  "updated_at": "2026-10-29T10:00:00Z"
}
```

### HTTP 401

Not authenticated

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 409

Conflict with existing data

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 422

Validation Error

Response model: [HTTPValidationError](/api-reference/schemas/httpvalidation-error)

```json
{
  "detail": [
    null
  ]
}
```
