<ApiEndpoint method="GET" path="/tenants/current/modules" auth="BearerAuth" />

Return catalog of business modules and their activation status.

Requires Bearer authentication. Returns which packages are enabled for the
current tenant organization context.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Header parameters

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `X-Tenant-ID` | string \| null | No | Active tenant UUID context. |

## Responses

### HTTP 200

Successful Response

Response model: [ModuleListResponse](/api-reference/schemas/module-list-response)

```json
{
  "active_ids": [
    "hrms"
  ],
  "installed": [
    {
      "activated_at": "2026-10-29T10:00:00Z",
      "description": "People and human resources management",
      "id": "hrms",
      "is_active": true,
      "name": "HRMS",
      "tags": [
        "Employees",
        "Leave",
        "Payroll"
      ],
      "tone": "chart-3",
      "type": "module",
      "version": "0.1.0"
    }
  ]
}
```

### HTTP 401

Not authenticated

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

Resource not found

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```

}
```
