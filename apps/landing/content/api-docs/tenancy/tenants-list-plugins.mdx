<ApiEndpoint method="GET" path="/tenants/current/plugins" auth="BearerAuth" />

Return catalog of extensible plugins and their activation status.

Requires Bearer authentication. Returns which plugins are enabled for the
current tenant organisation context.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Header parameters

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `X-Tenant-ID` | string \| null | No | Active tenant UUID context. |

## Responses

### HTTP 200

Successful Response

Response model: [PluginListResponse](/api-reference/schemas/plugin-list-response)

```json
{
  "active_ids": [
    "api-logger"
  ],
  "installed": [
    {
      "activated_at": "2026-10-29T10:00:00Z",
      "description": "API request logging, webhook inspection, and debugging",
      "id": "api-logger",
      "is_active": true,
      "name": "API Logger",
      "tags": [
        "Logs",
        "Webhooks",
        "Analytics"
      ],
      "tone": "chart-5",
      "type": "plugin",
      "version": "0.1.0"
    }
  ]
}
```

Not authenticated

Response model: [ErrorResponse](/api-reference/schemas/error-response)
