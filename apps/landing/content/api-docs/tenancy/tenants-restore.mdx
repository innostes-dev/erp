<ApiEndpoint method="POST" path="/tenants/{tenant_id}/restore" auth="BearerAuth" />

Bring back a soft-deleted tenant organisation.

Requires Bearer authentication. Clears `deleted_at` and `deleted_by`.
Calling on an active tenant is harmless and idempotent.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `tenant_id` | string | Yes | Unique identifier of the tenant organisation. |
