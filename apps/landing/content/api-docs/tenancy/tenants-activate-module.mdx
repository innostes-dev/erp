<ApiEndpoint method="POST" path="/tenants/current/modules/{module_id}/activate" auth="BearerAuth" />

Activate a business module for the current tenant.

Requires Super Administrator privilege. Enables the module's feature set
and navigation for the organization.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `module_id` | string | Yes | Package identifier of business module to activate. |

### Header parameters

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `X-Tenant-ID` | string \| null | No | Active tenant UUID context. |

## Responses

### HTTP 200

Successful Response

Response model: [ActivationResponse](/api-reference/schemas/activation-response)

```json
{
  "is_active": true,
  "item_id": "hrms",
  "message": "Module 'hrms' activated successfully."
}
```

### HTTP 401

Not authenticated

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 403

Not allowed

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 404

Resource not found

Response model: [ErrorResponse](/api-reference/schemas/error-response)

}
```

Validation Error

```
