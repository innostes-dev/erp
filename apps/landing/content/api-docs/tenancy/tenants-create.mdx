<ApiEndpoint method="POST" path="/tenants" auth="BearerAuth" />

Create a new tenant (customer organisation).

Requires Bearer authentication. If a valid bearer token is sent, its user is
recorded in `created_by` and `updated_by`. Returns **409** if the slug is already taken.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Request body

Payload model: [TenantCreate](/api-reference/schemas/tenant-create)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Display name of the organisation. |
| `slug` | string | Yes | Short unique identifier used in URLs: lowercase letters, digits, and hyphens (e.g. `northwind-traders`). |
| `country` | string \| null | No | ISO 3166-1 alpha-2 country code. |
| `timezone` | string \| null | No | IANA time zone name. |
| `language` | string \| null | No | BCP 47 language tag for default language. |
| `date_format` | string \| null | No | Preferred date display format. |

### Request example

```json
{
  "country": "IN",
  "date_format": "DD/MM/YYYY",
  "language": "en-IN",
  "name": "Northwind Traders Pvt Ltd",
  "slug": "northwind-traders",
  "timezone": "Asia/Kolkata"
}
```

```json
  "date_format": "DD/MM/YYYY",

  "language": "en-IN",
  "name": "Northwind Traders Pvt Ltd",
  "slug": "northwind-traders",
  "timezone": "Asia/Kolkata",
  "updated_at": "2026-10-26T10:15:00Z",
  "updated_by": "9b2e4c71-0a3d-4f5e-8b6c-1d2e3f4a5b6c"
}
```

### HTTP 401

Not authenticated

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 409

Conflict with existing data

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 422

Validation Error

Response model: [HTTPValidationError](/api-reference/schemas/httpvalidation-error)

```json
{
  "detail": [
    null
  ]
}
```
