<ApiEndpoint method="POST" path="/auth/logout" auth="BearerAuth" />

Revokes active refresh tokens and clears authentication cookies.

Requires Bearer authentication. Optionally revokes all active sessions
across all client devices when logout_all is true.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Request body

Payload model: [LogoutRequest](/api-reference/schemas/logout-request)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `refresh_token` | string \| null | No | Specific session refresh token to revoke. When omitted, active cookie is revoked. |
| `logout_all` | boolean | No | Whether to revoke all active sessions across all client devices. |

### Request example

```json
{
  "refresh_token": "rt_8f1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d",
  "logout_all": false
}
```

## Code samples

<Tabs items={["cURL", "TypeScript (fetch)", "Python (httpx)"]}>
  <Tab value="cURL">

```bash
curl -X POST "http://localhost:8001/auth/logout" \
  -H "Authorization: Bearer <your-access-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "refresh_token": "rt_8f1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d",
    "logout_all": false
  }'
```

  </Tab>
  <Tab value="TypeScript (fetch)">

```ts
const response = await fetch('http://localhost:8001/auth/logout', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer <your-access-token>',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    "refresh_token": "rt_8f1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d",
    "logout_all": false
  }),
});

const data = await response.json();
console.log(data);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

headers = {
    "Authorization": "Bearer <your-access-token>",
    "Content-Type": "application/json",
}

response = httpx.post(
    "http://localhost:8001/auth/logout",
    headers=headers,
    json={
      "refresh_token": "rt_8f1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d",
      "logout_all": false
    },
)

data = response.json()
print(data)
```
