<ApiEndpoint method="GET" path="/auth/api-keys" auth="BearerAuth" />

Lists programmatic API keys registered for the current organisation.

Requires Bearer authentication. Omits secret hashes and reveals key
metadata and permission scopes.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Responses

### HTTP 200

Successful Response

Response model: [ApiKeyListResponse](/api-reference/schemas/api-key-list-response)

```json
{
  "items": [
    {
      "created_at": "2026-10-29T09:00:00Z",
      "expires_at": "2026-11-28T10:00:00Z",
      "id": "3f2b1c9e-5d8a-4f6b-9c2e-1a3b5c7d9e0f",
      "is_revoked": false,
      "key_prefix": "inno_live_xK9p",
      "last_used_at": "2026-10-29T10:15:00Z",
      "name": "Zapier CRM Sync",
      "scopes": [
        "crm:read",
        "hrms:read"
      ]
    }
  ]
}
```

### HTTP 401

Not authenticated

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

## Code samples

<Tabs items={["cURL", "TypeScript (fetch)", "Python (httpx)"]}>
  <Tab value="cURL">

```bash
curl -X GET "http://localhost:8001/auth/api-keys" \
  -H "Authorization: Bearer <your-access-token>"
```

  </Tab>
  <Tab value="TypeScript (fetch)">

```ts
const response = await fetch('http://localhost:8001/auth/api-keys', {
  method: 'GET',
  headers: {
    Authorization: 'Bearer <your-access-token>',
  },
});

const data = await response.json();
console.log(data);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

headers = {
    "Authorization": "Bearer <your-access-token>",
}

response = httpx.get(
    "http://localhost:8001/auth/api-keys",
    headers=headers,
)

data = response.json()
print(data)
```
