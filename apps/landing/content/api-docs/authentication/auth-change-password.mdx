<ApiEndpoint method="POST" path="/auth/change-password" auth="BearerAuth" />

Updates password for the currently authenticated user.

Requires Bearer authentication. Verifies existing credentials before
applying the update and rotating active sessions.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Request body

Payload model: [ChangePasswordRequest](/api-reference/schemas/change-password-request)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `current_password` | string | Yes | Current active password or temporary one-time password. |
| `new_password` | string | Yes | New strong account password complying with complexity rules. |

### Request example

```json
{
  "current_password": "NorthwindPass2026!",
  "new_password": "NewPermanentPassword2026!"
}
```

## Responses

### HTTP 200

Successful Response

Response model: [MessageResponse](/api-reference/schemas/message-response)

```json
{
  "message": "Operation completed successfully."
}
```

### HTTP 401

Not authenticated

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 409

Conflict with existing data

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 422

Validation Error

Response model: [HTTPValidationError](/api-reference/schemas/httpvalidation-error)

```json
{
  "detail": [
    null
  ]
}
```

## Code samples

<Tabs items={["cURL", "TypeScript (fetch)", "Python (httpx)"]}>
  <Tab value="cURL">

```bash
curl -X POST "http://localhost:8001/auth/change-password" \
  -H "Authorization: Bearer <your-access-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "current_password": "NorthwindPass2026!",
    "new_password": "NewPermanentPassword2026!"
  }'
```

  </Tab>
  <Tab value="TypeScript (fetch)">

```ts
const response = await fetch('http://localhost:8001/auth/change-password', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer <your-access-token>',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    "current_password": "NorthwindPass2026!",
    "new_password": "NewPermanentPassword2026!"
  }),
});

const data = await response.json();
console.log(data);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

headers = {
    "Authorization": "Bearer <your-access-token>",
    "Content-Type": "application/json",
}

response = httpx.post(
    "http://localhost:8001/auth/change-password",
    headers=headers,
    json={
      "current_password": "NorthwindPass2026!",
      "new_password": "NewPermanentPassword2026!"
    },
)

data = response.json()
print(data)
```
