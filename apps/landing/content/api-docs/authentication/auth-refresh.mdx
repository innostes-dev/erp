<ApiEndpoint method="POST" path="/auth/refresh" auth="None" />

Rotates a single-use refresh token and issues fresh access credentials.

Public endpoint. Detects reuse attempts, invalidating compromised session
families if reuse occurs.

## Authentication

This endpoint is public and does not require an authentication header.

## Request body

Payload model: [RefreshTokenRequest](/api-reference/schemas/refresh-token-request)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `refresh_token` | string | Yes | Active single-use rotating refresh token. |

### Request example

```json
{
  "refresh_token": "rt_8f1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d"
}
```

const response = await fetch('http://localhost:8001/auth/refresh', {
