<ApiEndpoint method="POST" path="/auth/forgot-password" auth="None" />

Dispatches password reset instructions with anti-enumeration protection.

Public endpoint. Always returns a 200 confirmation notice regardless of
whether the email is registered in the system.

## Authentication

This endpoint is public and does not require an authentication header.

## Request body

Payload model: [ForgotPasswordRequest](/api-reference/schemas/forgot-password-request)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `email` | string | Yes | Registered user account email address. |

### Request example

```json
{
  "email": "priya.shah@northwind.example"
}
```

## Responses

### HTTP 200

Successful Response

Response model: [ForgotPasswordResponse](/api-reference/schemas/forgot-password-response)

```json
{
  "message": "If an account exists with that email address, a password reset link and temporary password have been sent."
}
```

### HTTP 422

Validation Error

Response model: [HTTPValidationError](/api-reference/schemas/httpvalidation-error)

```json
{
  "detail": [
    null
  ]
}
```

## Code samples

<Tabs items={["cURL", "TypeScript (fetch)", "Python (httpx)"]}>
  <Tab value="cURL">

```bash
curl -X POST "http://localhost:8001/auth/forgot-password" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "priya.shah@northwind.example"
  }'
```

  </Tab>
  <Tab value="TypeScript (fetch)">

```ts
const response = await fetch('http://localhost:8001/auth/forgot-password', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    "email": "priya.shah@northwind.example"
  }),
});

const data = await response.json();
console.log(data);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

headers = {
    "Content-Type": "application/json",
}

response = httpx.post(
    "http://localhost:8001/auth/forgot-password",
    headers=headers,
    json={
      "email": "priya.shah@northwind.example"
    },
)

data = response.json()
print(data)
```
