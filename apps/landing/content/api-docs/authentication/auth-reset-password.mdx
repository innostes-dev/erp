<ApiEndpoint method="POST" path="/auth/reset-password" auth="None" />

Resets account credentials using a single-use signed reset token.

Public endpoint. Enforces SOC 2 historical password reuse prevention and
revokes all active sessions upon successful reset.

## Authentication

This endpoint is public and does not require an authentication header.

## Request body

Payload model: [ResetPasswordRequest](/api-reference/schemas/reset-password-request)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `token` | string | Yes | Cryptographically signed single-use reset token delivered via email. |
| `new_password` | string | Yes | New strong account password complying with complexity rules. |

### Request example

```json
{
  "token": "rst_4f8e2a1b9c3d7e5f6a0b8c2d4e6f1a3b",
  "new_password": "NewPermanentPassword2026!"
}
```

## Responses

### HTTP 200

Successful Response

Response model: [MessageResponse](/api-reference/schemas/message-response)

```json
{
  "message": "Operation completed successfully."
}
```

Not authenticated

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

```

const response = await fetch('http://localhost:8001/auth/reset-password', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    "token": "rst_4f8e2a1b9c3d7e5f6a0b8c2d4e6f1a3b",
    "new_password": "NewPermanentPassword2026!"
  }),

```
