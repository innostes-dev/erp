<ApiEndpoint method="POST" path="/auth/login" auth="None" />

Authenticates credentials and issues short-lived JWT and refresh tokens.

Public endpoint. Sets secure HttpOnly cookies for web browsers and returns
bearer credentials for programmatic API callers.

## Authentication

This endpoint is public and does not require an authentication header.

## Request body

Payload model: [LoginRequest](/api-reference/schemas/login-request)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `email` | string | Yes | Registered user account email address. |
| `password` | string | Yes | Account authentication password. |
| `device_fingerprint` | string | No | Unique hardware or browser fingerprint for Zero-Trust verification. |
| `device_name` | string \| null | No | Optional human-readable client device label. |
| `device_type` | [DeviceType](/api-reference/schemas/device-type) | No | Form-factor classification of client hardware. |

### Request example

```json
{
  "email": "priya.shah@northwind.example",
  "password": "NorthwindPass2026!",
  "device_fingerprint": "fp_7a9f1c3e8b2d4a6e",
  "device_name": "Bengaluru Office MacBook Pro",
  "device_type": "desktop"
}
```

### HTTP 401

Not authenticated

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 403

Not allowed

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 422

Validation Error

Response model: [HTTPValidationError](/api-reference/schemas/httpvalidation-error)

```json
{
  "detail": [
    null
  ]
}
```
