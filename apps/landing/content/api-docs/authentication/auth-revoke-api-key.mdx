<ApiEndpoint method="DELETE" path="/auth/api-keys/{key_id}" auth="BearerAuth" />

Permanently revokes an API key.

Requires Bearer authentication. Revocation takes effect immediately, blocking
all subsequent calls made with this key.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `key_id` | string | Yes | Unique identifier of the API key to revoke. |

  <Tab value="cURL">

```bash
curl -X DELETE "http://localhost:8001/auth/api-keys/{key_id}" \
```

  <Tab value="TypeScript (fetch)">

```ts
const response = await fetch('http://localhost:8001/auth/api-keys/{key_id}', {
  method: 'DELETE',
  headers: {
    Authorization: 'Bearer <your-access-token>',
  },
});

const data = await response.json();
console.log(data);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

headers = {

}

response = httpx.delete(

    headers=headers,
)

data = response.json()
print(data)
```
