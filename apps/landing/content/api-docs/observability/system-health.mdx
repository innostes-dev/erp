<ApiEndpoint method="GET" path="/health" auth="None" />

Report API, database, and per-module health.

Public endpoint. Returns **200** with `status: pass` when the database responds,
otherwise **503** with `status: fail`.

## Authentication

This endpoint is public and does not require an authentication header.

## Responses

### HTTP 200

Successful Response

Response model: [HealthCheckRead](/api-reference/schemas/health-check-read)

```json
{
  "database": {
    "latency_ms": 1.25,
    "status": "HEALTHY"
  },
  "environment": "development",
  "modules": {
    "auth": {
      "status": "HEALTHY"
    },
    "tenancy": {
      "status": "HEALTHY"
    }
  },
  "status": "pass"
}
```

### HTTP 503

Database is unreachable
