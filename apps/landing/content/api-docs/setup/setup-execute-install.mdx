<ApiEndpoint method="POST" path="/setup" auth="BearerAuth" />

Install the system: create the database tables and the first organisation.

Requires the `X-Setup-Token` header. Works **only once**: afterwards this
route returns **404**, as if it never existed.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Header parameters

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `X-Setup-Token` | string \| null | No | One-time system installation token printed in server log or set via SETUP_TOKEN. |

## Request body

Payload model: [SetupRequest](/api-reference/schemas/setup-request)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `organization` | [TenantCreate](/api-reference/schemas/tenant-create) | Yes | The primary root customer organisation (tenant) to provision. |
| `admin` | [AdminUserCreate](/api-reference/schemas/admin-user-create) | No | The root super administrator credentials. |
| `branding` | [SetupBrandingCreate](/api-reference/schemas/setup-branding-create) \| null | No | Optional branding customization. Set to null if skipped. |

### Request example

```json
{
  "admin": {
    "email": "priya.shah@northwind.example",
    "first_name": "Priya",

    "language": "en-IN",

    "slug": "northwind-traders",
    "timezone": "Asia/Kolkata"
  }
}
```

### HTTP 401

Not authenticated

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 404

Resource not found

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 409

Conflict with existing data

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 422

Validation Error

Response model: [HTTPValidationError](/api-reference/schemas/httpvalidation-error)

```json
{
  "detail": [
    null
  ]
}
```

### HTTP 429

Too many requests

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```

### HTTP 503

A required service (e.g. the database) is unavailable

Response model: [ErrorResponse](/api-reference/schemas/error-response)

```json
{
  "code": "tenant_not_found",
  "detail": "Tenant not found."
}
```
