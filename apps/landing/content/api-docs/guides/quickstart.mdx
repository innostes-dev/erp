This guide walks you through bootstrapping a local innostes ERP development environment, initialising the primary tenant, authenticating an administrative user, and making your first API calls.

## Prerequisites

Ensure you have the following installed locally:
- Python 3.11+
- Node.js 22+ and pnpm
- Access to a running PostgreSQL 16+ instance

Start the API server locally:

```bash
pnpm nx serve api-server
```

The server listens on `http://localhost:8001`. Interactive OpenAPI documentation is exposed at `http://localhost:8001/docs`.

## Step 3: Execute installation

Retrieve the single-use setup token printed in the server boot terminal, then submit the initial organization and root administrator details:

<Tabs items={["cURL", "TypeScript (fetch)", "Python (httpx)"]}>
  <Tab value="cURL">

```bash
curl -X POST "http://localhost:8001/setup/install" \
  -H "Content-Type: application/json" \
  -H "X-Setup-Token: test-setup-token-42" \
  -d '{
    "app_name": "Northwind Enterprise ERP",
    "admin_email": "priya.shah@northwind.example",
    "admin_password": "Password123!",
    "admin_first_name": "Priya",
    "admin_last_name": "Shah"
  }'
```

  </Tab>
  <Tab value="TypeScript (fetch)">

```ts
const res = await fetch('http://localhost:8001/setup/install', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Setup-Token': 'test-setup-token-42',
  },
  body: JSON.stringify({
    app_name: 'Northwind Enterprise ERP',
    admin_email: 'priya.shah@northwind.example',
    admin_password: 'Password123!',
    admin_first_name: 'Priya',
    admin_last_name: 'Shah',
  }),
});
const result = await res.json();
console.log(result);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

res = httpx.post(
    "http://localhost:8001/setup/install",
    headers={
        "Content-Type": "application/json",
        "X-Setup-Token": "test-setup-token-42",
    },
    json={
        "app_name": "Northwind Enterprise ERP",
        "admin_email": "priya.shah@northwind.example",
        "admin_password": "Password123!",
        "admin_first_name": "Priya",
        "admin_last_name": "Shah",
    },
)
print(res.json())
```

  </Tab>
</Tabs>

**Response (`201 Created`)**:

```json

  "success": true,
  "message": "System installed successfully"
}
```

## Step 4: Authenticate and obtain tokens

Log in with your administrator credentials using [Login](/api-reference/authentication/auth-login):

<Tabs items={["cURL", "TypeScript (fetch)", "Python (httpx)"]}>
  <Tab value="cURL">

```bash
curl -X POST "http://localhost:8001/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "priya.shah@northwind.example",
    "password": "Password123!"
  }'
```

  </Tab>
  <Tab value="TypeScript (fetch)">

```ts
const res = await fetch('http://localhost:8001/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    username: 'priya.shah@northwind.example',
    password: 'Password123!',
  }),
});
const auth = await res.json();
const token = auth.access_token;
console.log('Access token:', token);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

res = httpx.post(
    "http://localhost:8001/auth/login",
    headers={"Content-Type": "application/json"},
    json={
        "username": "priya.shah@northwind.example",
        "password": "Password123!",
    },
)
auth = res.json()
token = auth["access_token"]
print("Access token:", token)
```

  </Tab>
</Tabs>

**Response (`200 OK`)**:

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 1800
}
```

## Step 5: Query your profile

Pass the JWT in the `Authorization: Bearer <token>` header to call [Get Current User](/api-reference/authentication/auth-get-me):

<Tabs items={["cURL", "TypeScript (fetch)", "Python (httpx)"]}>
  <Tab value="cURL">

```bash
curl -X GET "http://localhost:8001/auth/me" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

  </Tab>
  <Tab value="TypeScript (fetch)">

```ts
const res = await fetch('http://localhost:8001/auth/me', {
  headers: {
    Authorization: `Bearer ${token}`,
  },
});
const profile = await res.json();
console.log(profile);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

res = httpx.get(
    "http://localhost:8001/auth/me",
    headers={"Authorization": f"Bearer {token}"},
)
print(res.json())
```

  </Tab>
</Tabs>

**Response (`200 OK`)**:

```json
{
  "id": 1,
  "email": "priya.shah@northwind.example",
  "first_name": "Priya",
  "last_name": "Shah",
  "is_active": true,
  "is_superuser": true,
  "created_at": "2026-10-29T10:00:00Z"
}
```

## Step 6: Create and list organisations

Create a distributor tenant for Northwind Traders using [Create Tenant](/api-reference/tenancy/tenants-create):

<Tabs items={["cURL", "TypeScript (fetch)", "Python (httpx)"]}>
  <Tab value="cURL">

```bash
curl -X POST "http://localhost:8001/tenants" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Northwind Traders Pvt Ltd",
    "slug": "northwind",
    "domain": "northwind.example.com",
    "is_active": true
  }'
```

  </Tab>
  <Tab value="TypeScript (fetch)">

```ts
const res = await fetch('http://localhost:8001/tenants', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${token}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'Northwind Traders Pvt Ltd',
    slug: 'northwind',
    domain: 'northwind.example.com',
    is_active: true,
  }),
});
const tenant = await res.json();
console.log('Created tenant ID:', tenant.id);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

res = httpx.post(
    "http://localhost:8001/tenants",
    headers={
        "Authorization": f"Bearer {token}",
        "Content-Type": "application/json",
    },
    json={
        "name": "Northwind Traders Pvt Ltd",
        "slug": "northwind",
        "domain": "northwind.example.com",
        "is_active": True,
    },
)
tenant = res.json()
print("Created tenant ID:", tenant["id"])
```

  </Tab>
</Tabs>

**Response (`201 Created`)**:

```json
{
  "id": 1,
  "name": "Northwind Traders Pvt Ltd",
  "slug": "northwind",
  "domain": "northwind.example.com",
  "is_active": true,
  "created_at": "2026-10-29T10:00:00Z",
  "updated_at": "2026-10-29T10:00:00Z"
}
```

```bash
curl -X GET "http://localhost:8001/tenants?skip=0&limit=10" \
```
