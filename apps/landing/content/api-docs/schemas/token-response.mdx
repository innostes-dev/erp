Successful authentication response containing JWT credentials and user identity.

## Properties

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `access_token` | string | Yes | — | Short-lived JWT bearer access token valid for 30 minutes. |
| `refresh_token` | string | Yes | — | Long-lived single-use rotating refresh token valid for 7 days. |
| `token_type` | string | No | `"bearer"` | HTTP authorization scheme type. |
| `expires_in` | integer | Yes | — | Access token lifespan in seconds (1800 seconds). |
| `must_change_password` | boolean | Yes | — | Flag indicating whether user must change temporary credentials before continuing. |
| `user` | [UserRead](/api-reference/schemas/user-read) | Yes | — | Authenticated user identity and profile summary. |
