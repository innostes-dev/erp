Complete alphabetical catalogue of all 41 data transfer objects, request models, and response envelopes used across the API endpoints.

| Schema | Type | Description |
| --- | --- | --- |
| [ActivationResponse](/api-reference/schemas/activation-response) | `object` | Response returned upon activation or deactivation. |
| [AdminUserCreate](/api-reference/schemas/admin-user-create) | `object` | Administrator credentials and profile collected during first-run setup. |
| [ApiKeyCreatedResponse](/api-reference/schemas/api-key-created-response) | `object` | Returned exclusively on key creation. The raw_key will never be shown again. |
| [ApiKeyListResponse](/api-reference/schemas/api-key-list-response) | `object` | List of all API keys for tenant. |
| [ApiKeyRead](/api-reference/schemas/api-key-read) | `object` | Safe public representation of an API key without secret hash. |
| [ApiLoggerInfoResponse](/api-reference/schemas/api-logger-info-response) | `object` | Information schema for API Logger plugin. |
| [AppConfigRead](/api-reference/schemas/app-config-read) | `object` | Public application metadata and frontend bootstrapping configuration. |
| [ChangePasswordRequest](/api-reference/schemas/change-password-request) | `object` | Authenticated request to update credentials (or complete first-login reset). |
| [CreateApiKeyRequest](/api-reference/schemas/create-api-key-request) | `object` | Payload to generate a new API key. |
| [CrmInfoResponse](/api-reference/schemas/crm-info-response) | `object` | Information schema for CRM scaffold module. |
| [DeviceType](/api-reference/schemas/device-type) | `string` | Classification of client devices. |
| [ErrorResponse](/api-reference/schemas/error-response) | `object` | Body returned for handled errors, e.g. a not-found or conflict error. Attributes:     detail: Human-readable error message.     code: Machine-readable error id, only for some errors (e.g. "setup_required"). |
| [ForgotPasswordRequest](/api-reference/schemas/forgot-password-request) | `object` | Initiates an anti-enumeration password reset and temporary password dispatch. |
| [ForgotPasswordResponse](/api-reference/schemas/forgot-password-response) | `object` | Generic status response guaranteeing timing and anti-enumeration defense. |
| [HTTPValidationError](/api-reference/schemas/httpvalidation-error) | `object` | Data schema model. |
| [HealthCheckRead](/api-reference/schemas/health-check-read) | `object` | System health check and diagnostic status. |
| [HrmsInfoResponse](/api-reference/schemas/hrms-info-response) | `object` | Information schema for HRMS scaffold module. |
| [ItemCatalogRead](/api-reference/schemas/item-catalog-read) | `object` | Metadata describing an installed module or plugin package in the catalog. |
| [LoginRequest](/api-reference/schemas/login-request) | `object` | User login credentials and client hardware context. |
| [LogoutRequest](/api-reference/schemas/logout-request) | `object` | Request to revoke session refresh tokens. |
| [MessageResponse](/api-reference/schemas/message-response) | `object` | Standard operation message response. |
| [ModuleListResponse](/api-reference/schemas/module-list-response) | `object` | Catalog of business modules with current tenant activation status. |
| [Page_TenantRead_](/api-reference/schemas/page-tenant-read-) | `object` | Data schema model. |
| [PluginListResponse](/api-reference/schemas/plugin-list-response) | `object` | Catalog of extensible plugins with current tenant activation status. |
| [RefreshTokenRequest](/api-reference/schemas/refresh-token-request) | `object` | Payload to rotate a refresh token and obtain a new access token. |
| [RefreshTokenResponse](/api-reference/schemas/refresh-token-response) | `object` | New token pair issued following successful refresh token rotation. |
| [ResetPasswordRequest](/api-reference/schemas/reset-password-request) | `object` | Payload to reset account password using single-use signed reset token. |
| [ServiceInfoRead](/api-reference/schemas/service-info-read) | `object` | Core service identification and runtime module metadata. |
| [SetupBrandingCreate](/api-reference/schemas/setup-branding-create) | `object` | Optional branding preferences collected during first-run setup. |
| [SetupChecks](/api-reference/schemas/setup-checks) | `object` | Pre-install diagnostics for holders of the one-time setup token. |
| [SetupRequest](/api-reference/schemas/setup-request) | `object` | System configuration parameters collected by the setup wizard. |
| [SetupResult](/api-reference/schemas/setup-result) | `object` | Resources created during successful first-run installation. |
| [SetupStatus](/api-reference/schemas/setup-status) | `object` | Public answer to whether the UI needs to display the first-run setup wizard. |
| [TenantCreate](/api-reference/schemas/tenant-create) | `object` | Body for creating a customer organisation (tenant). |
| [TenantRead](/api-reference/schemas/tenant-read) | `object` | A tenant organisation as returned by the API (includes common audit trail fields). |
| [TenantUpdate](/api-reference/schemas/tenant-update) | `object` | Body for updating a tenant organisation. Send only the fields you wish to modify. |
| [TokenResponse](/api-reference/schemas/token-response) | `object` | Successful authentication response containing JWT credentials and user identity. |
| [UserCreate](/api-reference/schemas/user-create) | `object` | Payload to create a new user account. |
| [UserRead](/api-reference/schemas/user-read) | `object` | User identity record as returned by the API (with decrypted email and mobile). |
| [UserStatus](/api-reference/schemas/user-status) | `string` | Lifecycle status for user accounts. |
| [ValidationError](/api-reference/schemas/validation-error) | `object` | Data schema model. |
