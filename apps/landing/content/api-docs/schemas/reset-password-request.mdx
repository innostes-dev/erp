Payload to reset account password using single-use signed reset token.

## Properties

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `token` | string | Yes | — | Cryptographically signed single-use reset token delivered via email. |
| `new_password` | string | Yes | — | New strong account password complying with complexity rules. |

## Example payload

```json
{
  "token": "rst_4f8e2a1b9c3d7e5f6a0b8c2d4e6f1a3b",
  "new_password": "NewPermanentPassword2026!"
}
```
