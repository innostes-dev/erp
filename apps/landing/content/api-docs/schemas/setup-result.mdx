Resources created during successful first-run installation.

## Properties

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `tenant` | [TenantRead](/api-reference/schemas/tenant-read) | Yes | — | The primary organisation created during setup. |
| `admin` | [UserRead](/api-reference/schemas/user-read) \| null | No | — | The root super administrator created during setup. |
| `installed_at` | string | Yes | — | Timestamp in ISO 8601 UTC when setup was completed. |
