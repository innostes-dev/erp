Batch ingestion request payload.

## Properties

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `items` | [IngestLogItem](/api-reference/schemas/ingest-log-item)[] | Yes | — | List of telemetry logs to ingest in a single batch (max 250). |
