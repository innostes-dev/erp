System configuration parameters collected by the setup wizard.

## Properties

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `organization` | [TenantCreate](/api-reference/schemas/tenant-create) | Yes | — | The primary root customer organisation (tenant) to provision. |
| `admin` | [AdminUserCreate](/api-reference/schemas/admin-user-create) | No | — | The root super administrator credentials. |
| `branding` | [SetupBrandingCreate](/api-reference/schemas/setup-branding-create) \| null | No | — | Optional branding customization. Set to null if skipped. |

}
