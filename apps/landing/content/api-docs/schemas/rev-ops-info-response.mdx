Information schema for RevOps scaffold module.

## Properties

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `id` | string | No | `"revops"` | Unique package identifier string. |
| `name` | string | No | `"RevOps"` | Human-readable module title. |
| `version` | string | No | `"0.1.0"` | Semver version string. |
| `status` | string | No | `"scaffold_ready"` | Operational readiness status of module. |
| `sub_features` | string[] | No | `["leads","deals","pipeline","contacts"]` | List of functional sub-features supported by module. |
| `description` | string | No | `"Revenue operations, customer pipeline, deals, and accounts"` | Module functional overview. |

## Example payload

```json
{
  "description": "Revenue operations, customer pipeline, deals, and accounts",
  "id": "revops",
  "name": "RevOps",
  "status": "scaffold_ready",
  "sub_features": [
    "leads",
    "deals",
    "pipeline",
    "contacts"
  ],
  "version": "0.1.0"
}
```
