Information schema for SalesFlow scaffold module.

## Properties

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `id` | string | No | `"salesflow"` | Unique package identifier string. |
| `name` | string | No | `"SalesFlow"` | Human-readable module title. |
| `version` | string | No | `"0.1.0"` | Semver version string. |
| `status` | string | No | `"scaffold_ready"` | Operational readiness status of module. |
| `sub_features` | string[] | No | `["leads","deals","pipeline","contacts"]` | List of functional sub-features supported by module. |
| `description` | string | No | `"SalesFlow sales pipeline, customer leads, deals, and accounts"` | Module functional overview. |
