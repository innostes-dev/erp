Safe public representation of an API key without secret hash.

## Properties

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `id` | string | Yes | — | Unique identifier of the API key. |
| `name` | string | Yes | — | Human-readable label for the API key. |
| `key_prefix` | string | Yes | — | Public prefix used to identify the token key (e.g. inno_live_...). |
| `scopes` | string[] | Yes | — | Authorized permission scopes granted to this key. |
| `expires_at` | string \| null | No | — | Expiration timestamp in ISO 8601 UTC format. Null for perpetual keys. |
| `last_used_at` | string \| null | No | — | Timestamp when key was last presented in an authenticated request. |
| `is_revoked` | boolean | Yes | — | Flag indicating whether this API key has been revoked. |
| `created_at` | string | Yes | — | Timestamp when key was created. |

## Example payload

```json
{
  "created_at": "2026-10-29T09:00:00Z",
  "expires_at": "2026-11-28T10:00:00Z",
  "id": "3f2b1c9e-5d8a-4f6b-9c2e-1a3b5c7d9e0f",
  "is_revoked": false,
  "key_prefix": "inno_live_xK9p",
  "last_used_at": "2026-10-29T10:15:00Z",
  "name": "Zapier CRM Sync",
  "scopes": [
    "crm:read",
    "hrms:read"
  ]
}
```
