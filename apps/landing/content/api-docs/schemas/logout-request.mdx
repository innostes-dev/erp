Request to revoke session refresh tokens.

## Properties

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `refresh_token` | string \| null | No | — | Specific session refresh token to revoke. When omitted, active cookie is revoked. |
| `logout_all` | boolean | No | `false` | Whether to revoke all active sessions across all client devices. |

## Example payload

```json
{
  "refresh_token": "rt_8f1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d",
  "logout_all": false
}
```
