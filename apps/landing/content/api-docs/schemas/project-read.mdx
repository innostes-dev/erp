Project details with associated environments.

## Properties

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `id` | string | Yes | — | Unique identifier of the record in UUID v4 format. |
| `created_at` | string | Yes | — | Timestamp when the record was created in ISO 8601 UTC format. |
| `created_by` | string \| null | No | — | Unique identifier of the user who created the record. Null for automated system actions. |
| `updated_at` | string | Yes | — | Timestamp when the record was last modified in ISO 8601 UTC format. |
| `updated_by` | string \| null | No | — | Unique identifier of the user who last modified the record. Null for automated system actions. |
| `deleted_at` | string \| null | No | — | Timestamp when the record was soft-deleted in ISO 8601 UTC format. Null while active. |
| `deleted_by` | string \| null | No | — | Unique identifier of the user who soft-deleted the record. Null while active. |
| `tenant_id` | string | Yes | — | — |
| `name` | string | Yes | — | — |
| `slug` | string | Yes | — | — |
| `description` | string \| null | No | — | — |
| `is_active` | boolean | Yes | — | — |
| `environments` | [EnvironmentRead](/api-reference/schemas/environment-read)[] | No | `[]` | — |
