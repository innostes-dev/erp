<ApiEndpoint method="DELETE" path="/plugins/tracura/v1/projects/{project_id}" auth="BearerAuth" />



## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `project_id` | string | Yes | — |

### Header parameters

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `X-Tenant-ID` | string \| null | No | Active tenant context UUID |
| `X-API-Key` | string \| null | No | Scoped Ingestion / Management API Key (inno_log_live_...) |

## Responses

### HTTP 204

Successful Response

### HTTP 404

Project not found

### HTTP 422

Validation Error

Response model: [HTTPValidationError](/api-reference/schemas/httpvalidation-error)

```json
{
  "detail": [
    null
  ]
}
```

curl -X DELETE "http://localhost:8001/plugins/tracura/v1/projects/{project_id}" \

  <Tab value="TypeScript (fetch)">

```ts
const response = await fetch('http://localhost:8001/plugins/tracura/v1/projects/{project_id}', {
  method: 'DELETE',
  headers: {
    Authorization: 'Bearer <your-access-token>',
  },
});

const data = await response.json();
console.log(data);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

headers = {
    "Authorization": "Bearer <your-access-token>",
}

response = httpx.delete(
    "http://localhost:8001/plugins/tracura/v1/projects/{project_id}",
    headers=headers,
)

data = response.json()
print(data)
```
