<ApiEndpoint method="POST" path="/plugins/tracura/v1/projects" auth="BearerAuth" />



## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Header parameters

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `X-Tenant-ID` | string \| null | No | Active tenant context UUID |
| `X-API-Key` | string \| null | No | Scoped Ingestion / Management API Key (inno_log_live_...) |

## Request body

Payload model: [ProjectCreate](/api-reference/schemas/project-create)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Project display name |
| `slug` | string | Yes | URL/slug identifier |
| `description` | string \| null | No | Optional description of the project |

### Request example

```json
{
  "name": "Payment Gateway",
  "slug": "payment-gateway",
  "description": {}
}
```

## Code samples

<Tabs items={["cURL", "TypeScript (fetch)", "Python (httpx)"]}>
  <Tab value="cURL">

```bash
curl -X POST "http://localhost:8001/plugins/tracura/v1/projects" \
  -H "Authorization: Bearer <your-access-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Payment Gateway",
    "slug": "payment-gateway",
    "description": {}
  }'
```

  </Tab>
  <Tab value="TypeScript (fetch)">

```ts
const response = await fetch('http://localhost:8001/plugins/tracura/v1/projects', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer <your-access-token>',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    "name": "Payment Gateway",
    "slug": "payment-gateway",
    "description": {}
  }),
});

const data = await response.json();
console.log(data);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

headers = {
    "Authorization": "Bearer <your-access-token>",
    "Content-Type": "application/json",
}

response = httpx.post(
    "http://localhost:8001/plugins/tracura/v1/projects",
    headers=headers,
    json={
      "name": "Payment Gateway",
      "slug": "payment-gateway",
      "description": {}
    },
)

data = response.json()
print(data)
```
