<ApiEndpoint method="POST" path="/plugins/tracura/v1/ingest" auth="BearerAuth" />

High-throughput asynchronous ingestion endpoint. Accepts an inno_log_live_* key via X-API-Key header.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Header parameters

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `X-API-Key` | string \| null | No | Scoped Ingestion API Key (inno_log_live_...) |

## Request body

Payload model: [IngestLogItem](/api-reference/schemas/ingest-log-item)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `project` | string | Yes | Project slug or UUID string |
| `environment` | string | Yes | Environment slug or UUID string |
| `correlation_id` | string | Yes | Unique trace / request ID |
| `user_id` | string \| null | No | Authenticated actor ID if present |
| `client_ip` | string \| null | No | Client IP address |
| `user_agent` | string \| null | No | Client user agent |
| `http_method` | string | Yes | HTTP method |
| `url` | string | Yes | Full target request URL |
| `path` | string | Yes | Path component |
| `status_code` | integer | Yes | HTTP response status code |
| `duration_ms` | number | Yes | Total latency in milliseconds |
| `request_headers` | object \| null | No | Request headers (redacted on server) |
| `query_params` | object \| null | No | URL query parameters |
| `request_body` | string \| null | No | Raw request JSON or text |
| `response_headers` | object \| null | No | Response headers |
| `response_body` | string \| null | No | Response JSON or text |
| `error` | object \| null | No | Error diagnostics (code, message, stack trace) |
| `meta` | object \| null | No | Developer custom data escape hatch (AI tokens, Stripe ID, git commit, pod) |
| `created_at` | string \| null | No | Timestamp when request occurred |

## Responses

### HTTP 202

Successful Response

Response model: [IngestResponse](/api-reference/schemas/ingest-response)

```json
{
  "accepted": 1,
  "dropped": 1,
  "status": "string"
}
```

### HTTP 401

Invalid or missing API key

### HTTP 422

Validation Error

Response model: [HTTPValidationError](/api-reference/schemas/httpvalidation-error)

```json
{
  "detail": [
    null
  ]
}
```
