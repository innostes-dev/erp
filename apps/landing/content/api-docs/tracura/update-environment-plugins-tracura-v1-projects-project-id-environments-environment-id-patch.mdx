<ApiEndpoint method="PATCH" path="/plugins/tracura/v1/projects/{project_id}/environments/{environment_id}" auth="BearerAuth" />



## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `project_id` | string | Yes | — |
| `environment_id` | string | Yes | — |

### Header parameters

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `X-Tenant-ID` | string \| null | No | Active tenant context UUID |
| `X-API-Key` | string \| null | No | Scoped Ingestion / Management API Key (inno_log_live_...) |

## Request body

Payload model: [EnvironmentUpdate](/api-reference/schemas/environment-update)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string \| null | No | — |
| `color_badge` | string \| null | No | — |
| `is_active` | boolean \| null | No | — |

### Request example

```json
{
  "name": {},
  "color_badge": {},
  "is_active": {}
}
```

```bash
curl -X PATCH "http://localhost:8001/plugins/tracura/v1/projects/{project_id}/environments/{environment_id}" \
```

  <Tab value="TypeScript (fetch)">

```ts
const response = await fetch('http://localhost:8001/plugins/tracura/v1/projects/{project_id}/environments/{environment_id}', {
  method: 'PATCH',
  headers: {
    Authorization: 'Bearer <your-access-token>',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    "name": {},
    "color_badge": {},
    "is_active": {}
  }),
});

const data = await response.json();
console.log(data);
```

  </Tab>
  <Tab value="Python (httpx)">

```python
import httpx

headers = {
    "Authorization": "Bearer <your-access-token>",
    "Content-Type": "application/json",
}

response = httpx.patch(
    "http://localhost:8001/plugins/tracura/v1/projects/{project_id}/environments/{environment_id}",
    headers=headers,
    json={
      "name": {},
      "color_badge": {},
      "is_active": {}
    },
)

data = response.json()
print(data)
```
