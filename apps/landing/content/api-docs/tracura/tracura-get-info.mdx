<ApiEndpoint method="GET" path="/plugins/api-logger/info" auth="None" />

Return API Logger plugin metadata and status.

Public endpoint. Returns scaffold readiness status and available features.

## Authentication

This endpoint is public and does not require an authentication header.

## Responses

### HTTP 200

Successful Response

Response model: [ApiLoggerInfoResponse](/api-reference/schemas/tracura-info-response)

```json
{
  "description": "API request logging, webhook inspection, and debugging",
  "features": [
    "requests",
    "webhooks",
    "analytics",
    "filters"
  ],
  "id": "api-logger",
  "name": "API Logger",
  "status": "scaffold_ready",
  "type": "plugin",
  "version": "0.1.0"
}
```
