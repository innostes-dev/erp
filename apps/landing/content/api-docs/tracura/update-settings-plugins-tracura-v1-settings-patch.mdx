<ApiEndpoint method="PATCH" path="/plugins/tracura/v1/settings" auth="BearerAuth" />



## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Query parameters

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `project_id` | string \| null | No | — | Project scope override |
| `environment_id` | string \| null | No | — | Environment scope override |

### Header parameters

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `X-Tenant-ID` | string \| null | No | Active tenant context UUID |
| `X-API-Key` | string \| null | No | Scoped Ingestion / Management API Key (inno_log_live_...) |

## Request body

Payload model: [SettingsUpdate](/api-reference/schemas/settings-update)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `retention_days` | integer \| null | No | Log retention period in days |
| `max_body_size_bytes` | integer \| null | No | Max body capture bytes before truncation |
| `sampling_rate` | number \| null | No | Sampling rate from 0.01 (1%) to 1.00 (100%) |
| `capture_headers` | boolean \| null | No | — |
| `capture_body` | boolean \| null | No | — |
| `log_errors_only` | boolean \| null | No | — |
| `excluded_paths` | string[] \| null | No | — |
| `sensitive_headers` | string[] \| null | No | — |
| `sensitive_body_fields` | string[] \| null | No | — |
| `mask_client_ip` | boolean \| null | No | — |
