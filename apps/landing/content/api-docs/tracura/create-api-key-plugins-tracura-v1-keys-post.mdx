<ApiEndpoint method="POST" path="/plugins/tracura/v1/keys" auth="BearerAuth" />

Generate a new scoped ingestion API key. The raw secret is returned ONCE in this response.

## Authentication

Requires a valid JSON Web Token (JWT) issued by `/auth/login`. Pass the token in the `Authorization` HTTP header using the `Bearer` scheme:

```http
Authorization: Bearer <your-access-token>
```

## Parameters

### Header parameters

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `X-Tenant-ID` | string \| null | No | Active tenant context UUID |
| `X-API-Key` | string \| null | No | Scoped Ingestion / Management API Key (inno_log_live_...) |

## Request body

Payload model: [ApiKeyCreate](/api-reference/schemas/api-key-create)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Key name / label |
| `project_id` | string \| null | No | Scope to a specific project. If None, permitted across all tenant projects. |
| `allowed_environments` | string[] | No | Allowed environments, e.g. ['production'] or ['*'] |
| `ip_allowlist` | string[] \| null | No | Optional list of permitted client CIDRs or IPs |
| `allowed_origins` | string[] \| null | No | Optional list of permitted HTTP Origin headers |
| `rate_limit_rpm` | integer | No | Rate limit requests per minute |
| `expires_in_days` | integer \| null | No | Key expiry in days from creation |

### Request example

```json
{
  "name": "Prod Cluster Ingestion Key",
  "project_id": {},
  "allowed_environments": [
    "string"
  ],
  "ip_allowlist": {},
  "allowed_origins": {},
  "rate_limit_rpm": 1,
  "expires_in_days": {}
}
```
