<ApiEndpoint method="GET" path="/revops/info" auth="None" />

Return RevOps module metadata and scaffold status.

Public endpoint. Returns scaffold readiness status and available features.

## Authentication

This endpoint is public and does not require an authentication header.

## Responses

### HTTP 200

Successful Response

Response model: [RevOpsInfoResponse](/api-reference/schemas/rev-ops-info-response)

```json
{
  "description": "Revenue operations, customer pipeline, deals, and accounts",
  "id": "revops",
  "name": "RevOps",
  "status": "scaffold_ready",
  "sub_features": [
    "leads",
    "deals",
    "pipeline",
    "contacts"
  ],
  "version": "0.1.0"
}
```
