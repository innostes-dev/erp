<ApiEndpoint method="GET" path="/peopleops/info" auth="None" />

Return PeopleOps module metadata and scaffold status.

Public endpoint. Returns scaffold readiness status and available features.

## Authentication

This endpoint is public and does not require an authentication header.

## Responses

### HTTP 200

Successful Response

Response model: [PeopleOpsInfoResponse](/api-reference/schemas/people-ops-info-response)

```json
{
  "description": "People operations, employee directory, leaves, and payroll",
  "id": "peopleops",
  "name": "PeopleOps",
  "status": "scaffold_ready",
  "sub_features": [
    "employees",
    "leave",
    "payroll",
    "attendance"
  ],
  "version": "0.1.0"
}
```
