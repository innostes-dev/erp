<ApiEndpoint method="GET" path="/config" auth="None" />

Public configuration and app metadata for frontend bootstrapping.

Public endpoint. Supplies non-sensitive deployment information to client applications.

## Authentication

This endpoint is public and does not require an authentication header.

## Responses

### HTTP 200

Successful Response

Response model: [AppConfigRead](/api-reference/schemas/app-config-read)

```json
{
  "environment": "development",
  "service": "Innostes ERP API Server",
  "version": "0.1.0"
}
```
