<ApiEndpoint method="GET" path="/" auth="None" />

Service name, environment, status, and the list of loaded modules.

Public endpoint. Returns service identification and loaded feature module metadata.

## Authentication

This endpoint is public and does not require an authentication header.

## Responses

### HTTP 200

Successful Response

Response model: [ServiceInfoRead](/api-reference/schemas/service-info-read)

```json
{
  "environment": "development",
  "modules": [
    "auth",
    "setup",
    "tenancy",
    "user",
    "crm",
    "hrms",
    "api-logger"
  ],
  "service": "Innostes ERP API Server",
  "status": "online"
}
```
