## Responsive behaviour

- **Desktop (>= 1024px)**: Full multi-column tabular view displaying invoice number, customer legal name, GSTIN, due dates, currency totals, status tags, and action triggers.
- **Mobile (< 768px)**: The toolbar controls stack vertically into full-width elements. The table switches cleanly or scrolls horizontally without breaking outer container boundaries.

## Accessibility notes

- **Selection semantics**: The master checkbox in the header reflects `aria-checked="mixed"` when a partial subset of rows is selected. Individual row checkboxes carry descriptive `aria-label` tags including invoice numbers.
- **Search debounce**: Search input updates announce results politely via live regions without interrupting screen reader speech mid-keystroke.
- **Row action menus**: Each row menu button exposes an explicit accessible label (e.g. `aria-label="Actions for INV-2026-0801"`).
