## What's in it

This reference onboarding wizard guides new enterprise tenants through company configuration, database connection, administrator provisioning, and regional locale preferences:

| Section | Components |
| :--- | :--- |
| **Brand Panel** | [`Badge`](/ui/docs/components/data-display/badge), [`IconTile`](/ui/docs/components/data-display/icon-tile) |
| **Progress Stepper** | [`Stepper`](/ui/docs/components/navigation/stepper) with interactive completed steps and step descriptions |
| **Form Entry** | [`Field`](/ui/docs/components/forms/field), [`FieldLabel`](/ui/docs/components/forms/field), [`Input`](/ui/docs/components/forms/input), [`FormGrid`](/ui/docs/components/layout/form-layout) |
| **Regional Settings** | [`CountrySelect`](/ui/docs/components/forms/locale-select), [`LanguageSelect`](/ui/docs/components/forms/locale-select), [`TimezoneSelect`](/ui/docs/components/forms/locale-select), [`DateFormatSelect`](/ui/docs/components/forms/locale-select) |

| **Wizard Navigation** | [`FormActions`](/ui/docs/components/layout/form-layout), [`Button`](/ui/docs/components/actions/button) |

## Responsive behaviour

- **Desktop (>= 1024px)**: Renders a horizontal split view with the brand feature overview on the left panel (40% width) and the active setup form on the right panel (60% width).
- **Tablet & Mobile (< 1024px)**: Collapses into a single vertical container. The brand panel transforms into a compact header banner, and the horizontal `Stepper` compresses using compact step indicators. Form inputs span full container width.

## Accessibility notes

- **Step announcement**: The [`Stepper`](/ui/docs/components/navigation/stepper) communicates progress to screen readers with `aria-current="step"` on the active step and polite announcements upon advancing.
- **Form error associations**: All form controls are wrapped in [`Field`](/ui/docs/components/forms/field), ensuring invalid inputs automatically link to [`FieldError`](/ui/docs/components/forms/field) messages via `aria-describedby` and reflect `aria-invalid="true"`.
- **Focus management**: Advancing to the next step programmatically shifts keyboard focus to the first interactive field in the newly rendered step.
