## What's in it

| Part | Components |
| --- | --- |
| Brand panel | `Badge`, `IconTile` |
| Progress | `Stepper` (completed steps are clickable) |
| Form | `Form`, `FormGrid`, `Field`, `Input`, `Label` |
| Locale settings | `CountrySelect`, `TimezoneSelect`, `LanguageSelect`, `DateFormatSelect` |
| Help | `Alert` (info) |
| Footer | `FormActions align="between"`, `Button` |

Try submitting with an empty name, or a slug with spaces: validation runs on submit and the errors
are announced. The layout uses container queries, so it adapts to wherever it's placed.
