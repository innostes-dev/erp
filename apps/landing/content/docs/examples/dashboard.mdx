## What's in it

This flagship example combines our layout and widget components into a responsive HRMS application layout, matching our reference dashboard composition.

| Part                     | Components                                                                                                                                                                                                                  |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Global Navigation**    | [`AppRail`](/docs/components/layout/app-rail) on the far left with `AppRailItem`                                                                                                                                            |
| **Workspace Navigation** | [`SidebarProvider`](/docs/components/layout/sidebar), `Sidebar` (icon collapsible), `SidebarMenu`                                                                                                                           |
| **Top Header**           | [`TopBar`](/docs/components/layout/top-bar) with [`AppSwitcher`](/docs/components/widgets/app-switcher), [`NotificationBell`](/docs/components/widgets/notifications), and [`UserMenu`](/docs/components/widgets/user-menu) |
| **Content Area**         | `SidebarInset` containing the main content                                                                                                                                                                                  |
| **Welcome**              | [`WelcomeBanner`](/docs/components/widgets/welcome-banner)                                                                                                                                                                  |
| **KPIs**                 | [`MetricCard`](/docs/components/widgets/metric-card) and `MetricGrid`                                                                                                                                                       |
| **Data Viz**             | [`BarChart`](/docs/components/charts/bar-chart) in a [`WidgetCard`](/docs/components/widgets/widget-card)                                                                                                                   |
| **Dashboard Widgets**    | [`QuickActions`](/docs/components/widgets/quick-actions), [`EntityList`](/docs/components/widgets/entity-list), [`ActivityFeed`](/docs/components/widgets/activity-feed)                                                    |

### Responsive Behavior

Open the **Code** tab to copy the full page. The layout responds to its container and viewport widths:

- At narrower widths, the `AppRail` collapses or hides.
- The `Sidebar` collapses to an icon rail or goes off-canvas automatically.
- Dashboard widgets like the `BarChart` and `MetricCard`s stack vertically using grid layout and container queries (`@container`).
