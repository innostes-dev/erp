## What's in it

This reference example combines our layout and widget components into a responsive HRMS application layout, matching our reference dashboard composition.

| Part                     | Components                                                                                                                                                                                                                  |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Global Navigation**    | [`AppRail`](/ui/docs/components/layout/app-rail) on the far left with `AppRailItem`                                                                                                                                         |
| **Workspace Navigation** | [`SidebarProvider`](/ui/docs/components/layout/sidebar), `Sidebar` (icon collapsible), `SidebarMenu`                                                                                                                        |
| **Top Header**           | [`TopBar`](/ui/docs/components/layout/top-bar) with [`AppSwitcher`](/ui/docs/widgets/app-switcher), [`NotificationBell`](/ui/docs/widgets/notification-bell), and [`UserMenu`](/ui/docs/widgets/user-menu)               |
| **Content Area**         | `SidebarInset` containing the main content                                                                                                                                                                                  |
| **Welcome**              | `WelcomeBanner`                                                                                                                                                                                                             |
| **KPIs**                 | [`MetricCard`](/ui/docs/widgets/metric-card) and `MetricGrid`                                                                                                                                                                |
| **Data Viz**             | [`BarChart`](/ui/docs/charts/cartesian) in a [`WidgetCard`](/ui/docs/widgets/widget-card)                                                                                                                                    |
| **Dashboard Widgets**    | `QuickActions`, `EntityList`, `ActivityFeed`                                                                                                                                                                                |

### Responsive behaviour

Open the **Code** tab to copy the full page. The layout responds to its container and viewport widths:

- At narrower widths, the `AppRail` collapses or hides.
- The `Sidebar` collapses to an icon rail or goes off-canvas automatically.
- Dashboard widgets like the `BarChart` and `MetricCard`s stack vertically using grid layout and container queries (`@container`).
