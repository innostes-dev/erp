## What's in it

| Part | Components |
| --- | --- |
| App shell | `SidebarProvider`, `Sidebar`, `SidebarMenuButton`, `SidebarTrigger`, `SidebarInset` |
| Header | `PageHeader`, `Breadcrumb`, `Button`, `Avatar` |

| KPIs | `Stat` |

| Feedback | `toast` |

Open the **Code** tab to copy the full page. Collapse the sidebar with the button in the header
or Ctrl/⌘ + B. The layout responds to its container (CSS container queries), so it adapts
wherever you place it.
