`@innostes/ui` styles every primitive through **semantic design tokens**. Instead of scattering arbitrary hex codes or hardcoded utility classes across markup, components reference role-based CSS custom properties such as `bg-primary`, `text-muted-foreground`, and `border-border`.

## How tokens work

The design token system operates on three foundational principles:

1. **Role-based abstraction**: Tokens represent functional interface roles (`card`, `primary`, `destructive`, `muted`) rather than literal colours. Swapping a primary action colour requires changing one variable.
2. **Foreground pairing**: Every container or surface token has a strictly coupled foreground counterpart (`primary-foreground`, `card-foreground`, `destructive-foreground`) guaranteed to satisfy WCAG 2.2 AA contrast ratios.
3. **Perceptual uniformity with OKLCH**: Dark mode and theme overrides use the OKLCH colour model (`oklch(L C H)`), ensuring linear lightness transitions without unpredictable perceived brightness shifts across different hues.

## Overriding tokens

### Tailwind CSS v4

In Tailwind v4, declare custom tokens inside your `@theme` block. Because `@innostes/ui/tailwind.css` marks defaults with `@theme default`, any rule defined in your application stylesheet takes precedence:

```css title="app/globals.css"
@import "tailwindcss";
@import "@innostes/ui/tailwind.css";
@import "@innostes/ui/dark.css";

@theme {
  /* Override primary action to forest emerald */
  --color-primary: oklch(50.8% 0.144 164.215);
  --color-primary-hover: oklch(43.5% 0.138 164.5);
  --color-primary-foreground: oklch(100% 0 0);

  /* Adjust border rounding */
  --radius-md: 0.5rem;
}
```

### Tailwind CSS v3

For Tailwind v3, map the CSS custom properties inside your `tailwind.config.js`:

```js title="tailwind.config.js"
/** @type {import('tailwindcss').Config} */
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: {
          DEFAULT: 'var(--color-primary)',
          hover: 'var(--color-primary-hover)',
          foreground: 'var(--color-primary-foreground)',
        },
      },
    },
  },
};
```

### Without Tailwind CSS

When using plain CSS, override variables on `:root` or a scoped selector:

```css title="styles/theme.css"
:root {
  --color-primary: #059669;
  --color-primary-hover: #047857;
  --color-primary-foreground: #ffffff;
}
```

## Scoped themes

Because tokens are standard CSS custom properties, you can scope different themes to specific DOM branches without affecting the rest of the application:

```css title="app/globals.css"
/* Scoped finance sub-ledger theme */
.theme-finance {
  --color-primary: oklch(50.8% 0.144 164.215);
  --color-primary-hover: oklch(43.5% 0.138 164.5);
  --color-primary-foreground: oklch(100% 0 0);
  --color-card: oklch(98% 0.01 160);
}
```

Apply the class to any enclosing element:

```tsx title="app/finance/page.tsx"
import { Button, Card } from '@innostes/ui';

export function FinanceSection() {
  return (
    <div className="theme-finance p-6">
      <Card>
        <p className="text-sm">Northwind Traders Accounting Module</p>
        <Button variant="primary">Generate Balance Sheet</Button>
      </Card>
    </div>
  );
}
```

## White-label & multi-tenant theming

In multi-tenant ERP deployments, different subsidiaries or client organisations require distinct branding. Implement this by dynamically injecting tenant-specific CSS variables at runtime:

```tsx title="components/tenant-provider.tsx"
import * as React from 'react';

interface TenantTheme {
  primary: string;
  primaryHover: string;
  primaryForeground: string;
}

const TENANT_THEMES: Record<string, TenantTheme> = {
  'northwind-bengaluru': {
    primary: 'oklch(54.6% 0.245 262.881)', // Blue
    primaryHover: 'oklch(48.8% 0.243 264.376)',
    primaryForeground: 'oklch(100% 0 0)',
  },
  'western-logistics': {
    primary: 'oklch(50.8% 0.144 164.215)', // Emerald
    primaryHover: 'oklch(43.5% 0.138 164.5)',
    primaryForeground: 'oklch(100% 0 0)',
  },
};

export function TenantProvider({
  tenantId,
  children,
}: {
  tenantId: string;
  children: React.ReactNode;
}) {
  const theme = TENANT_THEMES[tenantId] || TENANT_THEMES['northwind-bengaluru'];

  const style = {
    '--color-primary': theme.primary,
    '--color-primary-hover': theme.primaryHover,
    '--color-primary-foreground': theme.primaryForeground,
  } as React.CSSProperties;

  return (
    <div data-tenant={tenantId} style={style}>
      {children}
    </div>
  );
}
```
