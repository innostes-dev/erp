# Typography

Typographic scale in innostes UI balances high information density with sustained reading comfort. Designed for enterprise data grids, accounting ledgers, and operational dashboards at Northwind Traders Pvt Ltd, the typographic hierarchy prioritises tabular alignment and clear legibility.

## Type scale

The type scale maps to CSS custom properties defined in the root stylesheet:

- `text-xs` (12px): Metadata timestamps, badge labels, and compact table captions.
- `text-sm` (14px): Standard enterprise body text, input fields, and data grid cells.
- `text-base` (16px): Document body copy, modal subtitles, and standard card headers.
- `text-lg` to `text-2xl` (18px–24px): Section titles, metric card values, and page headings.

The primary system font stack leverages modern geometric system typefaces with automatic fallback to Inter and Segoe UI, paired with monospace font stacks optimized for tabular numeric data.
