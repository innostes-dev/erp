# Icons

Icons in innostes UI provide immediate visual cues alongside textual labels. The design system standardises on the Lucide icon library, ensuring consistent stroke weights, optical alignment, and predictable bounding boxes across all components.

## Guidelines

- **Textual accompaniment**: Icons that trigger interactive operations must include visible text or an explicit `aria-label` for assistive technologies.
- **Decorative iconography**: Icons that accompany descriptive text should receive `aria-hidden="true"` to prevent duplicate screen reader announcements.
- **Sizing standards**: Standard icon sizes align with typographic scale: `size-3.5` (14px) for compact tags, `size-4` (16px) for standard buttons and inputs, and `size-5` (20px) for navigation items.
