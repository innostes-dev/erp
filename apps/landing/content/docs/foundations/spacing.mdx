# Spacing and layout

Consistent spatial rhythm prevents visual clutter and establishes structural relationships between interface elements. innostes UI adopts a 4px base increment across padding, margin, gap, and dimension tokens.

## Spatial grid

Spatial values follow a linear 4px progression aligned with standard Tailwind CSS spacing utilities:

- `1` (4px): Micro-spacing between icon glyphs and adjacent inline text.
- `2` (8px): Compact padding inside buttons, badges, and grouped controls.
- `3` (12px): Default internal padding for form inputs and table cells.
- `4` (16px): Card padding, dialog gutters, and standard component gaps.
- `6` (24px) to `8` (32px): Layout section margins and page header separation.

Components accommodate both standard and compact density modes, allowing operators to adjust data density according to screen resolution and task requirements.
