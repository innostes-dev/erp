## Import

Charts are exported from `@innostes/ui/charts` to isolate Recharts from your main application bundle:

```tsx
import { BarChart, LineChart, AreaChart } from '@innostes/ui/charts';
```

## When to use

Cartesian charts plot quantitative values across categorical dimensions (such as months, quarters, or product categories):

- **BarChart**: Comparing discrete, independent categories (e.g. quarterly spend per vendor or monthly dispatch volume).
- **LineChart**: Tracking continuous trends over time (e.g. daily inventory stock balance or invoice settlement times).
- **AreaChart**: Emphasizing cumulative volume or part-to-whole accumulation over continuous time intervals.

**Do not use Cartesian charts for:**
- Proportional parts of a single whole — use [DonutChart](/ui/docs/charts/donut).
- Minimal inline trendlines in tables or cards — use [Sparkline](/ui/docs/widgets/sparkline).
- Single KPI numbers — use [MetricCard](/ui/docs/widgets/metric-card).

## Examples

### Installation and React version guidance

Install `recharts` as a peer dependency matched to your project's React runtime:

- **React 18 / 19**: `pnpm add recharts@^3.0.0`
- **React 17**: `pnpm add recharts@^2.15.0`

### BarChart for categorical comparisons

Comparing quarterly procurement spend across Northwind Traders divisions:

```tsx
const quarterlySpend = [
  { quarter: 'Q1 FY26', procurement: 4200000, logistics: 850000 },
  { quarter: 'Q2 FY26', procurement: 4900000, logistics: 920000 },
  { quarter: 'Q3 FY26', procurement: 5400000, logistics: 1100000 },
  { quarter: 'Q4 FY26', procurement: 6100000, logistics: 1250000 },
];

<BarChart
  aria-label="Quarterly procurement and logistics expenditure"
  data={quarterlySpend}
  categoryKey="quarter"
  series={[
    { key: 'procurement', label: 'Procurement (INR)', color: 'chart-1' },
    { key: 'logistics', label: 'Logistics (INR)', color: 'chart-2' },
  ]}
  valueFormatter={(v) => `₹${(v / 100000).toFixed(1)}L`}
/>
```

### Indian fiscal formatting and en-IN localization

Use `Intl.NumberFormat` with `en-IN` to format currency and quantities correctly according to Indian numbering standards (lakhs and crores):

```tsx
const inrFormatter = (val: number) =>
  new Intl.NumberFormat('en-IN', {
    style: 'currency',
    currency: 'INR',
    maximumFractionDigits: 0,
  }).format(val);

<BarChart
  aria-label="Annual vendor payouts"
  data={vendorPayouts}
  categoryKey="vendor"
  series={[{ key: 'amount', label: 'Payout' }]}
  valueFormatter={inrFormatter}
  locale="en-IN"
/>
```

### Empty and loading states inside WidgetCard

Wrap charts in `WidgetCard` with `padding="none"` to maintain clean edges and handle asynchronous fetch lifecycles:

```tsx
<WidgetCard
  title="Monthly revenue trend"
  padding="none"
  loading={isLoading}
  empty={data.length === 0}
  emptyState="No transaction data recorded for this fiscal quarter."
>
  <AreaChart
    aria-label="Monthly revenue trend"
    data={data}
    categoryKey="period"
    series={[{ key: 'revenue', label: 'Revenue (₹)' }]}
  />
</WidgetCard>
```

## Accessibility

Every Cartesian chart automatically renders an accessible, visually-hidden `<table>` element alongside the visual SVG graphic via the internal `ChartFrame` wrapper.

### Screen reader table navigation

Assistive technologies do not encounter an unlabelled opaque canvas. Instead, screen reader operators navigate the underlying tabular dataset using standard table keyboard commands (such as Control + Option + Arrow keys in VoiceOver):

- The table is given an accessible name using the required `aria-label` prop.
- Category keys render as column headers (`<th>`).
- Data series render as structured rows (`<tr>`) with localized numeric values formatted via `valueFormatter`.

### Colour and contrast

Chart colours are mapped directly from semantic design tokens (`--color-chart-1` through `--color-chart-8`), ensuring minimum 4.5:1 contrast against both light and dark card backgrounds. Interactive legends allow operators to toggle individual data series visibility.
