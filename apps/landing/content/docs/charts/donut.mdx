## Import

Charts are exported from `@innostes/ui/charts` to isolate Recharts from your main application bundle:

```tsx
import { DonutChart, type DonutChartProps } from '@innostes/ui/charts';
```

## When to use

Use `DonutChart` when visualizing the proportional breakdown of a finite total across 2 to 7 categories:

- **Procurement expenditure by category**: Spices (42%), Dry Fruits (28%), Packaging Materials (18%), Logistics (12%).
- **Warehouse capacity allocation**: Occupied pallet bays versus available storage.
- **Invoice status distribution**: Paid, pending authorization, in-dispute, and overdue.

**Do not use DonutChart for:**
- More than 7 discrete categories — slices become too thin to distinguish visually; use a sorted horizontal [BarChart](/ui/docs/charts/cartesian) instead.
- Time-series or trend progression — use [LineChart](/ui/docs/charts/cartesian).
- Continuous cumulative flow — use [AreaChart](/ui/docs/charts/cartesian).

## Examples

### Category distribution with centre metric

Displaying total annual expenditure with prominent centre KPI callouts:

```tsx
const spendDistribution = [
  { key: 'spices', label: 'Spices & Condiments', value: 4280000, color: 'chart-1' },
  { key: 'dryfruits', label: 'Dry Fruits & Nuts', value: 2850000, color: 'chart-2' },
  { key: 'packaging', label: 'Packaging Materials', value: 1840000, color: 'chart-3' },
  { key: 'logistics', label: 'Freight & Logistics', value: 1220000, color: 'chart-4' },
];

<DonutChart
  aria-label="Annual expenditure breakdown by category"
  data={spendDistribution}
  centerLabel="Total spend"
  centerValue="₹1.02 Cr"
  valueFormatter={(v) => `₹${(v / 100000).toFixed(1)}L`}
  locale="en-IN"
/>
```

### Semantic tone mapping

Assign semantic tones (`success`, `warning`, `destructive`) to individual slices to reflect compliance status:

```tsx
const auditBreakdown = [
  { key: 'passed', label: 'Compliant consignments', value: 840, color: 'success' },
  { key: 'pending', label: 'Awaiting e-way bills', value: 120, color: 'warning' },
  { key: 'rejected', label: 'Damaged / rejected', value: 40, color: 'destructive' },
];

<DonutChart
  aria-label="Consignment compliance status"
  data={auditBreakdown}
  centerLabel="Audited"
  centerValue="1,000"
/>
```

## Accessibility

`DonutChart` renders an accessible, visually-hidden `<table>` element via `ChartFrame` alongside the visual SVG rendering.

### Screen reader table navigation

- The required `aria-label` provides an accessible title for the data table.
- Each slice is tabulated with its category name, absolute numeric value (formatted via `valueFormatter`), and calculated percentage share.
- Screen reader operators can review the exact breakdown sequentially without needing pointer coordinates.

### Colour contrast

Slices consume token-based colours (`chart-1` through `chart-8` or semantic tones) designed to maintain distinct contrast boundaries in both light and dark modes.
