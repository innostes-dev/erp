  type MetricCardProps,

## When to use

Use `MetricCard` to display primary Key Performance Indicators (KPIs) across executive and operational dashboards:

- **Executive overview**: Total revenue, gross margin, accounts receivable, and net profit.
- **Logistics operations**: On-time dispatches, warehouse capacity, and fleet turnaround.
- **Procurement metrics**: Open purchase order spend, vendor fulfilment rate, and average lead time.

**Do not use MetricCard for:**
- Long tabular data rows — use [DataTable](/ui/docs/components/data-display/data-table).
- Multi-step interactive wizards — use [Stepper](/ui/docs/components/navigation/stepper).
- Detailed multi-dimensional data charts — use [CartesianChart](/ui/docs/charts/cartesian).

## Examples

### Seven design variants

Select from seven specialized variants to match the density and focus of each dashboard row:

| Variant | Best for |
| :--- | :--- |
| `default` | Standard KPI with icon, primary value, delta badge, and comparison period. |
| `compact` | High-density grids, sidebars, or auxiliary operational cards. |
| `accent` | Highlighting the single most vital metric on the page. |
| `sparkline` | Emphasizing trajectory over time rather than a single static number. |
| `progress` | Tracking achievement toward an explicit quota or quarterly target. |
| `comparison` | Side-by-side contrast between current period and historical benchmark. |
| `split` | Decomposing a total into segmented parts (e.g. order status distribution). |

### Deltas, trends, and Indian fiscal formatting

Format numeric deltas as fractional values (e.g. `0.125` formats as `+12.5%`) and format rupee values in `en-IN`:

```tsx
<MetricGrid columns={3}>
  <MetricCard
    label="Monthly procurement"
    value="₹48,25,000"
    delta={0.142}
    comparison="vs last month"
  />
  <MetricCard
    label="Average lead time"
    value="3.2 days"
    delta={-0.18}
    upIsGood={false}
    comparison="vs target"
  />
  <MetricCard
    variant="sparkline"
    label="Daily order volume"
    value="142 orders"
    sparklineData={[110, 118, 125, 130, 138, 142]}
  />
</MetricGrid>
```

### Progress toward quarterly quota

Track goal completion percentages with `variant="progress"`:

```tsx
<MetricCard
  variant="progress"
  label="FY 2026 Q3 dispatch target"
  value="₹1.84 Cr"
  progress={82}
  comparison="Target: ₹2.25 Cr"
/>
```

## Accessibility

`MetricCard` formats values and delta directions with accessible announcements.

### Keyboard navigation

Metric cards render as readable informational blocks. When rendered with an `href` or interactive action, cards receive standard keyboard focus with Enter/Space triggers.

### ARIA attributes

- Directional delta arrows announce their trajectory ("Up", "Down") explicitly to screen readers so meaning is not conveyed by colour alone.
- Progress bars inside `variant="progress"` use semantic `role="progressbar"` with `aria-valuenow`, `aria-valuemin="0"`, and `aria-valuemax="100"`.
- Cards render within semantic `<section>` or `<article>` landmarks.
