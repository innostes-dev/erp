## When to use

Use `EntityList` to present curated collections of business records within dashboard cards or drawers:

- **Key vendor rankings**: Top suppliers by spend or pending invoice balance.
- **Customer account summaries**: Recent high-value corporate buyers.
- **Warehouse personnel rosters**: On-duty supervisors at regional depots.

**Do not use EntityList for:**
- Full-page searchable and sortable enterprise records — use [DataTable](/ui/docs/components/data-display/data-table).
- Pure task checklists with action buttons — use [ActionList](/ui/docs/widgets/action-list).
- Event audit feeds — use [ActivityFeed](/ui/docs/widgets/activity-feed).

## Examples

### Business vendor roster with status badges and actions

Presenting primary ERP suppliers with initials avatars, financial totals, and direct action triggers:

```tsx
<EntityList
  divided
  items={[
    {
      id: '1',
      title: 'Bengaluru Spices Pvt Ltd',
      subtitle: 'GSTIN: 29ABCDE1234F1Z5 · Koramangala Hub',
      initials: 'BS',
      tone: 'primary',
      meta: <span className="font-semibold">₹4,28,900</span>,
      action: (
        <Button size="sm" variant="ghost" iconOnly aria-label="View ledger">
          <ExternalLink className="size-4" />
        </Button>
      ),
    },
    {
      id: '2',
      title: 'Malabar Cardamom Producers',
      subtitle: 'GSTIN: 32AABCM5678K1Z2 · Kochi Depot',
      initials: 'MC',
      tone: 'success',
      meta: <span className="font-semibold">₹2,85,000</span>,
    },
  ]}
/>
```

### Compact density for sidebars

Set `density="sm"` when placing the list inside narrow navigation drawers or secondary panels:

```tsx
<EntityList
  density="sm"
  items={recentCustomers}
  onItemClick={(item) => navigateToCustomer(item.id)}
/>
```

## Accessibility

`EntityList` implements semantic list patterns with interactive row semantics.

### Keyboard navigation

<KeyboardTable
  entries={[
    { key: 'Tab', action: 'Moves focus sequentially between interactive row buttons or links.' },
    { key: 'Enter / Space', action: 'Activates the focused entity row or row action button.' },
  ]}
/>

### ARIA attributes

- Rows render inside semantic `<ul>` and `<li>` elements.
- When `onItemClick` is supplied, each item renders an accessible button element with full keyboard support.
- Action buttons inside rows maintain distinct accessible labels via `aria-label`.
