## When to use

Use `ChangeLog` when providing immutable historical inspection of record modifications:

- **ERP record revision history**: Tracking revisions to purchase orders, contracts, and vendor profiles.
- **Statutory tax modifications**: Logging alterations to GSTIN registrations, PAN details, and bank mandates.
- **Security credential adjustments**: Showing permission modifications made to operator roles.

**Do not use ChangeLog for:**
- High-level event timelines without field-level diffs — use [ActivityFeed](/ui/docs/widgets/activity-feed).
- Pending authorization task queues — use [ActionList](/ui/docs/widgets/action-list).
- Ephemeral toast notifications — use [Toast](/ui/docs/components/feedback/toast).

## Examples

### Field-level diffs with day grouping

Mapping audit records to structured entries with `from` and `to` values:

```tsx
<ChangeLog
  groupByDay
  entries={[
    {
      id: '1',
      actor: 'Priya Sharma',
      action: 'updated purchase order terms',
      time: new Date(Date.now() - 1000 * 60 * 30),
      changes: [
        { field: 'Payment terms', from: 'Net 30', to: 'Net 60' },
        { field: 'Delivery depot', from: 'Koramangala Hub', to: 'Whitefield Central Depot' },
      ],
      note: 'Adjusted per vendor renegotiation meeting.',
    },
    {
      id: '2',
      actor: 'Ramesh Kumar',
      action: 'authorized discount rate',
      time: new Date(Date.now() - 1000 * 60 * 180),
      changes: [
        { field: 'Trade discount', from: '0%', to: '5%' },
      ],
    },
  ]}
/>
```

### Badges and custom diff elements

`from` and `to` accept arbitrary React nodes, enabling live status badge diffs:

```tsx
<ChangeLog
  entries={[
    {
      id: '3',
      actor: 'System Automation',
      action: 'reconciled e-way bill status',
      time: new Date(),
      changes: [
        {
          field: 'GST Status',
          from: <Badge variant="warning">Generated</Badge>,
          to: <Badge variant="success">Validated</Badge>,
        },
      ],
    },
  ]}
/>
```

## Accessibility

`ChangeLog` renders semantic description lists with accessible diff tags.

### Keyboard navigation

<KeyboardTable
  entries={[
    { key: 'Tab', action: 'Moves focus sequentially between interactive links or user profile buttons in the log.' },
  ]}
/>

### ARIA attributes

- Differences use semantic `<del>` (for previous values) and `<ins>` (for updated values).
- Visually hidden labels (`diffLabels`, customizable for localization) announce "from" and "to" explicitly to screen readers.
- Day headers group revisions cleanly under accessible regional landmarks.

## Guidelines
