## Import

```tsx
import {
  Sparkline,
  type SparklineProps,
} from '@innostes/ui';
```

## When to use

Use `Sparkline` to display immediate trajectory context in compact environments where full chart axes would overwhelm the layout:

- **Data table cells**: Showing 7-day sales trends alongside inventory rows.
- **KPI cards**: Showing monthly cash flow trajectory in [MetricCard](/ui/docs/widgets/metric-card).
- **Stat summary tiles**: Visualizing delivery performance or return rates.

**Do not use Sparkline for:**
- Interactive data analysis requiring hover tooltips, axis labels, or multiple series — use [CartesianChart](/ui/docs/charts/cartesian).
- Part-to-whole categorical breakdowns — use [DonutChart](/ui/docs/charts/donut).
- Progress completion toward a fixed target — use [Progress](/ui/docs/components/feedback/progress).

## Examples

### Trendline with gradient area fill

Displaying 7-day revenue trend with accessible status tones:

```tsx
<Sparkline
  data={[42000, 48000, 45000, 52000, 61000, 58000, 69000]}
  tone="success"
  label="7-day revenue trajectory, rising"
  height={40}
/>
```

### Table cell line-only variant

Set `area={false}` to draw a minimal stroke-only line without gradient shading:

```tsx
<Sparkline
  data={[12, 18, 15, 22, 28]}
  area={false}
  height={24}
  className="w-24"
/>
```

## Accessibility

`Sparkline` generates accessible SVG elements with screen reader labels.

### Keyboard navigation

Sparklines are non-interactive graphical representations. Keyboard focus naturally moves past them unless wrapped in an interactive element.

### ARIA attributes

- When the `label` prop is provided, the SVG renders `role="img"` with `aria-label={label}`.
- If `label` is omitted, the SVG renders `aria-hidden="true"` so decorative sparklines do not distract screen reader operators when the trend metric is already articulated in text.
