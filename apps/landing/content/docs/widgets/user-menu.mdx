## Import

```tsx
import {
  UserMenu,
  DropdownMenuItem,
  DropdownMenuSeparator,
  type UserMenuProps,
} from '@innostes/ui';
```

## When to use

Use `UserMenu` in primary navigation headers or sidebar footers to provide operator account management and session termination:

- **Top navigation bar end slot**: Quick access to personal settings, company switcher, and sign out in [TopBar](/ui/docs/components/layout/top-bar).
- **Sidebar footer**: Grounding the desktop application layout in [Sidebar](/ui/docs/components/layout/sidebar).
- **Branch switching**: Switching active warehouse division or operational role.

**Do not use UserMenu for:**
- Static non-interactive team rosters — use [AvatarGroup](/ui/docs/components/data-display/avatar) or [EntityList](/ui/docs/widgets/entity-list).
- Standalone button menus without user profile metadata — use [DropdownMenu](/ui/docs/components/overlays/dropdown-menu).
- In-form user selection — use [Select](/ui/docs/components/forms/select).

## Examples

### Basic usage with avatar fallback and menu items

If `avatarSrc` is omitted, `UserMenu` automatically derives initials from the `name` prop:

```tsx
<UserMenu
  name="Priya Sharma"
  subtitle="Northwind Traders · Bengaluru Hub"
  email="priya.sharma@northwind.in"
  avatarSrc="/avatars/priya.jpg"
>
  <DropdownMenuItem onClick={() => router.push('/settings/profile')}>
    Profile & preferences
  </DropdownMenuItem>
  <DropdownMenuItem onClick={() => router.push('/settings/security')}>
    Security & 2FA
  </DropdownMenuItem>
  <DropdownMenuSeparator />
  <DropdownMenuItem variant="destructive" onClick={handleSignOut}>
    Sign out
  </DropdownMenuItem>
</UserMenu>
```

### In sidebar footer

Placing `UserMenu` at the bottom of the application sidebar:

```tsx
<SidebarFooter>
  <UserMenu
    name="Ramesh Kumar"
    subtitle="Logistics Manager"
    email="ramesh.k@northwind.in"
  >
    <DropdownMenuItem>Switch depot</DropdownMenuItem>
    <DropdownMenuSeparator />
    <DropdownMenuItem variant="destructive">Sign out</DropdownMenuItem>
  </UserMenu>
</SidebarFooter>
```

## Accessibility

`UserMenu` is built on Base UI Menu primitives (`@base-ui/react/menu`).

### Keyboard navigation

<KeyboardTable
  entries={[
    { key: 'Enter / Space / DownArrow', action: 'Opens the user account menu and focuses the first item.' },
    { key: 'DownArrow / UpArrow', action: 'Cycles focus between account menu items.' },
    { key: 'Enter / Space', action: 'Activates the focused menu item and dismisses the menu.' },
    { key: 'Escape', action: 'Dismisses the menu and restores focus to the user menu trigger button.' },
  ]}
/>

### ARIA attributes

- The trigger button receives `aria-haspopup="menu"`, `aria-expanded="true | false"`, and an accessible name incorporating the user's name.
- The dropdown container has `role="menu"`.
- Action items have `role="menuitem"`.
