## Import

```tsx
import {
  WidgetCard,
  type WidgetCardProps,
  type WidgetCardViewAll,
} from '@innostes/ui';
```

## When to use

Use `WidgetCard` as the outer container for every component or visualization placed on an administrative dashboard:

- **Asynchronous data widgets**: Housing lists, charts, and metrics fetching from backend APIs.
- **Task queues and alerts**: Presenting pending approval lists with real-time count badges.
- **Embedded tabular summaries**: Presenting top vendors or recent invoices.

**Do not use WidgetCard for:**
- Standard static article cards — use [Card](/ui/docs/components/data-display/card).
- In-form field groups — use [FormSection](/ui/docs/components/layout/form-layout).
- Slide-over inspection drawers — use [Sheet](/ui/docs/components/overlays/sheet).

## Examples

### Complete async lifecycle states

Wrap any content to provide consistent loading, error with retry, and empty state handling:

```tsx
'use client';

import { WidgetCard, ActionList, PeriodSelect } from '@innostes/ui';

export function PendingApprovalsWidget() {
  const { data, isLoading, error, refetch } = usePendingApprovals();

  return (
    <WidgetCard
      title="Pending authorizations"
      description="Purchase orders and credit notes awaiting review"
      count={data?.length}
      countTone="primary"
      viewAll={{ href: '/approvals', label: 'View all authorizations' }}
      actions={<PeriodSelect />}
      loading={isLoading}
      loadingRows={4}
      error={error ? 'Unable to load pending approvals from server.' : undefined}
      onRetry={refetch}
      empty={data?.length === 0}
      emptyState="All procurement authorizations have been cleared."
    >
      <ActionList items={data ?? []} divided />
    </WidgetCard>
  );
}
```

### Full-bleed content with padding="none"

Set `padding="none"` when embedding tables, charts, or maps so their edges align cleanly with the card boundaries:

```tsx
<WidgetCard
  title="Recent consignments"
  padding="none"
  viewAll={{ href: '/logistics/consignments' }}
>
  <Table>{/* Full-bleed table */}</Table>
</WidgetCard>
```

## Accessibility

`WidgetCard` renders semantic HTML5 `<section>` landmarks.

### Keyboard navigation

<KeyboardTable
  entries={[
    { key: 'Tab', action: 'Moves focus into the card, cycling through header actions, view-all links, and body controls.' },
  ]}
/>

### ARIA attributes

- The container renders as a `<section>` labelled by its heading via `aria-labelledby`, allowing screen reader operators to jump between dashboard widgets using standard landmark shortcuts.
- Loading states use `aria-busy="true"` and accessible skeleton elements.
- Error states render with `role="alert"` so network failures are announced promptly.
