## Import

```tsx
import { NotificationBell, NotificationList, NotificationItem } from '@innostes/ui';
```

## Usage

The `NotificationBell` is primarily used in the top bar. It wraps a trigger and a popover containing a `NotificationList`.

It automatically calculates the unread count based on the `items` provided (items where `read` is falsy or `undefined`), or you can explicitly provide an `unreadCount`.

```tsx
function TopNavigation() {
  const notifications: NotificationItem[] = [
    {
      id: '1',
      title: 'New message from Sarah',
      description: 'Can we review the latest designs?',
      time: new Date(),
      icon: <MessageSquareIcon />,
      tone: 'primary',
      read: false,
    },
    // ...
  ];

  return (
    <NotificationBell
      items={notifications}
      onMarkAllRead={() => markAllRead()}
      viewAll={{ href: '/notifications' }}
    />
  );
}
```

### Notification List

If you need to render the list of notifications outside of the bell popover (for example, on a dedicated full-page notifications view or inside a widget card), you can use the `NotificationList` component directly.

```tsx
<NotificationList
  items={notifications}
  onItemClick={(item) => markRead(item.id)}
/>
```
