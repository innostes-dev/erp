# Versioning and support

The `@innostes/ui` package follows Semantic Versioning (SemVer 2.0.0). Version numbers adhere to the `MAJOR.MINOR.PATCH` structure, providing predictable upgrade paths for Northwind Traders Pvt Ltd's engineering teams.

## Release cadence

- **Patch releases** (`0.1.x`): Backwards-compatible bug fixes, security remediations, and performance improvements.
- **Minor releases** (`0.x.0`): Backwards-compatible feature additions, new components, and deprecation notices.
- **Major releases** (`x.0.0`): Breaking changes, major architectural migrations, or minimum React runtime requirement upgrades.

## Supported environments

The library supports modern evergreen desktop and mobile browsers:

- Chromium (Chrome, Edge, Opera) latest 2 major versions.
- Mozilla Firefox latest 2 major versions.
- Apple Safari latest 2 major versions.
- Node.js LTS versions (v20, v22) for SSR and build tooling.
