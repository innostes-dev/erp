# Resources

Reference documentation, architectural conventions, contribution standards, and release governance for `@innostes/ui`. These resources guide engineers and contributors in maintaining code quality, version compatibility, and secure development practices.

## Available resources

- **[Conventions](/ui/docs/resources/conventions)**: Core design principles, component composition rules, event signatures, and styling models.
- **[Changelog](/ui/docs/resources/changelog)**: Chronological release notes tracking new components, enhancements, bug fixes, and deprecations.
- **[Versioning and support](/ui/docs/resources/versioning)**: Semantic versioning guarantees, browser compatibility matrix, and LTS support windows.
- **[Migration guides](/ui/docs/resources/migration)**: Step-by-step upgrade instructions for major library releases and breaking changes.
- **[Contributing](/ui/docs/resources/contributing)**: Development workflow, local testing procedures, and submission standards.
- **[Security](/ui/docs/resources/security)**: Vulnerability reporting protocols, dependency audit policies, and security advisories.
- **[FAQ](/ui/docs/resources/faq)**: Frequently asked questions regarding framework integration, bundle size, and styling overrides.
