# Resources

Reference documentation, architectural conventions, contribution standards, and release governance for `@innostes/ui`. These resources guide engineers and contributors in maintaining code quality, version compatibility, and secure development practices.

## Available resources

- **Conventions**: Core design principles, component composition rules, event signatures, and styling models.
- **Changelog**: Detailed release notes tracking new components, enhancements, bug fixes, and deprecations.
- **Versioning and support**: Semantic versioning guarantees, browser compatibility matrix, and LTS support windows.
- **Migration guides**: Step-by-step upgrade instructions for major library releases and breaking changes.
- **Contributing**: Development workflow, local testing procedures, and submission standards.
- **Security**: Vulnerability reporting protocols, dependency audit policies, and security advisories.
- **FAQ**: Frequently asked questions regarding framework integration, bundle size, and styling overrides.
