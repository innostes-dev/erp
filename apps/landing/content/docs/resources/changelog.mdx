# Changelog

All notable changes to the `@innostes/ui` package are documented chronologically in accordance with Keep a Changelog principles. Every release adheres strictly to Semantic Versioning.

## Version 0.1.0

### Added

- Hardened 19 action and form primitives with Base UI integration and accessible labelling tokens.
- Accessible ARIA live regions and progress meter percentage normalization across feedback components.
- Overlay primitives including `Dialog`, `Sheet`, `Popover`, `Tooltip`, and `AlertDialog` with logical RTL positioning.
- Enterprise widgets: `PermissionMatrix`, `KanbanBoard`, `MetricCard`, `WidgetCard`, and `Sparkline`.
- Cartesian and donut chart visualisations built on Recharts with semantic token support.
- Documentation site enhancements: dynamic props playground, interactive category overviews, and LLM text exports.
