## Import

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionPanel,
} from '@innostes/ui';
```

## When to use

Use `Accordion` to organize progressive disclosure content in vertically constrained spaces:

- **Frequently asked questions (FAQs)**: Compliance and GST tax invoice questions.
- **Grouped settings**: Collapsible sections for billing preferences, notifications, and permissions.
- **Detailed record audit logs**: Expanding historical revisions on vendor profiles.

**Do not use Accordion for:**
- Primary application navigation across distinct URLs — use [Tabs](/ui/docs/components/navigation/tabs) or [Sidebar](/ui/docs/components/layout/sidebar).
- A single isolated disclosure box like "Advanced options" — use [Collapsible](/ui/docs/components/navigation/collapsible).
- Sequential multi-stage onboarding flows — use [Stepper](/ui/docs/components/navigation/stepper).

## Examples

### Basic usage with default open item

An accordion for enterprise procurement terms:

```tsx
<Accordion defaultValue={['gst-compliance']}>
  <AccordionItem value="gst-compliance">
    <AccordionTrigger>GST compliance and invoicing</AccordionTrigger>
    <AccordionPanel>
      Northwind Traders generates digital e-invoices with valid IRN numbers and dynamic QR codes for B2B transactions under Indian GST laws.
    </AccordionPanel>
  </AccordionItem>
  <AccordionItem value="delivery-terms">
    <AccordionTrigger>Delivery schedule and transit insurance</AccordionTrigger>
    <AccordionPanel>
      Consignments dispatched from our Bengaluru hub include full transit insurance under All Risks Marine clauses.
    </AccordionPanel>
  </AccordionItem>
</Accordion>
```

### Multiple expanded sections

Set `multiple` to allow users to inspect multiple sections simultaneously:

```tsx
<Accordion multiple defaultValue={['summary', 'tax']}>
  <AccordionItem value="summary">
    <AccordionTrigger>Order summary</AccordionTrigger>
    <AccordionPanel>PO-2026-081 created for ₹89,400 with 18% integrated GST.</AccordionPanel>
  </AccordionItem>
  <AccordionItem value="tax">
    <AccordionTrigger>Tax breakdown</AccordionTrigger>
    <AccordionPanel>CGST (9%): ₹6,818.64 | SGST (9%): ₹6,818.64</AccordionPanel>
  </AccordionItem>
</Accordion>
```

## Accessibility

`Accordion` is built on Base UI Accordion primitives (`@base-ui/react/accordion`).

### Keyboard navigation

<KeyboardTable
  entries={[
    { key: 'Enter / Space', action: 'Expands or collapses the focused accordion trigger.' },
    { key: 'DownArrow', action: 'Moves focus to the next accordion header trigger.' },
    { key: 'UpArrow', action: 'Moves focus to the previous accordion header trigger.' },
    { key: 'Home', action: 'Moves focus to the first accordion header trigger.' },
    { key: 'End', action: 'Moves focus to the last accordion header trigger.' },
  ]}
/>

### ARIA attributes

- Each `AccordionTrigger` is rendered as an accessible button with `aria-expanded="true | false"` and `aria-controls` pointing to its panel id.
- Each `AccordionPanel` receives `role="region"` and `aria-labelledby` referencing its trigger.

## Guidelines

<DoDont
  do={{
    description: 'Use clear, descriptive trigger headers that indicate the contents hidden inside.',
    code: `<AccordionTrigger>Statutory GST information</AccordionTrigger>`,
  }}
  dont={{
    description: 'Do not use vague trigger text that leaves users guessing what each panel contains.',
    code: `<AccordionTrigger>More info</AccordionTrigger>`,
  }}
/>

<DoDont
  do={{
    description: 'Use multiple when users need to cross-reference details across multiple panels at once.',
    code: `<Accordion multiple defaultValue={['items', 'taxes']} />`,
  }}
  dont={{
    description: 'Do not force single expansion when users must frequently compare data across sections.',
    code: `<Accordion defaultValue={['items']} />`,
  }}
/>
