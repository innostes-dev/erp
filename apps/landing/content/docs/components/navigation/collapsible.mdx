## Import

```tsx
import { Collapsible, CollapsibleTrigger, CollapsiblePanel } from '@innostes/ui';
```

## Usage

The trigger gets `data-panel-open` while open; use it to rotate an icon
(`group-data-panel-open:rotate-180`), as in the demo.
