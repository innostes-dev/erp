## Import

```tsx
import {
  Collapsible,
  CollapsibleTrigger,
  CollapsiblePanel,
} from '@innostes/ui';
```

## When to use

Use `Collapsible` for isolated disclosures where a user might optionally need extra settings or secondary details:

- **Advanced form fields**: E-way bill vehicle numbers, GST exemption certificates, or dispatch notes.
- **Filter drawers and panels**: Expanding extra facet filters on inventory search.
- **Code snippet disclosures**: Showing generated JSON payloads or webhook logs.

**Do not use Collapsible for:**
- Stacked groups of mutually exclusive sections — use [Accordion](/ui/docs/components/navigation/accordion).
- Top-level page tab switches — use [Tabs](/ui/docs/components/navigation/tabs).
- Complex overlay modals — use [Dialog](/ui/docs/components/overlays/dialog).

## Examples

### Secondary form options

Hiding advanced tax and compliance fields until requested by the procurement agent:

```tsx
<Collapsible>
  <div className="flex items-center justify-between border-b pb-2">
    <h4 className="text-sm font-semibold">Consignment details</h4>
    <CollapsibleTrigger
      render={
        <Button variant="ghost" size="sm" className="group">
          Advanced options
          <ChevronDownIcon className="size-4 transition-transform duration-200 group-data-panel-open:rotate-180" />
        </Button>
      }
    />
  </div>
  <CollapsiblePanel className="space-y-4 pt-4">
    <Field name="vehicleNo">
      <FieldLabel>E-Way bill vehicle number</FieldLabel>
      <Input placeholder="KA-01-AB-1234" />
    </Field>
    <Field name="transporterId">
      <FieldLabel>Transporter GSTIN / ID</FieldLabel>
      <Input placeholder="29AAAAA0000A1Z5" />
    </Field>
  </CollapsiblePanel>
</Collapsible>
```

### Controlled open state

Manage the disclosure programmatically from external component state:

```tsx
const [isOpen, setIsOpen] = useState(false);

<Collapsible open={isOpen} onOpenChange={setIsOpen}>
  <div className="flex gap-2">
    <Button onClick={() => setIsOpen((prev) => !prev)}>
      {isOpen ? 'Hide raw audit logs' : 'View raw audit logs'}
    </Button>
  </div>
  <CollapsiblePanel className="mt-4 rounded bg-muted p-4 font-mono text-xs">
    {JSON.stringify(auditRecord, null, 2)}
  </CollapsiblePanel>
</Collapsible>
```

## Accessibility

`Collapsible` is built on Base UI Collapsible primitives (`@base-ui/react/collapsible`).

### Keyboard navigation

### ARIA attributes

- The `CollapsibleTrigger` receives `aria-expanded="true | false"` and `aria-controls` referencing the panel id.
- The trigger button receives `data-panel-open` when the panel is visible, enabling Tailwind group-hover or sibling animations.
- The `CollapsiblePanel` receives `hidden` when closed, ensuring screen readers do not read collapsed content.
