# Navigation

Navigation components establish information architecture and wayfinding across Northwind Traders Pvt Ltd's ERP modules. They provide predictable, keyboard-accessible paths through complex inventory hierarchies, multi-stage procurement flows, and paginated records.

## Usage guidelines

- **Wayfinding hierarchy**: Combine `Breadcrumb` for relational hierarchy, `Tabs` for alternate views of an entity, and `Stepper` for sequential multi-step wizards.
- **Keyboard navigation**: Tab strips support Left/Right arrow keys for roving focus. Accordions support Up/Down arrow navigation.
- **RTL awareness**: All navigation elements honour document directionality (`dir="rtl"`) with logical margin and icon rotation.
