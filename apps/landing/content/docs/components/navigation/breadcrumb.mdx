## Import

```tsx
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbPage,
  BreadcrumbSeparator,
  BreadcrumbEllipsis,
} from '@innostes/ui';
```

## With your router

`BreadcrumbLink` renders an `<a>`. Pass `render` to use your router's link:

```tsx
import Link from 'next/link';

<BreadcrumbLink render={<Link href="/orders" />}>Orders</BreadcrumbLink>
```

## Accessibility

- A `<nav aria-label="Breadcrumb">` containing an ordered list.
- The current page has `aria-current="page"`; separators are hidden from screen readers.
