## Import

```tsx
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbPage,
  BreadcrumbSeparator,
  BreadcrumbEllipsis,
} from '@innostes/ui';
```

## When to use

Use `Breadcrumb` to establish hierarchical context within deep enterprise applications:

- **Multi-tiered resource views**: `Purchasing > Vendors > Bengaluru Spices > Orders > PO-2026-081`.
- **Complex nested configuration**: `Settings > Enterprise > Billing & Tax > GSTIN Profiles`.
- **Catalogue and warehousing**: `Inventory > Raw Materials > Spices & Seasonings > Cardamom Grade A`.

**Do not use Breadcrumb for:**
- Flat top-level navigation — use [TopBar](/ui/docs/components/layout/top-bar) or [AppRail](/ui/docs/components/layout/app-rail).
- Linear multi-step sequential tasks or wizards — use [Stepper](/ui/docs/components/navigation/stepper).
- History-based browser back/forward pagination.

## Examples

### Integration with Next.js router

`BreadcrumbLink` renders a semantic anchor tag (`<a>`). Use the `render` prop to pass Next.js `Link` for client-side transitions:

```tsx
import Link from 'next/link';

<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink render={<Link href="/" />}>Dashboard</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink render={<Link href="/purchases" />}>Purchases</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>PO-2026-081</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

### Deep hierarchies with ellipsis

When path depths exceed four levels, collapse middle steps using `BreadcrumbEllipsis`:

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/inventory">Inventory</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbEllipsis />
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="/inventory/warehouses/blr-01">Bengaluru Central Hub</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Aisle 4 Bay 12</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## Accessibility

`Breadcrumb` renders semantic HTML5 navigation landmarks.

### ARIA attributes

- The container element is a `<nav aria-label="Breadcrumb">`.
- The list uses `<ol>` and `<li>` elements, giving screen readers an accurate count of total path levels.
- The current page indicator uses `<BreadcrumbPage>` which marks the element with `aria-current="page"`.
- Separators render with `aria-hidden="true"` so assistive technologies ignore decorative divider symbols.

## Guidelines

  do={{
    description: 'Mark the final item with BreadcrumbPage, rendering text rather than a redundant self-link.',

  dont={{

  }}
/>
