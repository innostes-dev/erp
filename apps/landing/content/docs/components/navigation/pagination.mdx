## Import

```tsx
import { Pagination, getPaginationRange, type PaginationProps } from '@innostes/ui';
```

## When to use

Use `Pagination` when dividing large datasets into discrete pages:

- **Enterprise data tables**: Navigating through thousands of purchase orders, stock items, or ledger entries.
- **Search result listings**: Paginated inventory queries or customer catalogues.
- **Audit logs**: Stepping through historical system logs.

**Do not use Pagination for:**
- Infinite feed streams or chat conversations.
- Multi-step wizards or checkout funnels — use [Stepper](/ui/docs/components/navigation/stepper).
- Switching between distinct functional sections on a single screen — use [Tabs](/ui/docs/components/navigation/tabs).

## Examples

### Basic controlled pagination

Managing the current page in component state:

```tsx
const [page, setPage] = useState(1);
const totalRecords = 480;
const pageSize = 20;
const pageCount = Math.ceil(totalRecords / pageSize);

<Pagination
  page={page}
  pageCount={pageCount}
  onPageChange={(nextPage) => {
    setPage(nextPage);
    fetchOrders({ page: nextPage, pageSize });
  }}
/>
```

### Boundary and sibling counts

Adjust `boundaryCount` (pages anchored at the start and end) and `siblingCount` (pages surrounding the current page):

```tsx
<Pagination
  page={page}
  pageCount={50}
  siblingCount={2}
  boundaryCount={2}
  onPageChange={setPage}
/>
```

### Server-side range helper (`getPaginationRange`)

`getPaginationRange` calculates the page numbers and ellipsis positions without importing React, making it ideal for Server Components or custom pagination renderers:

```ts
import { getPaginationRange } from '@innostes/ui';

const range = getPaginationRange({
  page: 6,
  pageCount: 20,
  siblingCount: 1,
  boundaryCount: 1,
});
// Output: [1, 'ellipsis-start', 5, 6, 7, 'ellipsis-end', 20]
```

## Accessibility

`Pagination` implements the WAI-ARIA Navigation pattern.

### Keyboard navigation

<KeyboardTable
  entries={[
    { key: 'Tab', action: 'Moves focus sequentially between Previous, page number buttons, and Next.' },
    { key: 'Enter / Space', action: 'Activates the focused page number or directional button.' },
  ]}
/>

### ARIA attributes

- The container is rendered as `<nav aria-label="Pagination">`.
- The active page button has `aria-current="page"`.
- Previous and Next buttons receive descriptive `aria-label` text via `labels.previous` and `labels.next`.
- Ellipsis spans receive `aria-hidden="true"`.
