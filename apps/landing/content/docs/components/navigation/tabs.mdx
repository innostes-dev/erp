## Import

```tsx
import { Tabs, TabsList, TabsTab, TabsPanel } from '@innostes/ui';
```

## When to use

Use `Tabs` to present parallel views or alternate perspectives of the same core entity:

- **Entity detail views**: Overview, Line Items, Documents, Audit Trail, and Invoices.
- **Settings panels**: Account, Security, Billing, and Team Members.
- **Reporting ranges**: Compact pill switches for Day, Week, Month, Quarter.

**Do not use Tabs for:**
- Sequential step-by-step wizards where order is strictly enforced — use [Stepper](/ui/docs/components/navigation/stepper).
- Deep ancestral tree hierarchies — use [Breadcrumb](/ui/docs/components/navigation/breadcrumb).
- Primary multi-page top-level navigation — use [AppRail](/ui/docs/components/layout/app-rail) or [Sidebar](/ui/docs/components/layout/sidebar).

## Examples

### Underline variant for page sections

The standard underline tab strip with an animated active highlight bar:

```tsx
<Tabs defaultValue="overview" variant="underline">
  <TabsList>
    <TabsTab value="overview">Order overview</TabsTab>
    <TabsTab value="items">Line items (14)</TabsTab>
    <TabsTab value="shipping">Logistics & E-Way</TabsTab>
  </TabsList>
  <TabsPanel value="overview">
    <div className="py-4">Purchase order details for Bengaluru Spices.</div>
  </TabsPanel>
  <TabsPanel value="items">
    <div className="py-4">Items table with HSN breakdown.</div>
  </TabsPanel>
  <TabsPanel value="shipping">
    <div className="py-4">Tracking consignment via Blue Dart Express.</div>
  </TabsPanel>
</Tabs>
```

### Pills variant for compact metric cards

Use `variant="pills"` inside toolbars or card headers:

```tsx
<Tabs defaultValue="quarterly" variant="pills">
  <TabsList>
    <TabsTab value="monthly">Monthly</TabsTab>
    <TabsTab value="quarterly">Quarterly</TabsTab>
    <TabsTab value="annual">FY 2025-26</TabsTab>
  </TabsList>
  <TabsPanel value="monthly">{/* Monthly revenue chart */}</TabsPanel>
  <TabsPanel value="quarterly">{/* Quarterly tax review */}</TabsPanel>
  <TabsPanel value="annual">{/* Annual compliance statement */}</TabsPanel>
</Tabs>
```

### Vertical orientation for settings sidebars

Stack tabs vertically for wide screen settings dialogs or configuration layouts:

```tsx
<Tabs defaultValue="gst" orientation="vertical" className="w-full">
  <TabsList className="w-64 border-r pr-4">
    <TabsTab value="profile">Company profile</TabsTab>
    <TabsTab value="gst">GSTIN & Taxes</TabsTab>
    <TabsTab value="bank">Bank accounts</TabsTab>
  </TabsList>
  <div className="flex-1 pl-6">
    <TabsPanel value="profile">Northwind Traders Pvt Ltd</TabsPanel>
    <TabsPanel value="gst">State: Karnataka (29), GSTIN: 29ABCDE1234F1Z5</TabsPanel>
    <TabsPanel value="bank">HDFC Bank, Bengaluru Koramangala Branch</TabsPanel>
  </div>
</Tabs>
```

## Accessibility

`Tabs` is built on Base UI Tabs primitives (`@base-ui/react/tabs`).

### Keyboard navigation

  ]}
/>

### ARIA attributes

- The tab strip has `role="tablist"`.
- Each tab trigger has `role="tab"` with `aria-selected="true | false"` and `aria-controls` pointing to its corresponding panel.
- Each content panel has `role="tabpanel"` and `aria-labelledby` referencing its tab trigger.
