## Import

```tsx
import { CommandPalette, type CommandGroup, type CommandItem } from '@innostes/ui';
```

## When to use

Use `CommandPalette` as the central keyboard-driven interface for enterprise applications:

- **Global navigation**: Jumping across ERP modules (Purchase Orders, Tax Invoices, General Ledger, Vendors).
- **Administrative actions**: Creating records, exporting reports, or toggling developer modes.
- **Search and recent items**: Finding recently edited contracts or frequently accessed supplier files.

**Do not use CommandPalette for:**
- Standard dropdown action lists on a single row — use [DropdownMenu](/ui/docs/components/overlays/dropdown-menu).
- Form field selection from a predefined enumeration — use [Select](/ui/docs/components/forms/select).
- Complex workflows requiring multiple user inputs or validation — use [Dialog](/ui/docs/components/overlays/dialog).

## Examples

### Grouping and shortcuts

Organise commands into logical categories such as Pages, Recent items, and Actions:

```tsx
const groups: CommandGroup[] = [
  {
    heading: 'Recent items',
    items: [
      {
        id: 'po-2026-081',
        label: 'PO-2026-081 · Bengaluru Spices',
        description: 'Updated 10 minutes ago · ₹89,400',
        onSelect: () => router.push('/purchases/PO-2026-081'),
      },
    ],
  },
  {
    heading: 'Quick actions',
    items: [
      {
        id: 'new-po',
        label: 'Create purchase order',
        shortcut: 'C P',
        keywords: ['procurement', 'buy', 'vendor'],
        onSelect: () => router.push('/purchases/new'),
      },
      {
        id: 'export-gst',
        label: 'Generate GST return (GSTR-1)',
        shortcut: 'G R',
        keywords: ['tax', 'finance', 'invoices'],
        onSelect: openGstExportDialog,
      },
    ],
  },
];

<CommandPalette groups={groups} />
```

### Global shortcut configuration

By default, the palette listens for `Ctrl + K` or `⌘ + K`. Customise the shortcut key with `hotkey="j"` or pass `hotkey={null}` to disable the automatic global listener and control visibility manually:

```tsx
// Custom hotkey ⌘J
<CommandPalette hotkey="j" groups={groups} />

// Manual trigger from top navigation bar button
const [open, setOpen] = useState(false);

<Button variant="outline" onClick={() => setOpen(true)}>
  Search commands (⌘K)
</Button>
<CommandPalette
  open={open}
  onOpenChange={setOpen}
  hotkey="k"
  groups={groups}
/>
```

### Dynamic search and recent items

Combine static navigation items with dynamically updated recent items stored in local state or browser storage:

```tsx
'use client';

import { useState, useEffect } from 'react';
import { CommandPalette, type CommandGroup } from '@innostes/ui';

export function GlobalSearch() {
  const [recentIds, setRecentIds] = useState<string[]>([]);

  useEffect(() => {
    const saved = localStorage.getItem('northwind_recent_records');
    if (saved) setRecentIds(JSON.parse(saved));
  }, []);

  const groups: CommandGroup[] = [
    {
      heading: 'Recent records',
      items: recentIds.map((id) => ({
        id,
        label: `Record ${id}`,
        onSelect: () => navigateToRecord(id),
      })),
    },
    {
      heading: 'Modules',
      items: [
        { id: 'inventory', label: 'Inventory & Warehousing', onSelect: () => router.push('/inventory') },
        { id: 'billing', label: 'Invoices & E-Way Bills', onSelect: () => router.push('/billing') },
      ],
    },
  ];

  return <CommandPalette groups={groups} />;
}
```

## Accessibility

`CommandPalette` implements the WAI-ARIA Combobox pattern anchored within a modal dialog (`@base-ui/react/dialog`).

### ARIA attributes

- The search input element uses `role="combobox"`, `aria-expanded="true"`, and `aria-autocomplete="list"`.
- `aria-activedescendant` tracks the focused option without removing keyboard focus from the search input, allowing continuous typing while navigating.
- The results list uses `role="listbox"`, with individual entries having `role="option"` and `aria-selected="true | false"`.
- Groups are marked with `role="group"` and reference their group headings via `aria-labelledby`.
