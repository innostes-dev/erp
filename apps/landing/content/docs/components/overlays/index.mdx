# Overlays

Overlays present supplementary workflows, context-sensitive details, and decision prompts above the primary page canvas. They enable Northwind Traders operators to complete focused sub-tasks without navigating away from their active workspace.

## Usage guidelines

- **Modality**: Use `Dialog` or `AlertDialog` when operator confirmation or focused data entry is mandatory before proceeding. Use `Sheet` for wide inspection panels and edit drawers.
- **Focus management**: Overlays automatically trap focus when opened, restore focus to the triggering element upon dismissal, and close on Escape key navigation.
- **Progressive disclosure**: Reserve `Tooltip` for non-essential keyboard hints and iconography descriptions. Use `Popover` for rich interactive menus and filters.
