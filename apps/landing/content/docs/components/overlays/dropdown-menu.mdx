## When to use

Use `DropdownMenu` when presenting a compact list of distinct commands, navigations, or configuration toggles from a single trigger:

- **Data table row actions**: Consolidating View, Edit, Duplicate, Export, and Delete under a single action button.
- **Header account menus**: Switching user profiles, navigating to billing, or initiating sign-out.
- **View customisation menus**: Toggling visible columns or grouping dimensions.

**Do not use DropdownMenu for:**
- Selectable form values that update an input field — use [Select](/ui/docs/components/forms/select).
- Arbitrary interactive form fields or multi-step controls — use [Popover](/ui/docs/components/overlays/popover).
- Direct right-click pointer menus — use [ContextMenu](/ui/docs/components/overlays/context-menu).

## Examples

### Row actions in enterprise tables

The standard ERP pattern: a `⋯` action button per purchase order row:

```tsx
<DropdownMenu>
  <DropdownMenuTrigger
    render={
      <Button
        variant="ghost"
        size="sm"
        iconOnly
        aria-label="Actions for PO-2026-081"
      />
    }
  >
    <MoreHorizontalIcon />
  </DropdownMenuTrigger>
  <DropdownMenuContent align="end">
    <DropdownMenuItem onClick={() => router.push('/purchases/PO-2026-081')}>
      View order
      <DropdownMenuShortcut>⌘O</DropdownMenuShortcut>
    </DropdownMenuItem>
    <DropdownMenuItem onClick={duplicateOrder}>
      Duplicate line
    </DropdownMenuItem>
    <DropdownMenuSeparator />
    <DropdownMenuItem variant="destructive" onClick={openCancelDialog}>
      Cancel PO
    </DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

### Submenus for hierarchical actions

Nested submenus allow deep hierarchies without cluttering the top-level menu:

```tsx
<DropdownMenu>
  <DropdownMenuTrigger render={<Button variant="outline" />}>
    Export options
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem onClick={exportPdf}>PDF Document</DropdownMenuItem>
    <DropdownMenuSub>
      <DropdownMenuSubTrigger>Spreadsheet</DropdownMenuSubTrigger>
      <DropdownMenuSubContent>
        <DropdownMenuItem onClick={exportCsv}>CSV (UTF-8)</DropdownMenuItem>
        <DropdownMenuItem onClick={exportXlsx}>Excel Workbook (.xlsx)</DropdownMenuItem>
      </DropdownMenuSubContent>
    </DropdownMenuSub>
  </DropdownMenuContent>
</DropdownMenu>
```

### Checkbox and radio items

Selectable items preserve toggle state for filter criteria and view modes:

```tsx
<DropdownMenu>
  <DropdownMenuTrigger render={<Button variant="outline" />}>
    View settings
  </DropdownMenuTrigger>
  <DropdownMenuContent className="w-56">
    <DropdownMenuGroup>
      <DropdownMenuGroupLabel>Columns</DropdownMenuGroupLabel>
      <DropdownMenuCheckboxItem
        checked={showGst}
        onCheckedChange={setShowGst}
      >
        Show GST breakdown
      </DropdownMenuCheckboxItem>
      <DropdownMenuCheckboxItem
        checked={showHsn}
        onCheckedChange={setShowHsn}
      >
        Show HSN codes
      </DropdownMenuCheckboxItem>
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuGroup>
      <DropdownMenuGroupLabel>Density</DropdownMenuGroupLabel>
      <DropdownMenuRadioGroup value={density} onValueChange={setDensity}>
        <DropdownMenuRadioItem value="compact">Compact</DropdownMenuRadioItem>
        <DropdownMenuRadioItem value="comfortable">Comfortable</DropdownMenuRadioItem>
      </DropdownMenuRadioGroup>
    </DropdownMenuGroup>
  </DropdownMenuContent>
</DropdownMenu>
```

## Accessibility

`DropdownMenu` is built on Base UI Menu primitives (`@base-ui/react/menu`).

### Keyboard navigation

    { key: 'Escape', action: 'Dismisses the open menu and restores focus to the trigger button.' },

/>

### ARIA attributes

- The trigger element receives `aria-haspopup="menu"` and dynamic `aria-expanded`.
- The menu popup container has `role="menu"`.
- Menu items receive `role="menuitem"`, `role="menuitemcheckbox"`, or `role="menuitemradio"` with `aria-checked` states.
- Disabled items receive `aria-disabled="true"`.
