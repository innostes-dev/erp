## Import

```tsx
import {
  Tooltip,
  TooltipTrigger,
  TooltipContent,
  TooltipProvider,
} from '@innostes/ui';
```

## When to use

Use `Tooltip` to clarify icon-only buttons or provide supplementary keyboard shortcut cues without cluttering the main user interface:

- **Icon-only toolbar controls**: Editing tools, table row shortcuts, or status indicators.
- **Truncated text hint**: Revealing full text when enterprise table cells truncate customer or vendor names.
- **Keyboard shortcut reminders**: Showing `⌘S` or `⌘K` alongside standard actions.

**Do not use Tooltip for:**
- Interactive content such as links or forms — use [Popover](/ui/docs/components/overlays/popover).
- Essential instructional information that touch-device users must read to complete a task.
- Lengthy multi-paragraph explanations — use an inline helper text or [Alert](/ui/docs/components/feedback/alert).

## Examples

### Basic usage

Providing an accessible name for an icon button:

```tsx
<Tooltip>
  <TooltipTrigger
    render={<Button iconOnly variant="ghost" aria-label="Archive purchase order" />}
  >
    <ArchiveIcon />
  </TooltipTrigger>
  <TooltipContent>Archive purchase order</TooltipContent>
</Tooltip>
```

### Shared delay with TooltipProvider

Wrap your application root or toolbar in `TooltipProvider`. After the initial delay timer fires for the first tooltip, hovering over subsequent triggers displays their tooltips immediately without waiting:

```tsx
<TooltipProvider delay={300}>
  <div className="flex gap-1 rounded-md border p-1">
    <Tooltip>
      <TooltipTrigger render={<Button iconOnly variant="ghost" aria-label="Bold text" />}>
        <BoldIcon />
      </TooltipTrigger>
      <TooltipContent>Bold (⌘B)</TooltipContent>
    </Tooltip>
    <Tooltip>
      <TooltipTrigger render={<Button iconOnly variant="ghost" aria-label="Italic text" />}>
        <ItalicIcon />
      </TooltipTrigger>
      <TooltipContent>Italic (⌘I)</TooltipContent>
    </Tooltip>
  </div>
</TooltipProvider>
```

### Position and alignment

Tooltips can position along `top`, `bottom`, `left`, or `right` margins, and will flip dynamically to stay within the visible screen area:

```tsx
<TooltipContent side="bottom" align="center" sideOffset={6}>
  Export GST report (CSV)
</TooltipContent>
```

## Accessibility

`Tooltip` is built on Base UI Tooltip primitives (`@base-ui/react/tooltip`).

### ARIA attributes

- For icon-only buttons, always ensure the trigger element possesses an `aria-label`.
- `Tooltip` automatically associates the tooltip content with the trigger via `aria-describedby` when opened.
- Tooltips are not reachable on pure touch screen devices without focus emulation; essential business instructions must never be sequestered in a tooltip.
