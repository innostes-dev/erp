## When to use

Use `ContextMenu` to provide power-user contextual shortcuts directly where the user clicks or taps:

- **Enterprise data grid rows**: Quick access to edit, copy ID, duplicate, or inspect records.
- **Tree view and file directories**: Renaming, moving, downloading, or archiving documents.
- **Canvas or diagram editors**: Context-specific manipulation of nodes and edges.

**Do not use ContextMenu as the only way to perform an action.** Right-click gestures are invisible, undiscoverable for new users, and difficult to trigger on touch screens. Always provide a primary on-screen button or a [DropdownMenu](/ui/docs/components/overlays/dropdown-menu) alongside it.

## Examples

### Table row contextual actions

Allowing users to right-click an ERP table row for immediate options:

```tsx
<ContextMenu>
  <ContextMenuTrigger className="flex items-center justify-between rounded border p-4">
    <div>
      <div className="font-medium">INV-2026-081 (Bengaluru Spices)</div>
      <div className="text-sm text-muted-foreground">₹89,400 · Tax invoice</div>
    </div>
    <span className="text-xs text-muted-foreground">Right-click for options</span>
  </ContextMenuTrigger>
  <ContextMenuContent>
    <ContextMenuItem onClick={() => router.push('/invoices/INV-2026-081')}>
      View details
      <ContextMenuShortcut>⌘O</ContextMenuShortcut>
    </ContextMenuItem>
    <ContextMenuItem onClick={copyInvoiceNumber}>
      Copy invoice number
      <ContextMenuShortcut>⌘C</ContextMenuShortcut>
    </ContextMenuItem>
    <ContextMenuSeparator />
    <ContextMenuItem variant="destructive" onClick={openVoidDialog}>
      Void invoice
    </ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>
```

### Contextual submenus

Organise deeper secondary actions using nested submenus:

```tsx
<ContextMenu>
  <ContextMenuTrigger className="rounded-lg border border-dashed p-8 text-center text-sm">
    Right-click here to view reporting options
  </ContextMenuTrigger>
  <ContextMenuContent>
    <ContextMenuItem onClick={refreshData}>Refresh data</ContextMenuItem>
    <ContextMenuSub>
      <ContextMenuSubTrigger>Export as</ContextMenuSubTrigger>
      <ContextMenuSubContent>
        <ContextMenuItem onClick={exportXlsx}>Excel spreadsheet (.xlsx)</ContextMenuItem>
        <ContextMenuItem onClick={exportPdf}>PDF summary</ContextMenuItem>
      </ContextMenuSubContent>
    </ContextMenuSub>
  </ContextMenuContent>
</ContextMenu>
```

## Accessibility

`ContextMenu` is built on Base UI Menu primitives (`@base-ui/react/menu`).

### Discovery and touch interfaces

- Right-click is not discoverable through visual scanning alone. Every action exposed in a context menu must also be accessible via a visible UI element (such as a toolbar button or table row action menu).
- Long-press support allows mobile browsers to trigger the context menu, but primary mobile workflows should rely on explicit touch buttons.
