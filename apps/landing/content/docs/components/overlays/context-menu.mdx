## Import

```tsx
import {
  ContextMenu,
  ContextMenuTrigger,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuSeparator,
  ContextMenuShortcut,
  // …and ContextMenuCheckboxItem, ContextMenuRadioGroup, ContextMenuSub, etc.
} from '@innostes/ui';
```

## Usage

Items are the same components as [Dropdown Menu](/ui/docs/components/overlays/dropdown-menu),
exported with `ContextMenu*` names.

<Callout type="warn">
  Right-click is hard to discover and unavailable to some users. Make every action in a context menu
  reachable another way too, e.g. a row actions button.
</Callout>
