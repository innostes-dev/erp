## Import

```tsx
import {
  Popover,
  PopoverTrigger,
  PopoverContent,
  PopoverTitle,
  PopoverDescription,
  PopoverClose,
} from '@innostes/ui';
```

## Usage

`side`, `align` and `sideOffset` on `PopoverContent` position it; it flips automatically when
there's no room. For plain hints, use [Tooltip](/ui/docs/components/overlays/tooltip).

## Accessibility

- The trigger has `aria-expanded`. Focus moves into the popover and returns on close.
- Escape and outside click close it.
