## Import

```tsx
import {
  Sheet,
  SheetTrigger,
  SheetContent,
  SheetHeader,
  SheetTitle,
  SheetDescription,
  SheetBody,
  SheetFooter,
  SheetClose,
} from '@innostes/ui';
```

## Usage

```tsx
<Sheet>
  <SheetTrigger render={<Button variant="outline" />}>Filters</SheetTrigger>
  <SheetContent side="right">
    <SheetHeader>
      <SheetTitle>Filters</SheetTitle>
    </SheetHeader>
    <SheetBody>…</SheetBody>   {/* scrolls when content is long */}
    <SheetFooter>…</SheetFooter>
  </SheetContent>
</Sheet>
```

`side` is `right` (default), `left`, `top` or `bottom`. Left and right flip in right-to-left layouts.

## Accessibility

Same as [Dialog](/ui/docs/components/overlays/dialog): focus is trapped, Escape closes, and the
title labels the panel.
