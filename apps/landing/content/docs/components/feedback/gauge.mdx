## Import

```tsx
import { Gauge, type GaugeProps, type GaugeTone, type GaugeSlot } from '@innostes/ui';
```

## When to use

Use `Gauge` when an executive dashboard requires a circular dial to communicate an operational metric, utilization rate, or SLA compliance score:

- Showing warehouse storage capacity utilization or truck fleet availability.
- Displaying SLA fulfillment percentages or customer satisfaction ratings.
- Visualizing annual budget expenditure versus fiscal limits.

When choosing scalar components:
- Use `Gauge` for prominent, radial visual dials on operational and executive dashboards.
- Use [Meter](/ui/docs/components/feedback/meter) for compact, linear horizontal bars in dense tables or cards.
- Use [Progress](/ui/docs/components/feedback/progress) for active workflows or tasks advancing toward completion.
- Refer to the [Feedback decision guide](/ui/docs/components/feedback#feedback-decision-guide) for full guidance.

## Examples

### Basic radial dial

Provide `value`, `min`, `max`, and a descriptive `label`:

```tsx
import { Gauge } from '@innostes/ui';

export function DispatchGauge() {
  return (
    <Gauge
      value={84}
      max={100}
      label="Daily dispatch target"
      description="840 of 1,000 pallets loaded"
      format={{ style: 'percent' }}
    />
  );
}
```

### Dynamic threshold colouring

Pass a function to `tone` to change the arc colour dynamically as the measured metric enters warning or critical bands:

```tsx
import { Gauge } from '@innostes/ui';

const computeTone = (val: number) => {
  if (val > 90) return 'destructive';
  if (val > 75) return 'warning';
  return 'success';
};

export function StorageGauge() {
  return (
    <Gauge
      value={92}
      max={100}
      label="Cold storage utilization"
      description="Zone B Freezers"
      tone={computeTone}
    />
  );
}
```

### Metric descriptions and sizing

Control the overall dial width using `size` (e.g. `'12rem'` or `200`). Add a secondary `description` under the label:

```tsx
import { Gauge } from '@innostes/ui';

export function SlaComplianceGauge() {
  return (
    <Gauge
      value={99.2}
      max={100}
      size="12rem"
      label="Order delivery SLA"
      description="Last 30 days rolling"
      format={{ style: 'percent', maximumFractionDigits: 1 }}
      tone="success"
    />
  );
}
```

## Accessibility

`Gauge` wraps Base UI Meter primitives (`@base-ui/react/meter`).

### Screen readers and meter semantics

- Renders with `role="meter"` and sets `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`.
- The `label` prop is connected to the meter as its accessible name.
- Percentage calculations are normalized against the span between `min` and `max` so screen readers announce human-readable fractions (e.g., "Daily dispatch target, 84%").
- The SVG arc elements include `aria-hidden="true"`, ensuring assistive technologies rely exclusively on the semantic meter attributes.
