## Import

```tsx
import { Skeleton } from '@innostes/ui';
```

## When to use

Use `Skeleton` to provide a low-contrast visual preview of content geometry while asynchronous data fetches are in flight:

- Mirroring cards, user profiles, or dashboard tiles on initial page load.
- Rendering placeholder rows in [DataTable](/ui/docs/components/data-display/data-table) or lists during search queries.
- Preventing Cumulative Layout Shift (CLS) as images, fonts, and API payloads hydrate into view.

When choosing loading representations:
- Use `Skeleton` when you know the approximate dimensions of the incoming layout structure (cards, tables, lists).
- Use [Spinner](/ui/docs/components/feedback/spinner) inside action buttons or compact controls during quick submission operations (< 1s).
- Use [Progress](/ui/docs/components/feedback/progress) when tracking a background upload or multi-step batch job.

## Examples

### Basic card placeholder

Size `Skeleton` components using standard Tailwind width and height utilities to match the expected content proportions:

```tsx
import { Skeleton } from '@innostes/ui';

export function ProfileCardSkeleton() {
  return (
    <div
      aria-busy="true"
      aria-label="Loading vendor profile"
      className="flex flex-col gap-4 rounded-xl border p-6"
    >
      <div className="flex items-center gap-3">
        <Skeleton className="size-12 rounded-full" />
        <div className="flex flex-1 flex-col gap-2">
          <Skeleton className="h-4 w-1/3" />
          <Skeleton className="h-3 w-1/4" />
        </div>
      </div>
      <Skeleton className="h-20 w-full" />
    </div>
  );
}
```

### Table row skeletons

Render multiple skeleton rows to indicate that a data table is actively fetching its next page:

```tsx
import { Skeleton } from '@innostes/ui';

export function TableLoadingRows() {
  return (
    <div aria-busy="true" className="flex flex-col gap-3">
      {Array.from({ length: 4 }).map((_, i) => (
        <div key={i} className="flex items-center justify-between gap-4 py-2 border-b">
          <Skeleton className="h-4 w-28" />
          <Skeleton className="h-4 w-48" />
          <Skeleton className="h-4 w-16" />
          <Skeleton className="h-4 w-20" />
        </div>
      ))}
    </div>
  );
}
```

### Layout shift prevention

Mirror typography heights (`h-4` for `text-sm`, `h-5` for `text-base`, `h-8` for `text-2xl`) so the layout remains steady when real content mounts:

```tsx
import { Skeleton } from '@innostes/ui';

export function StatTileSkeleton() {
  return (
    <div aria-busy="true" className="flex flex-col gap-2 rounded-xl border p-5">
      <Skeleton className="h-4 w-24" />
      <Skeleton className="h-8 w-32" />
      <Skeleton className="h-3 w-40" />
    </div>
  );
}
```

## Accessibility

`Skeleton` is carefully designed to avoid distracting screen reader chatter during network fetches.

### Container aria-busy and aria-live

- `Skeleton` elements are marked with `aria-hidden="true"`, ensuring assistive technologies do not announce every individual placeholder bar.
- Always add `aria-busy="true"` and an `aria-label` (e.g. `aria-label="Loading purchase orders"`) on the parent container enclosing the skeletons. Remove `aria-busy` once real data has populated the DOM.

### Reduced motion support

When a user enables `prefers-reduced-motion: reduce` in their operating system accessibility settings, the pulsing animation is automatically disabled (`motion-reduce:animate-none`), displaying a steady muted background.
