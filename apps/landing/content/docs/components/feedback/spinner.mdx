## Import

```tsx
import { Spinner, type SpinnerProps } from '@innostes/ui';
```

## When to use

Use `Spinner` to indicate localized asynchronous activity when space does not permit a full skeleton or progress bar:

- Indicating asynchronous background sync in table headers or stat cards.
- Rendering an inline indicator next to a "Saving draft…" status note.
- Showing loading spinners in asynchronous dropdown search results.

When choosing loading components:
- Use `Spinner` for compact inline loading indicators and isolated status chips.
- Use `Button loading` directly on buttons rather than nesting a manual `<Spinner />` inside the button label.
- Use [Skeleton](/ui/docs/components/feedback/skeleton) when fetching initial page layouts or table records.
- Use [Progress](/ui/docs/components/feedback/progress) for determinate task progression (uploads, exports).

## Examples

### Basic spinner

By default, `Spinner` renders at `size-4` (16px) and carries an accessible label of `"Loading"` with `role="status"`:

```tsx
import { Spinner } from '@innostes/ui';

export function DefaultSpinner() {
  return <Spinner aria-label="Loading purchase orders" />;
}
```

### Sizing and color inheritance

`Spinner` uses `stroke="currentColor"` so it automatically matches the text color of its parent container. Adjust its dimensions using standard Tailwind `size-*` utilities:

```tsx
import { Spinner } from '@innostes/ui';

export function SizedSpinners() {
  return (
    <div className="flex items-center gap-4">
      <Spinner className="size-4" />
      <Spinner className="size-6 text-primary" />
      <Spinner className="size-8 text-muted-foreground" />
    </div>
  );
}
```

### Inlined with status text

When a spinner sits directly beside descriptive text (such as "Syncing ledger..."), pass `label={null}`. This marks the spinner as decorative (`aria-hidden="true"`), preventing screen readers from announcing duplicate loading messages:

```tsx
import { Spinner } from '@innostes/ui';

export function InlineStatus() {
  return (
    <div className="flex items-center gap-2 text-sm text-muted-foreground">
      <Spinner label={null} />
      <span>Reconciling bank transactions…</span>
    </div>
  );
}
```

### Inside buttons and controls

For interactive buttons, always prefer the built-in `loading` prop on [Button](/ui/docs/components/actions/button). It automatically manages focus, disables pointer events, and injects a spinner with proper ARIA attributes:

```tsx
import { Button } from '@innostes/ui';

export function SubmitButton({ isSubmitting }: { isSubmitting: boolean }) {
  return (
    <Button loading={isSubmitting} type="submit">
      Approve purchase order
    </Button>
  );
}
```

## Accessibility

`Spinner` handles assistive technology notifications gracefully.

### Accessible labels versus decorative hiding

- When `label` is provided (defaults to `"Loading"`), `Spinner` sets `role="status"` and `aria-label={label}`. Screen readers announce the status update politely.
- When `label={null}` is explicitly passed, `Spinner` removes `role="status"` and sets `aria-hidden="true"`, ensuring no extraneous speech is triggered when accompanying text already explains the state.

### Screen readers and role="status"

- By using `role="status"`, screen readers wait until the current utterance completes before announcing the loading state, preventing jarring speech interruptions.
