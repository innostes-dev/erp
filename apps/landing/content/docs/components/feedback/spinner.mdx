## Import

```tsx
import { Spinner } from '@innostes/ui';
```

## Usage

```tsx
<Spinner />                                   {/* announced as "Loading" */}
<Spinner className="size-6 text-primary" label="Loading orders" />
<span><Spinner label={null} /> Syncing…</span> {/* text already says it */}
```

For buttons, use `<Button loading>` instead; it handles the spinner and the busy state.
