```tsx
import { Meter, type MeterProps } from '@innostes/ui';
```

## When to use

Use `Meter` to communicate an existing scalar measurement or capacity against known numerical bounds:

- Displaying storage consumption, memory usage, or compute quotas.
- Tracking organisation seat licence utilisation (e.g. 8 of 10 operator licences used).
- Monitoring warehouse bin volume or tank fuel levels.

When choosing scalar components:
- Use `Meter` (`role="meter"`) for static capacity or volume measurements within a fixed range.
- Use [Progress](/ui/docs/components/feedback/progress) (`role="progressbar"`) when an active task is advancing toward completion.
- Use [Gauge](/ui/docs/components/feedback/gauge) when you need an executive radial dial display on KPI dashboards.
- Refer to the [Feedback decision guide](/ui/docs/components/feedback#feedback-decision-guide) for guidance on all feedback mechanisms.

## Examples

### Basic capacity measurement

Provide `value`, `min`, `max`, and a descriptive `label`:

```tsx
import { Meter } from '@innostes/ui';

export function StorageMeter() {
  return (
    <Meter
      value={64}
      max={100}
      label="Cloud document storage"
      format={{ style: 'unit', unit: 'gigabyte' }}
    />
  );
}
```

### Warning and destructive tones

Set `tone` to `primary`, `success`, `warning`, or `destructive` to communicate status severity as a metric approaches full capacity:

```tsx
import { Meter } from '@innostes/ui';

export function CapacityTones() {
  const usedSeats = 9;
  const maxSeats = 10;
  const isCritical = usedSeats / maxSeats > 0.85;

  return (
    <Meter
      value={usedSeats}
      max={maxSeats}
      label="Dispatch operator licenses"
      tone={isCritical ? 'destructive' : 'primary'}
      showValue
    />
  );
}
```

### Normalized percentage formatting

When `format={{ style: 'percent' }}` is specified, `Meter` normalizes `value` against `min` and `max` so that `value={72}` with `max={100}` renders `"72%"` (rather than `"7,200%"`):

```tsx
import { Meter } from '@innostes/ui';

export function NormalizedQuotaMeter() {
  return (
    <Meter
      value={84}
      min={0}
      max={100}
      label="Monthly API rate limit"
      format={{ style: 'percent' }}
      tone="warning"
    />
  );
}
```

## Accessibility

`Meter` is built on Base UI Meter primitives (`@base-ui/react/meter`).

### Screen readers and meter semantics

- Renders with native `role="meter"`.
- Sets `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` automatically.
- Screen readers announce the current reading in relation to the upper and lower boundaries (e.g., "Cloud document storage, 64 gigabytes, 64%").
- When `format={{ style: 'percent' }}` is used, `aria-valuetext` announces the correct computed percentage string.

### Colour independence

Avoid relying strictly on the bar colour to communicate limit risks. Always provide clear numerical text or helper copy indicating proximity to the maximum capacity.
