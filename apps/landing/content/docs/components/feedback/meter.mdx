## Import

```tsx
import { Meter } from '@innostes/ui';
```

## Usage

```tsx
<Meter
  value={used}
  max={limit}
  label="Seats"
  tone={used / limit > 0.9 ? 'destructive' : used / limit > 0.75 ? 'warning' : 'primary'}
/>
```

`format` takes `Intl.NumberFormat` options, e.g. `{ style: 'percent' }` with `max={1}`.

## Accessibility

- `role="meter"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`.
