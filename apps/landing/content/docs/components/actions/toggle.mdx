## Import

```tsx
import { Toggle } from '@innostes/ui';
```

## Usage

```tsx
// Uncontrolled
<Toggle aria-label="Bold" defaultPressed><BoldIcon /></Toggle>

// Controlled
const [starred, setStarred] = useState(false);
<Toggle pressed={starred} onPressedChange={setStarred} aria-label="Star">
  <StarIcon />
</Toggle>
```

Use `Toggle` for state that applies immediately and is shown by the button itself.
For settings in a form, use [Switch](/ui/docs/components/forms/switch).

## Accessibility

- Exposes `aria-pressed`, so screen readers announce "pressed" / "not pressed".
- Icon-only toggles need an `aria-label`.
