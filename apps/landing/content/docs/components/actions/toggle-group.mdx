ToggleGroup coordinates a set of two-state toggle buttons. Built on Base UI's toggle group primitive, it supports both single-selection (e.g. text alignment, view modes) and multi-selection (e.g. text formatting options) with built-in roving focus management and keyboard arrow navigation.

<ComponentPreview name="actions/toggle-group/basic" />

## Import

```tsx
import { ToggleGroup, ToggleGroupItem } from '@innostes/ui';
```

## When to use

- **Use ToggleGroup** when users need to switch between related view layouts (e.g. List vs Grid) or apply multiple independent formatting options (e.g. Bold, Italic, Underline).
- **Use RadioGroup** when selecting one option from a list within a standard form where standard radio button styling is required.
- **Use Tabs** when selecting an option switches an entire underlying panel or page view.
- **Use ButtonGroup** when grouping operational action buttons that trigger commands rather than maintaining state.

## Examples

### Single selection

In default mode, ToggleGroup operates with single selection:

```tsx
const [view, setView] = useState(['table']);

<ToggleGroup value={view} onValueChange={setView} aria-label="Inventory layout">
  <ToggleGroupItem value="table">Table view</ToggleGroupItem>
  <ToggleGroupItem value="kanban">Kanban board</ToggleGroupItem>
</ToggleGroup>
```

### Multiple selection

Enable the `multiple` prop to permit selecting more than one option concurrently:

```tsx
const [formatting, setFormatting] = useState(['bold', 'italic']);

<ToggleGroup
  multiple
  value={formatting}
  onValueChange={setFormatting}
  aria-label="Rich text formatting"
>
  <ToggleGroupItem value="bold" aria-label="Bold"><Bold className="size-4" /></ToggleGroupItem>
  <ToggleGroupItem value="italic" aria-label="Italic"><Italic className="size-4" /></ToggleGroupItem>
  <ToggleGroupItem value="underline" aria-label="Underline"><Underline className="size-4" /></ToggleGroupItem>
</ToggleGroup>
```

### Attached outline styling

Use `variant="outline"` to merge borders and join the items into a solid segmented control:

```tsx
<ToggleGroup variant="outline" defaultValue={['all']} aria-label="Status filter">
  <ToggleGroupItem value="all">All orders</ToggleGroupItem>
  <ToggleGroupItem value="pending">Pending</ToggleGroupItem>
  <ToggleGroupItem value="dispatched">Dispatched</ToggleGroupItem>
</ToggleGroup>
```

### Screen readers and ARIA

- **Roving tabindex**: Only the active or focused item has `tabIndex={0}`; remaining items receive `tabIndex={-1}`, ensuring the entire group acts as a single tab stop in the DOM.
- **`role="group"`**: Automatically applied to the container alongside the provided `aria-label`.
- **`aria-pressed`**: Emitted on each item to announce active state changes to screen readers.

## Guidelines

<DoDont>
  <Do>
    Always provide an `aria-label` on `ToggleGroup` describing the group purpose (e.g. `aria-label="View mode"`).
  </Do>
  <Dont>
    Never use `ToggleGroup` for navigating between separate URLs; use `Tabs` or standard navigation links instead.
  </Dont>
</DoDont>

<DoDont>
  <Do>
    Provide an `aria-label` on each `ToggleGroupItem` when items contain only icons without text labels.
  </Do>
  <Dont>
    Never mix mutually exclusive options with multi-select toggles inside the same group container.
  </Dont>
</DoDont>
