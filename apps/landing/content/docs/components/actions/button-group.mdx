ButtonGroup organizes a collection of related button triggers into a cohesive segmented bar, collapsing adjacent borders and rounding only the outer corners. It is commonly used for date pagination controls, multi-part save buttons, and table view switchers.

<ComponentPreview name="actions/button-group/basic" />

## Import

```tsx
import { Button, ButtonGroup } from '@innostes/ui';
```

## When to use

- **Use ButtonGroup** when grouping related triggers such as pagination controls (Previous / Today / Next) or split action menus (Save / More options).
- **Use ToggleGroup** when buttons toggle pressed states or select mutually exclusive options.
- **Use FormActions** when laying out separate form submission buttons (e.g. Save and Cancel) across a footer.

## Examples

### Basic usage

Wrap adjacent buttons with `ButtonGroup` and assign an accessible label:

```tsx
<ButtonGroup aria-label="Order pagination">
  <Button variant="outline" size="sm">Previous</Button>
  <Button variant="outline" size="sm">Next</Button>
</ButtonGroup>
```

### Split button

Combine a primary action trigger with a contextual dropdown menu button:

```tsx
<ButtonGroup aria-label="Invoice settlement actions">
  <Button variant="primary">Approve and remit</Button>
  <Button
    variant="primary"
    iconOnly
    aria-label="Additional remittance options"
    className="border-s border-s-primary-foreground/20"
  >
    <ChevronDown className="size-4" />
  </Button>
</ButtonGroup>
```

### Orientation

Arrange buttons vertically when building sidebar toolbars:

```tsx
<ButtonGroup orientation="vertical" aria-label="Document view tools">
  <Button variant="outline" size="sm">Zoom in</Button>
  <Button variant="outline" size="sm">Zoom out</Button>
  <Button variant="outline" size="sm">Reset</Button>
</ButtonGroup>
```

### Screen readers and ARIA

- **`role="group"`**: Automatically applied to the wrapper container.
- **`aria-label` requirement**: You **must** provide `aria-label` or `aria-labelledby` describing the collection of buttons (e.g. `aria-label="Pagination controls"`).
- **Z-index focus stacking**: Focus rings are rendered with elevated z-index so the active button outline is never clipped by neighbouring buttons.

## Guidelines

<DoDont>
  <Do>
    Always provide an `aria-label` on `ButtonGroup` explaining the shared purpose of the grouped actions.
  </Do>
  <Dont>
    Never use `ButtonGroup` for mutually exclusive selection; use `ToggleGroup` or `RadioGroup` instead.
  </Dont>
</DoDont>

<DoDont>
  <Do>
    Maintain consistent button variants and sizes inside a single group container.
  </Do>
  <Dont>
    Never mix conflicting heights (`size="sm"` with `size="lg"`) within the same button group.
  </Dont>
</DoDont>
