## Import

```tsx
import { Button, ButtonGroup } from '@innostes/ui';
```

## Usage

Use a group for actions that belong together: a pager, a split button, or a set of views.
For buttons that toggle state, use [Toggle Group](/ui/docs/components/actions/toggle-group) instead.

```tsx
<ButtonGroup aria-label="Pager">
  <Button variant="outline">Previous</Button>
  <Button variant="outline">Next</Button>
</ButtonGroup>
```

## Accessibility

- Renders `role="group"`. Give it an `aria-label` that describes the set.
- Focus outlines stay on top of neighbouring buttons.
