## Import

```tsx
import { ScrollArea } from '@innostes/ui';
```

## When to use

Use `ScrollArea` when a region must scroll independently without relying on divergent OS-native scrollbar styling:

- **Audit trails and activity logs**: Displaying long chronological timelines in sidebars or cards.
- **Data drawers and sheets**: Ensuring vertical scrolling inside `SheetBody` or dialog viewports.
- **Wide horizontal tables or code blocks**: Providing clean horizontal scroll tracking without bulky browser bars.

**Do not use ScrollArea for:**
- The primary window body scroll — allow the browser window to scroll naturally.
- Small fixed-size cards where content easily fits without truncation.
- Infinite lists requiring virtual DOM rendering — use a virtualised data grid.

## Examples

### Vertical scrollable audit feed

Giving the container a bounded height or max-height:

```tsx
<ScrollArea className="h-72 rounded-md border p-4">
  <div className="space-y-4">
    <h4 className="text-sm font-semibold">ERP audit log (PO-2026-081)</h4>
    {auditLogs.map((log) => (
      <div key={log.id} className="text-sm border-b pb-2">
        <p className="font-medium text-foreground">{log.action}</p>
        <p className="text-xs text-muted-foreground">{log.actor} · {log.timestamp}</p>
      </div>
    ))}
  </div>
</ScrollArea>
```

### Horizontal scrolling for wide datasets

Set `scrollbars="horizontal"` or `scrollbars="both"` when hosting wide data grids or timeline bars:

```tsx
<ScrollArea scrollbars="horizontal" className="w-full rounded-md border">
  <div className="flex w-max gap-4 p-4">
    {warehouses.map((wh) => (
      <Card key={wh.id} className="w-64 shrink-0">
        <CardHeader>
          <CardTitle>{wh.name}</CardTitle>
          <CardDescription>{wh.location}</CardDescription>
        </CardHeader>
      </Card>
    ))}
  </div>
</ScrollArea>
```

## Accessibility

`ScrollArea` is built on Base UI ScrollArea primitives (`@base-ui/react/scroll-area`).

### Keyboard navigation

  ]}
/>

### ARIA attributes

- The scroll area maintains standard native scrolling mechanics, ensuring assistive technologies can navigate child nodes sequentially.
- Scrollbar thumbs hide visually when inactive but expand upon pointer hover to offer a clear drag target.
