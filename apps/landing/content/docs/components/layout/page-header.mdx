## Import

```tsx
import { PageHeader } from '@innostes/ui';
```

## When to use

Use `PageHeader` at the top of every internal administrative view:

- **Record detail pages**: Purchase order `PO-2026-081`, Customer account `Acme Corp`, or Tax invoice `INV-2026-081`.
- **List and catalogue dashboards**: Warehouses, inventory catalogues, or statutory reports.
- **Settings subpages**: Security preferences, GST profiles, or team roles.

**Do not use PageHeader for:**
- Global application-level headers (with tenant switcher, global search, and user avatar) — use [TopBar](/ui/docs/components/layout/top-bar).
- In-page card section titles — use [Card](/ui/docs/components/data-display/card) or standard heading elements.
- Dialog and modal window titles — use `DialogHeader` and `DialogTitle`.

## Examples

### Basic usage with breadcrumb and actions

Render breadcrumbs, page title, description, and primary action buttons:

```tsx
<PageHeader
  breadcrumb={
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="/purchases">Purchases</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>PO-2026-081</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  }
  title="Purchase order PO-2026-081"
  description="Bengaluru Spices Pvt Ltd · Created on 24 Oct 2026 by Priya Sharma"
  actions={
    <div className="flex items-center gap-2">
      <Button variant="outline">Download PDF</Button>
      <Button>Approve order</Button>
    </div>
  }
/>
```

### With status badge in title

Pass React nodes to `title` to pair headings with live status chips:

```tsx
<PageHeader
  title={
    <div className="flex items-center gap-3">
      <span>Tax invoice INV-2026-081</span>
      <Badge variant="success">E-Way Bill Generated</Badge>
    </div>
  }
  description="GST Tax Invoice · Total value ₹89,400"
  actions={<Button variant="destructive">Void invoice</Button>}
/>
```

## Accessibility

`PageHeader` provides unambiguous document heading landmarks.

### ARIA attributes

- The container renders as a semantic `<header>` landmark.
- The `title` prop renders the unique primary `<h1>` heading for the page.
- Action buttons remain in logical DOM order so screen reader users encounter contextual breadcrumbs, title, description, and actions in sequence.
