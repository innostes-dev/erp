## Import

```tsx
import { Separator } from '@innostes/ui';
```

## When to use

Use `Separator` to establish clear visual boundaries between distinct functional areas:

- **Form and section dividers**: Breaking up long configuration panels into readable chunks.
- **Toolbar dividers**: Separating button groups (e.g. text formatting vs clipboard actions).
- **Detail card segments**: Separating customer metadata from order financial totals.

**Do not use Separator for:**
- Purely decorative lines with no semantic division — use CSS borders.
- Spacing between consecutive table rows — use table row borders.
- Top-level page borders — rely on layout containers like `PageHeader` and `TopBar`.

## Examples

### Horizontal card divider

Separating enterprise entity headers from summary line items:

```tsx
<div className="rounded-lg border p-6">
  <div className="space-y-1">
    <h4 className="text-sm font-semibold">Northwind Traders Pvt Ltd</h4>
    <p className="text-xs text-muted-foreground">Bengaluru Central Hub · GSTIN 29ABCDE1234F1Z5</p>
  </div>
  <Separator className="my-4" />
  <div className="flex justify-between text-sm">
    <span>Active purchase orders</span>
    <span className="font-semibold">₹4,28,900</span>
  </div>
</div>
```

### Vertical divider inside button toolbars

Set `orientation="vertical"` to separate interactive clusters:

```tsx
<div className="flex h-9 items-center gap-2 rounded-md border p-1">
  <Button size="sm" variant="ghost" iconOnly aria-label="Bold"><BoldIcon /></Button>
  <Button size="sm" variant="ghost" iconOnly aria-label="Italic"><ItalicIcon /></Button>
  <Separator orientation="vertical" className="h-4" />
  <Button size="sm" variant="ghost" iconOnly aria-label="Align left"><AlignLeftIcon /></Button>
  <Button size="sm" variant="ghost" iconOnly aria-label="Align center"><AlignCenterIcon /></Button>
</div>
```

## Accessibility

`Separator` is built on Base UI Separator primitives (`@base-ui/react/separator`).

### Keyboard navigation

Separators are non-focusable elements skipped by keyboard tab loops.

### ARIA attributes

- Renders with `role="separator"`.
- Sets `aria-orientation="horizontal"` (default) or `aria-orientation="vertical"`.
- When used purely for cosmetic decoration without structural meaning, pass `decorative={true}` to render `role="none"` and hide it from screen readers.
