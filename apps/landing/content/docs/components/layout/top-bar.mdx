## Import

```tsx
import {
  TopBar,
  TopBarStart,
  TopBarCenter,
  TopBarEnd,
} from '@innostes/ui';
```

## When to use

Use `TopBar` as the persistent header across administrative and enterprise applications:

- **Application header**: Housing the organization logo, workspace switcher, and mobile sidebar trigger.
- **Global search integration**: Providing a prominent trigger for [CommandPalette](/ui/docs/components/overlays/command-palette).
- **Tenant and user profile tools**: Housing branch switchers (e.g. Bengaluru vs Mumbai), alert notifications, and user avatars.

**Do not use TopBar for:**
- In-page sub-headers with breadcrumbs and primary entity actions — use [PageHeader](/ui/docs/components/layout/page-header).
- Local card headers — use [Card](/ui/docs/components/data-display/card).
- Pure marketing navigation headers with multi-level megamenus.

## Examples

### Three-slot header composition

Using `TopBarStart`, `TopBarCenter`, and `TopBarEnd`:

```tsx
<TopBar sticky blur>
  <TopBarStart>
    <SidebarTrigger />
    <div className="flex items-center gap-2 font-semibold text-sm">
      <span className="size-6 rounded bg-primary text-primary-foreground flex items-center justify-center font-bold text-xs">
        N
      </span>
      <span>Northwind Traders</span>
    </div>
  </TopBarStart>

  <TopBarCenter>
    <Button
      variant="outline"
      size="sm"
      className="w-full max-w-sm justify-between text-muted-foreground"
      onClick={openSearch}
    >
      <span>Search invoices, POs, vendors...</span>
      <kbd className="text-xs bg-muted border px-1.5 py-0.5 rounded">⌘K</kbd>
    </Button>
  </TopBarCenter>

  <TopBarEnd>
    <Button variant="ghost" size="sm" iconOnly aria-label="Notifications">
      <BellIcon className="size-4" />
    </Button>
    <UserMenu name="Priya Sharma" email="priya.sharma@northwind.in" />
  </TopBarEnd>
</TopBar>
```

### Sticky positioning and backdrop blur

`TopBar` sticks to the top of the viewport by default. Enable `blur` for a translucent frosted glass effect over scrolling content:

```tsx
<TopBar sticky blur className="border-b">
  {/* Content blurred under header while scrolling */}
</TopBar>
```

## Accessibility

`TopBar` implements semantic landmark navigation.

### Keyboard navigation

<KeyboardTable
  entries={[

  ]}
/>

### ARIA attributes

- The container renders as a `<header>` element with `data-slot="top-bar"`.
- Buttons and search triggers inside `TopBar` maintain clear `aria-label` text for assistive devices.
- Focus order flows naturally from left to right in LTR (and right to left in RTL).
