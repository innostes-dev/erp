## Import

```tsx
import { FormGrid, FormSection, FormActions } from '@innostes/ui';
```

## When to use

Use `FormLayout` primitives to establish clean, predictable field spacing across diverse layout environments:

- **Full-page forms**: Vendor onboarding, purchase order creation, or product catalogue entries.
- **Side drawer forms**: Edit forms inside [Sheet](/ui/docs/components/overlays/sheet).
- **Modal forms**: Quick entry dialogues inside [Dialog](/ui/docs/components/overlays/dialog).

Because `FormGrid` uses CSS **container queries** rather than viewport media queries, the grid automatically adapts to the actual width of its container (page, drawer, or modal) without needing custom responsive breakpoint classes.

## Examples

### Responsive FormGrid with column spans

Organise form fields into 1, 2, 3, or 4 adaptive columns:

```tsx
<FormGrid columns={2}>
  <Field name="vendorName">
    <FieldLabel>Vendor legal name</FieldLabel>
    <Input defaultValue="Bengaluru Spices Pvt Ltd" />
  </Field>
  <Field name="gstin">
    <FieldLabel>GSTIN</FieldLabel>
    <Input defaultValue="29ABCDE1234F1Z5" />
  </Field>
  <Field name="address" className="col-span-full">
    <FieldLabel>Registered warehouse address</FieldLabel>
    <Textarea defaultValue="Plot 42, Electronic City Phase 1, Hosur Road, Bengaluru 560100" />
  </Field>
</FormGrid>
```

### FormSection: stacked versus aside

Use `layout="stacked"` (default) for dialogs and standard pages, or `layout="aside"` for settings screens where section titles sit on the left:

```tsx
<FormSection
  title="Statutory tax profiles"
  description="Manage registered GSTIN identifiers and TDS rates."
  layout="aside"
>
  <FormGrid columns={2}>
    <Field name="pan">
      <FieldLabel>Company PAN</FieldLabel>
      <Input defaultValue="ABCDE1234F" />
    </Field>
    <Field name="tan">
      <FieldLabel>Tax deduction account number (TAN)</FieldLabel>
      <Input defaultValue="BLRA01234E" />
    </Field>
  </FormGrid>
</FormSection>
```

### FormActions with sticky positioning

`FormActions` aligns save and cancel buttons. Use `align="between"` to place the back/cancel button on the left and the primary submit button on the right:

```tsx
<FormActions align="between" sticky>
  <Button variant="outline">Cancel</Button>
  <div className="flex gap-2">
    <Button variant="secondary">Save as draft</Button>
    <Button type="submit">Submit for approval</Button>
  </div>
</FormActions>
```

## Accessibility

`FormLayout` primitives enforce structured visual hierarchy and standard DOM order.

### Keyboard navigation

### ARIA attributes

- `FormSection` wraps fields in semantic `<section>` landmarks labelled by the section title.
- `FormGrid` preserves natural reading and focus order, avoiding confusing CSS grid reordering.
