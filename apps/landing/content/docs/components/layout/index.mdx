# Layout

Layout components define the structural scaffold for Northwind Traders Pvt Ltd's applications. They orchestrate viewports, responsive sidebars, persistent headers, and split-pane inspection canvases to support complex enterprise workflows.

## Usage guidelines

- **Application Shell**: Combine `AppRail`, `Sidebar`, `TopBar`, and `PageHeader` to create structured, responsive application frames.
- **Scroll containment**: Use `ScrollArea` for customized, accessible scrollable regions rather than unstyled browser overflow bars.
- **Form layouts**: Structure form controls using `FormLayout` to enforce standard vertical rhythm and responsive column wrapping.
