## When to use

Use `Sidebar` as the primary navigation backbone of administrative and enterprise applications:

- **ERP application shell**: Multi-level navigation across Procurement, Warehousing, Invoicing, and Master Data.
- **Hierarchical menu structures**: Submenus grouping purchase orders, vendor master, and goods received notes.
- **Responsive administrative layouts**: Desktop sidebars that cleanly switch to mobile slide-over drawers below 768px.

**Do not use Sidebar for:**
- Isolated page-level filters — use [Sheet](/ui/docs/components/overlays/sheet) or inline filter cards.
- Horizontal category tabs — use [Tabs](/ui/docs/components/navigation/tabs).
- Single-page marketing websites — use standard top headers.

## Examples

### Basic application shell composition

Compose `SidebarProvider`, `Sidebar`, `TopBar`, and `SidebarInset` into an accessible layout with router integration:

```tsx
import Link from 'next/link';
import { usePathname } from 'next/navigation';
import {
  SidebarProvider,
  Sidebar,
  SidebarHeader,
  SidebarContent,
  SidebarFooter,
  SidebarGroup,
  SidebarGroupLabel,
  SidebarMenu,
  SidebarMenuItem,
  SidebarMenuButton,
  SidebarTrigger,
  SidebarInset,
  TopBar,
} from '@innostes/ui';
import { ShoppingCart, Package, FileText } from 'lucide-react';

export function AdminLayout({ children }: { children: React.ReactNode }) {
  const pathname = usePathname();

  return (
    <SidebarProvider>
      <Sidebar>
        <SidebarHeader>
          <div className="flex items-center gap-2 px-2 py-3 font-semibold text-sm">
            <span className="size-6 rounded bg-primary text-primary-foreground flex items-center justify-center font-bold text-xs">
              N
            </span>
            Northwind Traders
          </div>
        </SidebarHeader>

        <SidebarContent>
          <SidebarGroup>
            <SidebarGroupLabel>Procurement</SidebarGroupLabel>
            <SidebarMenu>
              <SidebarMenuItem>
                <SidebarMenuButton
                  icon={<ShoppingCart className="size-4" />}
                  isActive={pathname.startsWith('/purchases')}
                  render={<Link href="/purchases" />}
                >
                  Purchase orders
                </SidebarMenuButton>
              </SidebarMenuItem>
              <SidebarMenuItem>
                <SidebarMenuButton
                  icon={<Package className="size-4" />}
                  isActive={pathname.startsWith('/inventory')}
                  render={<Link href="/inventory" />}
                >
                  Inventory stock
                </SidebarMenuButton>
              </SidebarMenuItem>
            </SidebarMenu>
          </SidebarGroup>
        </SidebarContent>

        <SidebarFooter>
          {/* User profile and sign-out */}
        </SidebarFooter>
      </Sidebar>

      <SidebarInset>
        <TopBar>
          <SidebarTrigger />
        </TopBar>
        <main className="p-6">
          {children}
        </main>
      </SidebarInset>
    </SidebarProvider>
  );
}
```

### Collapsible behaviour and keyboard shortcuts

- **Desktop state**: Expands to standard width (default `256px`) or collapses into an icon rail (default `56px`). In icon mode, hovering or focusing any menu item displays its title via an accessible tooltip.
- **Mobile drawer**: Below `768px` (customisable via `mobileQuery`), the sidebar automatically switches to a slide-in modal drawer. Selecting any item automatically closes the drawer.
- **Global hotkey**: Pressing `Ctrl + B` or `⌘ + B` toggles the sidebar open or closed. Disable by setting `keyboardShortcut={null}`.
- **State hook**: `useSidebar()` gives any descendant component access to `{ open, setOpen, toggle, isMobile, openMobile, setOpenMobile }`.

### Theming the sidebar

The sidebar consumes dedicated CSS colour tokens, allowing a distinct brand surface (e.g. dark navy sidebar inside a light neutral application) without conflicting with page background tokens:

```css
@theme {
  --color-sidebar: var(--color-slate-900);
  --color-sidebar-foreground: var(--color-slate-50);
  --color-sidebar-primary: var(--color-blue-500);
  --color-sidebar-primary-foreground: var(--color-white);
  --color-sidebar-accent: var(--color-slate-800);
  --color-sidebar-accent-foreground: var(--color-slate-50);
  --color-sidebar-border: var(--color-slate-800);
  --color-sidebar-ring: var(--color-blue-500);
}
```

## Accessibility

`Sidebar` implements WAI-ARIA Landmark and Disclosure specifications.

### Keyboard navigation

  entries={[

    { key: 'Tab', action: 'Cycles sequentially through interactive sidebar menu links and triggers.' },
    { key: 'Escape', action: 'Dismisses the open mobile drawer panel and restores focus to the trigger button.' },
  ]}
/>

### ARIA attributes

- The sidebar root renders as `<nav aria-label="Sidebar">` (or custom `label`).
- Active items receive `aria-current="page"`.
- `SidebarTrigger` provides `aria-expanded="true | false"` and `aria-label="Toggle sidebar"`.
- When in icon-collapsed mode, items render accessible tooltips to prevent icon ambiguity.
