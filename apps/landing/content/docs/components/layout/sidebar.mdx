## Layout

```tsx title="app/(admin)/layout.tsx"
<SidebarProvider>
  <Sidebar>
    <SidebarHeader>{/* logo, workspace switcher */}</SidebarHeader>
    <SidebarContent>
      <SidebarGroup>
        <SidebarGroupLabel>Sales</SidebarGroupLabel>
        <SidebarMenu>
          <SidebarMenuItem>
            <SidebarMenuButton
              icon={<ShoppingCartIcon />}
              isActive={pathname.startsWith('/orders')}
              render={<Link href="/orders" />}
            >
              Orders
            </SidebarMenuButton>
          </SidebarMenuItem>
        </SidebarMenu>
      </SidebarGroup>
    </SidebarContent>
    <SidebarFooter>{/* user menu */}</SidebarFooter>
  </Sidebar>
  <SidebarInset>
    <header><SidebarTrigger /></header>
    <main>{children}</main>
  </SidebarInset>
</SidebarProvider>
```

## Behaviour

- **Desktop**: expanded (256px) or collapsed to icons (56px). Collapsed items show their label in a tooltip.
- **Mobile** (below 768px, set with `mobileQuery`): the sidebar becomes a slide-in panel that closes when an item is chosen.
- **Shortcut**: Ctrl/⌘ + B toggles it (`keyboardShortcut`, or `null` to turn off).
- **Persist** the choice by controlling `open` / `onOpenChange` and saving it, e.g. in a cookie, so the server renders the right state.

`useSidebar()` gives any component inside the provider `open`, `toggle`, `isMobile` and setters.

## Custom Width

You can customize the width of the sidebar when expanded, collapsed to icons, and on mobile. These props map directly to `--sidebar-width`, `--sidebar-width-icon`, and `--sidebar-width-mobile` CSS variables.

## Variants

The sidebar comes in three visual variants: `sidebar` (classic full-height side navigation), `floating` (a floating panel distinct from the edge), and `inset` (a sidebar that wraps the content area with a rounded border).

## Theming the sidebar

The sidebar is built with its own set of CSS variables (tokens) independent from the rest of the application. This allows you to give the app shell a distinct look (like a dark sidebar in a light app) without affecting standard components.

To theme the sidebar, override the `--color-sidebar*` tokens in your CSS.

```css
@theme {
  --color-sidebar: var(--color-slate-900);
  --color-sidebar-foreground: var(--color-slate-50);
  --color-sidebar-primary: var(--color-blue-500);
  --color-sidebar-primary-foreground: var(--color-white);
  --color-sidebar-accent: var(--color-slate-800);
  --color-sidebar-accent-foreground: var(--color-slate-50);
  --color-sidebar-border: var(--color-slate-800);
  --color-sidebar-ring: var(--color-blue-500);
}
```

## Accessibility

- The sidebar is a `<nav>` landmark (label it with `label`). The active item has `aria-current="page"`.
- `SidebarTrigger` reports `aria-expanded`.
