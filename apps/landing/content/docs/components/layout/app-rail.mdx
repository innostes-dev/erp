## Import

```tsx
import {
  AppRail,
  AppRailItem,
  AppRailHeader,
  AppRailFooter,
  AppRailSeparator,
} from '@innostes/ui';
```

## When to use

Use `AppRail` when building two-tier enterprise navigation suites:

- **Multi-module ERP platforms**: Fast switching between Procurement, Inventory, Finance, and HRMS.
- **Persistent workspace switcher**: Keeping global shortcuts reachable regardless of current deep view.
- **High-density desktop apps**: Minimising horizontal space loss while retaining full-screen module switching.

**Do not use AppRail for:**
- Single-purpose applications with fewer than 5 total pages — use a standard [Sidebar](/ui/docs/components/layout/sidebar).
- Page-level content tabs — use [Tabs](/ui/docs/components/navigation/tabs).
- Mobile screens — `AppRail` hides automatically below the `md` breakpoint, where `Sidebar` assumes mobile navigation duties.

## Examples

### Two-tier navigation shell

Composing `AppRail` alongside `Sidebar` inside `SidebarProvider`:

```tsx
import Link from 'next/link';
import {
  SidebarProvider,
  AppRail,
  AppRailHeader,
  AppRailItem,
  AppRailFooter,
  Sidebar,
  SidebarInset,
} from '@innostes/ui';
import { Package, ShoppingCart, Landmark, Users } from 'lucide-react';

export function ErpShell({ children }) {
  return (
    <SidebarProvider>
      <AppRail label="ERP modules">
        <AppRailHeader>
          <div className="size-8 rounded bg-primary font-bold text-primary-foreground flex items-center justify-center">
            N
          </div>
        </AppRailHeader>

        <AppRailItem
          icon={<ShoppingCart />}
          label="Procurement"
          isActive
          render={<Link href="/procurement" />}
        />
        <AppRailItem
          icon={<Package />}
          label="Inventory"
          badge={12}
          render={<Link href="/inventory" />}
        />
        <AppRailItem
          icon={<Landmark />}
          label="Finance & GST"
          render={<Link href="/finance" />}
        />

        <AppRailFooter>
          <AppRailItem
            icon={<Users />}
            label="Employees"
            render={<Link href="/hrms" />}
          />
        </AppRailFooter>
      </AppRail>

      <Sidebar>
        {/* Secondary navigation for Procurement */}
      </Sidebar>

      <SidebarInset>
        {children}
      </SidebarInset>
    </SidebarProvider>
  );
}
```

### With badges and tooltips

Each `AppRailItem` automatically renders an accessible tooltip when hovered or focused, displaying the item's label and notification badge count:

```tsx
<AppRailItem
  icon={<Bell />}
  label="Approvals"
  badge={3}
  render={<Link href="/approvals" />}
/>
```

## Accessibility

`AppRail` renders semantic HTML5 navigation landmarks.

### Keyboard navigation

<KeyboardTable
  entries={[
    { key: 'Tab', action: 'Moves focus sequentially between interactive module items.' },
    { key: 'Enter / Space', action: 'Activates the focused module link or trigger.' },
  ]}
/>

### ARIA attributes

- The container renders as `<nav aria-label="Apps">` (customisable via the `label` prop).
- Active items receive `aria-current="page"`.
- If an item includes a numerical badge, the count is included in accessible label computations for screen readers.

## Guidelines

<DoDont
  do={{
    description: 'Always supply a clear text label for each AppRailItem so tooltips and screen reader names are complete.',

<DoDont

  }}
  dont={{
    description: 'Do not nest native anchor tags inside interactive button triggers.',
    code: `<AppRailItem><a href="/finance">Finance</a></AppRailItem>`,
  }}
/>
