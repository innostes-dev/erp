## Import

```tsx
import { EmptyState } from '@innostes/ui';
```

## Usage

Say what's empty, why, and what to do next:

- **First use**: "No invoices yet" + "Create invoice".
- **No results**: "No orders match ‘acme’" + "Clear filters".
- **No access**: explain who can grant it.

Pass it to `DataTable` as `emptyState` for empty tables.
