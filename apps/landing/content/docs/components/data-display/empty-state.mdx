## Import

```tsx
import { EmptyState, type EmptyStateProps, type EmptyStateSlot } from '@innostes/ui';
```

## When to use

Use `EmptyState` when a view, list, table, or search panel contains no records to present:

- **First-use onboarding**: Introducing a blank module (e.g. "No purchase orders yet") and guiding the user to create their first record.
- **Zero search or filter matches**: Explaining that a query returned no results and providing a one-click action to reset active filters.
- **Completed queues**: Congratulating an operator when an inbox or approval queue has been fully cleared.
- **Permission boundaries**: Explaining that the current user account does not have authorization to view records in this section.

When choosing empty representation:
- Use `EmptyState` inside tables, cards, and page views when space permits an icon, title, and action buttons.
- Use a concise string or empty message inside small dropdown menus (such as [Select](/ui/docs/components/forms/select) or [Combobox](/ui/docs/components/forms/combobox)).
- Refer to the [Feedback decision guide](/ui/docs/components/feedback) for cross-component guidance on when to choose between alerts, empty states, and dialogs.

## Examples

### First use / blank canvas

Provide a welcoming title, a brief explanation of how records are populated, and primary action buttons to create or import records:

```tsx
import { Button, EmptyState } from '@innostes/ui';
import { FilePlus, Upload } from 'lucide-react';

export function InitialInvoicesEmptyState() {
  return (
    <EmptyState
      icon={<FilePlus />}
      title="No purchase orders created"
      description="Create your first purchase order or import batch requisitions from your ERP spreadsheet."
      actions={
        <>
          <Button variant="outline" startIcon={<Upload />}>
            Import CSV
          </Button>
          <Button startIcon={<FilePlus />}>
            Create purchase order
          </Button>
        </>
      }
    />
  );
}
```

### No search or filter results

When active filters produce zero records, reassure the operator that data exists and offer a clear filter reset trigger:

```tsx
'use client';

import { Button, EmptyState } from '@innostes/ui';
import { SearchX } from 'lucide-react';

export function FilterEmptyState({ onReset }: { onReset: () => void }) {
  return (
    <EmptyState
      icon={<SearchX />}
      title="No matching invoices found"
      description="No records match your active date range and vendor filters. Try clearing filters to see all invoices."
      actions={
        <Button variant="outline" onClick={onReset}>
          Reset active filters
        </Button>
      }
    />
  );
}
```

### Permission or access restriction

When an operator lacks role-based permissions, clarify the restriction and indicate which department or administrator can grant access:

```tsx
import { Button, EmptyState } from '@innostes/ui';
import { ShieldAlert } from 'lucide-react';

export function RestrictedEmptyState() {
  return (
    <EmptyState
      icon={<ShieldAlert />}
      title="Restricted ledger view"
      description="Your user profile does not have clearance to view executive payroll ledgers. Contact your compliance administrator to request access."
      actions={
        <Button variant="outline" onClick={() => window.location.href = 'mailto:compliance@northwindtraders.in'}>
          Request clearance
        </Button>
      }
    />
  );
}
```

### Data table integration

Pass `EmptyState` directly to `DataTable` via its `emptyState` prop:

```tsx
<DataTable
  aria-label="Purchase requisitions"
  data={[]}
  columns={columns}
  getRowId={(r) => r.id}
  emptyState={
    <EmptyState
      title="No open requisitions"
      description="All procurement requisitions for this quarter have been processed."
    />
  }
/>
```

## Accessibility

`EmptyState` uses accessible heading structure and semantic action layout.

### Heading hierarchy

- `title` renders inside an `<h3>` heading element by default.
- When placed within a top-level page landmark that lacks intermediate headings, you can customise the title element using `classNames.title` or nest an appropriate heading level (`<h2>`) within `title`.

### Focus management and action clarity

- Action buttons inside `actions` receive standard keyboard tab navigation.
- Ensure action button labels clearly communicate destination or consequence (e.g. "Create purchase order" instead of generic "Create").
- Icons are wrapped in an `aria-hidden` container to avoid announcing decorative icon names to screen reader users.
