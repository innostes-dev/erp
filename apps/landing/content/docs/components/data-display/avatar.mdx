## Import

```tsx
import { Avatar, AvatarImage, AvatarFallback, AvatarGroup } from '@innostes/ui';
```

## Usage

```tsx
<Avatar>
  <AvatarImage src={user.photoUrl} alt="" />
  <AvatarFallback>{initials(user.name)}</AvatarFallback>
</Avatar>
```

The fallback shows while the image loads and if it fails. Use `delay` on `AvatarFallback` (ms) to
avoid a flash of initials on fast connections.

## Accessibility

- When the person's name is shown next to the avatar, use `alt=""` so it isn't read twice.
- `AvatarGroup` labels its "+N" counter (e.g. "2 more").
