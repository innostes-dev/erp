## Import

```tsx
import { Kbd } from '@innostes/ui';
```

## Usage

```tsx
<Kbd>⌘</Kbd> <Kbd>K</Kbd>
```

Renders a native `<kbd>`, which screen readers treat as keyboard input.

## API Reference

`Kbd` takes the props of a `<kbd>` element.
