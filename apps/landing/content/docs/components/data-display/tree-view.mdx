## When to use

Use `TreeView` to present deeply nested, hierarchical structures where users navigate between parent categories and child entities:

- Displaying general ledger Chart of Accounts (Assets > Current Assets > Bank Accounts).
- Navigating organizational structures (Departments > Divisions > Regional Teams).
- Browsing product catalogue taxonomy (Electronics > Industrial Automation > Sensors).
- Exploring multi-level warehouse bin and racking locations.

When choosing hierarchical components:
- Use `TreeView` when the hierarchy contains multiple levels and operators need to expand and collapse branches selectively.
- Use [Breadcrumb](/ui/docs/components/navigation/breadcrumb) to show an operator their current position within a linear ancestral hierarchy.
- Use [Accordion](/ui/docs/components/navigation/accordion) when presenting stacked sections of content that expand to reveal detailed panels.

## Examples

### Basic hierarchy

Construct a tree by passing an array of `TreeNode` objects to `items`. Any node with a `children` property is treated as a branch node and displays a collapsible chevron toggle.

```tsx
'use client';

import { useState } from 'react';
import { TreeView, type TreeNode } from '@innostes/ui';

const accounts: TreeNode[] = [
  {
    id: 'assets',
    label: 'Current assets',
    children: [
      { id: 'bank-hdfc', label: 'HDFC Operating Account' },
      { id: 'bank-sbi', label: 'SBI Forex Treasury' },
    ],
  },
  {
    id: 'liabilities',
    label: 'Current liabilities',
    children: [
      { id: 'ap-domestic', label: 'Domestic Trade Payables' },
      { id: 'tax-gst', label: 'GST Output Liability' },
    ],
  },
];

export function ChartOfAccounts() {
  const [selected, setSelected] = useState<string | null>('bank-hdfc');

  return (
    <TreeView
      aria-label="Chart of accounts"
      items={accounts}
      defaultExpanded={['assets']}
      selected={selected}
      onSelectedChange={setSelected}
    />
  );
}
```

### Asynchronous node loading

To load child nodes on demand (e.g. from a backend API when a warehouse zone is clicked), set `loading={true}` on the parent node while the network request is in flight. A spinner automatically displays in place of the chevron toggle.

```tsx
'use client';

import { useState } from 'react';
import { TreeView, type TreeNode } from '@innostes/ui';

export function LazyWarehouseTree() {
  const [items, setItems] = useState<TreeNode[]>([
    { id: 'blr', label: 'Bengaluru Logistics Center', children: [] },
  ]);

  const handleExpandedChange = async (expandedIds: string[]) => {
    if (expandedIds.includes('blr')) {
      // Mark node as loading
      setItems((prev) =>
        prev.map((n) => (n.id === 'blr' ? { ...n, loading: true } : n))
      );

      // Simulate remote fetch
      const bins = await fetch('/api/v1/warehouses/blr/bins').then((r) => r.json());

      setItems((prev) =>
        prev.map((n) =>
          n.id === 'blr' ? { ...n, loading: false, children: bins } : n
        )
      );
    }
  };

  return (
    <TreeView
      aria-label="Warehouse storage tree"
      items={items}
      onExpandedChange={handleExpandedChange}
    />
  );
}
```

### Icons and metadata badges

Enhance nodes by providing leading `icon` elements and trailing `meta` content (such as item counts or currency totals):

```tsx
import { Badge, TreeView, type TreeNode } from '@innostes/ui';
import { Folder, FolderTree } from 'lucide-react';

const catalog: TreeNode[] = [
  {
    id: 'packaging',
    label: 'Packaging materials',
    icon: <FolderTree className="size-4" />,
    meta: <Badge size="sm" variant="secondary">48 SKUs</Badge>,
    children: [
      {
        id: 'corrugated',
        label: 'Corrugated boxes',
        icon: <Folder className="size-4" />,
        meta: <span className="font-mono text-xs text-muted-foreground">₹1,42,000</span>,
      },
    ],
  },
];

export function CatalogTree() {
  return <TreeView aria-label="Inventory catalog" items={catalog} />;
}
```

### Compact sizing

Set `size="sm"` to reduce row height (from 36px to 28px) and font size, making the tree suitable for narrow sidebars and dense file tree palettes.

```tsx
import { TreeView } from '@innostes/ui';

export function DenseTree() {
  return (
    <TreeView
      aria-label="Compact project tree"
      items={accounts}
      size="sm"
    />
  );
}
```

## Accessibility

`TreeView` strictly adheres to the W3C WAI-ARIA Treeview Design Pattern.

### Screen readers and tree semantics

- The root element uses `role="tree"` with `aria-label` defining the tree's purpose.
- Each branch node has `role="treeitem"`, carrying `aria-expanded="true"` or `aria-expanded="false"`, along with `aria-level` denoting depth in the hierarchy.
- The tree represents a single tab stop with roving tabindex across nodes.
- When `loading={true}`, the node announces the `loadingLabel` ("Loading…" by default) to assistive technologies.
