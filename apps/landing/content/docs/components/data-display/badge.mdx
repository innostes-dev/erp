## Import

```tsx
import { Badge, badgeVariants } from '@innostes/ui';
```

## Usage

Map your domain statuses to a variant once, and reuse it:

```tsx
const statusVariant = {
  paid: 'success',
  pending: 'warning',
  overdue: 'destructive',
  draft: 'info',
} as const satisfies Record<InvoiceStatus, BadgeVariant>;

<Badge variant={statusVariant[invoice.status]} dot>{invoice.status}</Badge>
```

Don't rely on colour alone: the text says what the status is.
