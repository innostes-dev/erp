## Import

```tsx
import { IconTile, type IconTileProps, type IconTileTone } from '@innostes/ui';
```

## When to use

Use `IconTile` to highlight an icon with a tinted or solid background container in dashboard summaries, module navigation lists, or feature cards:

- Categorizing ERP modules (Procurement, Inventory, Ledgers, Logistics) with dedicated palette colors.
- Visually anchoring metric tiles ([MetricCard](/ui/docs/widgets/metric-card) and [Stat](/ui/docs/components/data-display/stat)).
- Reinforcing empty state or workflow step headers with prominent iconography.

When choosing icon components:
- Use `IconTile` when an icon needs a dedicated square or circular background surface to aid visual scanning.
- Use raw SVG icons (from `lucide-react`) directly when rendering inline icon buttons or standard form input adornments.
- Use [Avatar](/ui/docs/components/data-display/avatar) when representing people, team members, or company logos.

## Examples

### Semantic and categorical tones

`IconTile` provides both semantic roles (`primary`, `success`, `warning`, `destructive`, `info`, `neutral`) and eight categorical chart tones (`chart-1` through `chart-8`). Categorical tones match design system charts, allowing dashboards to share uniform color coding across charts and tiles.

```tsx
import { IconTile } from '@innostes/ui';
import { Truck, ShieldCheck, AlertTriangle } from 'lucide-react';

export function SemanticTiles() {
  return (
    <div className="flex gap-3">
      <IconTile tone="primary"><Truck /></IconTile>
      <IconTile tone="success"><ShieldCheck /></IconTile>
      <IconTile tone="warning"><AlertTriangle /></IconTile>
    </div>
  );
}
```

### Soft and solid variants

Choose between `variant="soft"` (default, tinted background with colored foreground icon) for subtle dashboard lists, and `variant="solid"` (bold, opaque fill) for primary callouts:

```tsx
import { IconTile } from '@innostes/ui';
import { Package, Warehouse } from 'lucide-react';

export function TileVariants() {
  return (
    <div className="flex gap-4">
      <IconTile tone="chart-1" variant="soft"><Package /></IconTile>
      <IconTile tone="chart-1" variant="solid"><Warehouse /></IconTile>
    </div>
  );
}
```

### Sizes and shapes

`IconTile` supports four sizes: `sm` (32px), `md` (40px, default), `lg` (48px), and `xl` (56px). Set `shape="circle"` to render circular badges:

```tsx
import { IconTile } from '@innostes/ui';
import { Check, Shield } from 'lucide-react';

export function ShapeSizes() {
  return (
    <div className="flex items-center gap-3">
      <IconTile size="sm" shape="circle" tone="success" variant="solid">
        <Check />
      </IconTile>
      <IconTile size="lg" shape="square" tone="info">
        <Shield />
      </IconTile>
    </div>
  );
}
```

### Bordered tiles on tinted surfaces

When placing an icon tile on a tinted or card surface, add `bordered={true}` to introduce an inset ring token that maintains crisp silhouette definition:

```tsx
import { IconTile } from '@innostes/ui';
import { Bell } from 'lucide-react';

export function BorderedTile() {
  return (
    <div className="rounded-lg bg-muted/40 p-4">
      <IconTile tone="destructive" bordered>
        <Bell />
      </IconTile>
    </div>
  );
}
```

## Accessibility

`IconTile` is strictly a presentation component.

### Decorative icons and aria-hidden

- Embedded icons render with `aria-hidden="true"` by default.
- `IconTile` itself is decorative. Never use an isolated `IconTile` without adjacent descriptive text (such as a card title or list label) or an explicit `aria-label` when wrapped inside an interactive container.

### Color contrast

All `soft` and `solid` variants meet WCAG 2.2 AA non-text contrast requirements (> 3:1 for graphical objects and boundaries) across light and dark display modes.
