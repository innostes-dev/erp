## Import

```tsx
import { IconTile, type IconTileTone } from '@innostes/ui';
```

## Usage

```tsx
<IconTile tone="chart-2"><UsersIcon /></IconTile>
<IconTile tone="success" variant="solid" shape="circle" size="sm"><CheckIcon /></IconTile>
```

- **Semantic tones** (`primary`, `success`, `warning`, `destructive`, `info`, `neutral`) carry meaning.
- **Categorical tones** (`chart-1` … `chart-8`) tell items apart, e.g. one colour per module.
  They're the same colours the charts use, so a module looks the same everywhere.
- The tile is decorative (`aria-hidden`); put the meaning in the text next to it.
