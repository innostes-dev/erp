## Best practices

- **Data tables**: Prefer `DataTable` for complex administrative tables requiring client-side pagination, sorting, row selection, and column toggling.
- **Empty states**: Always render an explicit `EmptyState` when collections, search queries, or filter combinations produce zero results.
- **Status indicators**: Use semantic badges (`success`, `warning`, `destructive`) consistently across data rows to reflect item lifecycles.
