The editor lives in a **separate entry point** (`@innostes/ui/editor`) so applications that do not require rich text editing do not bundle Tiptap dependencies.

## Import

```tsx
import {
  RichTextEditor,
  type RichTextEditorProps,
  type RichTextEditorLabels,
  type RichTextTool,
} from '@innostes/ui/editor';
```

## When to use

Use `RichTextEditor` when users need to author formatted prose beyond the limits of a plain text area:

- Adding warehouse delivery instructions, packing specifications, or special handling notes on purchase orders.
- Editing product catalogue marketing descriptions with bolding, lists, and external reference links.
- Authoring internal standard operating procedures (SOPs) or supplier terms and conditions.

When choosing between text inputs:
- Use [Textarea](/ui/docs/components/forms/textarea) for plain, unformatted multiline input (e.g. shipping street address, feedback comments, or remarks).
- Use `RichTextEditor` when users require formatted structure such as bulleted lists, headings, and inline links.

## Examples

### Installation

`RichTextEditor` is built on [Tiptap](https://tiptap.dev) 3. Install its peer dependencies in your application:

```bash
pnpm add @tiptap/react @tiptap/pm @tiptap/core @tiptap/starter-kit @tiptap/extensions
```

### Basic editor

Provide `value` and `onValueChange` for controlled operation. An empty editor normalises to an empty string `""`, making standard form validation checks straightforward.

```tsx
'use client';

import { useState } from 'react';
import { Field, FieldLabel } from '@innostes/ui';
import { RichTextEditor } from '@innostes/ui/editor';

export function PurchaseOrderNotes() {
  const [content, setContent] = useState('');

  return (
    <Field>
      <FieldLabel id="po-notes">Delivery and unloading notes</FieldLabel>
      <RichTextEditor
        aria-labelledby="po-notes"
        placeholder="Specify delivery bay, contact numbers, and unloading hours…"
        value={content}
        onValueChange={setContent}
      />
    </Field>
  );
}
```

### Form validation and error state

Pass `invalid={true}` (or integrate inside `Field` with validation errors) to apply the semantic destructive border and ring tokens, setting `data-invalid` and `aria-invalid`.

```tsx
'use client';

import { useState } from 'react';
import { Field, FieldLabel, FieldError } from '@innostes/ui';
import { RichTextEditor } from '@innostes/ui/editor';

export function ValidatedEditor() {
  const [html, setHtml] = useState('');
  const [hasSubmitted, setHasSubmitted] = useState(false);
  const isInvalid = hasSubmitted && html.trim().length === 0;

  return (
    <Field invalid={isInvalid}>
      <FieldLabel id="scope-label">Work scope description</FieldLabel>
      <RichTextEditor
        aria-labelledby="scope-label"
        value={html}
        onValueChange={setHtml}
        invalid={isInvalid}
      />
      {isInvalid && <FieldError>Work scope description is required.</FieldError>}
    </Field>
  );
}
```

### Custom toolbar configuration

Customise the visible toolbar actions using the `toolbar` prop, or pass `false` to hide the visual toolbar while preserving keyboard and Markdown shortcuts. Use `'|'` to insert visual dividers between action groups.

```tsx
import { RichTextEditor } from '@innostes/ui/editor';

export function MinimalEditor() {
  return (
    <RichTextEditor
      toolbar={['bold', 'italic', '|', 'bulletList', 'orderedList', '|', 'link']}
      placeholder="Type notes or use Markdown shortcuts like **bold** or - list"
      aria-label="Terms summary"
    />
  );
}
```

### Read-only content display

Pass `readOnly={true}` to display saved HTML content safely without the editing chrome or toolbar.

```tsx
import { RichTextEditor } from '@innostes/ui/editor';

const savedHtml = '<p>Goods must be delivered to <strong>Bay 4</strong>.</p>';

export function ReadOnlyNotice() {
  return (
    <div className="rounded-lg border border-border p-3">
      <RichTextEditor
        value={savedHtml}
        readOnly
        aria-label="Saved instructions"
      />
    </div>
  );
}
```

### Tiptap extensions and editor instance

Pass custom extensions through the `extensions` prop, and access the raw Tiptap instance via `onReady` for advanced programmatic manipulation.

```tsx
import { RichTextEditor } from '@innostes/ui/editor';
import CharacterCount from '@tiptap/extension-character-count';
import type { Editor } from '@tiptap/react';

export function ExtendedEditor() {
  const handleReady = (editor: Editor) => {
    // Programmatic access to Tiptap editor API
    console.info('Editor initialized', editor.getHTML());
  };

  return (
    <RichTextEditor
      extensions={[CharacterCount.configure({ limit: 1000 })]}
      onReady={handleReady}
      aria-label="Character counted specification"
    />
  );
}
```

### Screen readers

- Formatting buttons include descriptive `aria-label` attributes and stateful `aria-pressed` values indicating whether the active selection carries that style.
- The link configuration popover traps focus until applied or dismissed with Escape.
- Form validation errors are associated with the editor via `aria-describedby` when wrapped in a `Field`.
