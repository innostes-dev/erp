`InputGroup` merges single-line inputs with leading and trailing addons into a single contiguous bordered track. It is designed for URL prefixes, monetary currency denominations (e.g. `₹` and `INR`), unit indicators (e.g. `kg`, `litres`), and inline copy buttons.

<ComponentPreview name="forms/input-group/basic" />

## Import

```tsx
import {
  InputGroup,
  InputGroupInput,
  InputGroupAddon,
  SearchInput,
  PasswordInput,
} from '@innostes/ui';
```

## When to use

- **Use InputGroup** when an input requires an explicit unit of measurement, protocol prefix (`https://`), currency symbol, or action button directly attached to the input boundary.
- **Use Input** for plain text fields that do not require affixed addons.
- **Use NumberField** when capturing numbers that require stepper up/down buttons and automatic locale formatting.

## Examples

### Currency and unit addons

Add static currency glyphs and unit labels:

```tsx
<Field>
  <FieldLabel>Procurement unit price</FieldLabel>
  <InputGroup>
    <InputGroupAddon>₹</InputGroupAddon>
    <InputGroupInput inputMode="decimal" placeholder="0.00" />
    <InputGroupAddon>INR</InputGroupAddon>
  </InputGroup>
</Field>
```

### URL protocol prefix

Affix domain and protocol prefixes:

```tsx
<Field>
  <FieldLabel>Tenant portal address</FieldLabel>
  <InputGroup>
    <InputGroupAddon>https://</InputGroupAddon>
    <InputGroupInput placeholder="northwind" />
    <InputGroupAddon>.innostes.com</InputGroupAddon>
  </InputGroup>
</Field>
```

### Icon addon with inline action button

Combine an icon prefix with a trailing copy trigger button:

```tsx
<Field>
  <FieldLabel>ERP webhook key</FieldLabel>
  <InputGroup>
    <InputGroupAddon variant="icon">
      <Key className="size-4 text-muted-foreground" />
    </InputGroupAddon>
    <InputGroupInput defaultValue="whsec_908234892019" readOnly font-mono />
    <InputGroupAddon variant="icon" className="pe-1">
      <Button
        size="sm"
        variant="ghost"
        iconOnly
        aria-label="Copy webhook secret"
        onClick={() => navigator.clipboard.writeText('whsec_908234892019')}
      >
        <Copy className="size-3.5" />
      </Button>
    </InputGroupAddon>
  </InputGroup>
</Field>
```

### Screen readers and ARIA

- **Focus containment**: Clicking on a static text or icon addon transfers focus automatically to the nested input element.
- **Semantic grouping**: The container groups visual addons without fragmenting the accessibility tree, preserving standard `aria-describedby` associations from `<Field>`.

## Guidelines

<DoDont>
  <Do>
    Use `InputGroupAddon` for short units (e.g. `₹`, `kg`, `cm`, `https://`) that provide immediate formatting context.
  </Do>
  <Dont>
    Never place lengthy prose or instructional sentences inside an addon slot; use `<FieldDescription>` instead.
  </Dont>
</DoDont>

<DoDont>
  <Do>
    Always supply an explicit `aria-label` when placing an icon-only button inside an addon slot.
  </Do>
  <Dont>
    Never attach multiple overlapping action buttons to a single input track; limit addons to one clear secondary trigger.
  </Dont>
</DoDont>
