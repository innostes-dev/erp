`Slider` allows users to select a single numerical value or a bounded numerical range by dragging thumbs along a horizontal track or adjusting values via keyboard arrows. Built on Base UI's slider primitive, it supports dual-thumb range filtering, custom stepping, and automatic accessibility announcements.

<ComponentPreview name="forms/slider/basic" />

## Import

```tsx
import { Slider } from '@innostes/ui';
```

## When to use

- **Use Slider** for selecting approximate numeric values along a continuous range (e.g. percentage volumes, price range filters, inspection sample thresholds).
- **Use NumberField** when exact numerical precision is required (e.g. entering invoice currency totals or unit quantities).
- **Use Progress or Meter** when displaying a read-only visual measurement without user dragging interaction.

## Examples

### Single value slider

Select a discrete numeric value along a defined boundary:

```tsx
<Field>
  <FieldLabel>Warehouse humidity threshold (%)</FieldLabel>
  <Slider defaultValue={45} min={20} max={80} step={5} aria-label="Humidity threshold" />
</Field>
```

### Dual-thumb range selection

Pass an array of two numbers (`[min, max]`) to enable dual-thumb range mode:

```tsx
const [priceRange, setPriceRange] = useState<number[]>([2500, 8000]);

<div className="space-y-2">
  <div className="flex justify-between text-sm font-medium">
    <span>Procurement budget</span>
    <span className="font-mono text-muted-foreground">₹{priceRange[0]} – ₹{priceRange[1]}</span>
  </div>
  <Slider
    value={priceRange}
    onValueChange={(val) => setPriceRange(val as number[])}
    min={1000}
    max={15000}
    step={250}
    thumbLabels={['Minimum budget rate', 'Maximum budget rate']}
  />
</div>
```

### Screen readers and ARIA

- **`role="slider"`**: Emitted on each thumb element.
- **ARIA synchronization**: Exposes `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`.
- **`thumbLabels` requirement**: In dual-thumb range mode, `thumbLabels` **must** be provided so screen readers announce which thumb is being adjusted (e.g. `thumbLabels={['Minimum rate', 'Maximum rate']}`).

## Guidelines

<DoDont>
  <Do>
    Always display the currently selected value numerically beside the slider when exact figures matter to the operator.
  </Do>
  <Dont>
    Never use `Slider` without a visible numerical readout when users need to select precise monetary amounts.
  </Dont>
</DoDont>

<DoDont>
  <Do>
    Provide descriptive `thumbLabels` for dual-thumb range sliders.
  </Do>
  <Dont>
    Never allow the minimum thumb to cross past the maximum thumb; `@innostes/ui` automatically clamps thumbs to prevent inversion.
  </Dont>
</DoDont>
