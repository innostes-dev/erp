`Textarea` provides multiline text input for customer remarks, delivery instructions, procurement notes, and descriptions. Built on standard HTML5 textarea ergonomics, it supports automatic vertical resizing via CSS `field-sizing: content` while integrating directly with `<Field>` for validation and error reporting.

<ComponentPreview name="forms/textarea/basic" />

## Import

```tsx
import { Textarea } from '@innostes/ui';
```

## When to use

- **Use Textarea** for multiline text entries such as shipping instructions, invoice notes, or bug reports.
- **Use Input** for single-line values such as customer names, email addresses, or phone numbers.
- **Use RichTextEditor** when formatted text (bold, lists, links, headers) or document authoring is required.

## Examples

### Basic usage

Specify the initial visible height using the `rows` prop:

```tsx
<Field>
  <FieldLabel>Dispatch instructions</FieldLabel>
  <Textarea rows={4} placeholder="Gate delivery instructions, bay access codes..." />
  <FieldDescription>Max 500 characters.</FieldDescription>
</Field>
```

### Auto-resize

Enable `autoResize` to allow the textarea to grow vertically as the operator types:

```tsx
<Field>
  <FieldLabel>Internal procurement note</FieldLabel>
  <Textarea
    autoResize
    rows={2}
    placeholder="Describe vendor negotiation terms..."
  />
  <FieldDescription>Grows smoothly with content using CSS field-sizing.</FieldDescription>
</Field>
```

Browsers without native `field-sizing: content` support gracefully fall back to standard vertical drag-resizing.

### Validation state

When used inside `<Field>`, validation errors trigger error rings and ARIA live announcements:

```tsx
<Field name="justification" required>
  <FieldLabel required>Order cancellation reason</FieldLabel>
  <Textarea required minLength={10} />
  <FieldError match="valueMissing">Please state a reason for cancelling this order.</FieldError>
  <FieldError match="tooShort">Please provide at least 10 characters of explanation.</FieldError>
</Field>
```

### Screen readers and ARIA

- **Automatic labelling**: When wrapped inside `<Field>`, the `<FieldLabel>` is programmatically coupled via `htmlFor`/`id`.
- **Validation binding**: Error and helper descriptions connect via `aria-describedby` and set `aria-invalid="true"` when invalid.

## Guidelines

<DoDont>
  <Do>
    Provide an initial `rows` value (typically 3 to 5) that accommodates expected content without overwhelming the screen.
  </Do>
  <Dont>
    Never use a `Textarea` for single-line values like titles, email addresses, or tax numbers; use `Input` instead.
  </Dont>
</DoDont>

<DoDont>
  <Do>
    Use `autoResize` for compact comment forms to keep the initial footprint minimal.
  </Do>
  <Dont>
    Never hide the scrollbar or restrict manual resizing when `autoResize` is disabled.
  </Dont>
</DoDont>
