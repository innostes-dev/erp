## Import

```tsx
import { Textarea } from '@innostes/ui';
```

## Usage

```tsx
<Textarea name="notes" rows={4} />
<Textarea autoResize rows={2} />  {/* grows with the content */}
```

`autoResize` uses CSS `field-sizing: content`. Browsers without support fall back to a normal,
vertically resizable textarea.
