`NumberField` provides a precision numerical input control. Built on Base UI's number field primitive, it manages numeric stepping, bounds clamping (`min`, `max`), keyboard increment shortcuts, and automatic `Intl.NumberFormat` localization for Indian Rupees (`INR`), percentages, and quantities.

<ComponentPreview name="forms/number-field/basic" />

## Import

```tsx
import { NumberField } from '@innostes/ui';
```

## When to use

- **Use NumberField** when capturing quantitative figures that benefit from stepping, bounds clamping, or locale-aware currency formatting (e.g. order quantities, prices, discount rates).
- **Use Input** with `type="number"` only for simple unbounded numbers without stepping or formatting needs.
- **Use Slider** when visual spatial selection along a continuous track is preferred over typed numeric input.

## Examples

### Currency formatting in en-IN

`NumberField` formats numbers according to Indian numbering grouping rules (thousands, lakhs, crores) when supplied with `locale="en-IN"`:

```tsx
<Field>
  <FieldLabel>Procurement invoice total</FieldLabel>
  <NumberField
    defaultValue={145280.50}
    step={100}
    locale="en-IN"
    format={{ style: 'currency', currency: 'INR' }}
  />
  <FieldDescription>Displays as ₹1,45,280.50 with proper Indian digit grouping.</FieldDescription>
</Field>
```

### Percentage calculation

When formatting percentages, supply a decimal fraction (e.g. `0.18` for 18%):

```tsx
<Field>
  <FieldLabel>GST tax slab</FieldLabel>
  <NumberField
    defaultValue={0.18}
    min={0}
    max={0.28}
    step={0.01}
    locale="en-IN"
    format={{ style: 'percent' }}
  />
</Field>
```

### Bounds and step behaviour

Enforce minimum, maximum, and step increments:

```tsx
<NumberField
  defaultValue={10}
  min={1}
  max={100}
  step={5}
  largeStep={25}
  aria-label="Pallet batch quantity"
/>
```

- **`step`**: Determines the increment for Up/Down arrow keys and stepper buttons (defaults to `1`).
- **`largeStep`**: Determines the increment for `PageUp` and `PageDown` keys (defaults to `10`).
- **Clamping**: Typing a number outside `[min, max]` automatically clamps to the boundary when the field loses focus.

### Screen readers and ARIA

- **`role="spinbutton"`**: Identifies the control as an accessible numeric spinner.
- **ARIA attributes**: Automatically exposes `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, and `aria-valuetext` (reflecting localized formatted currency or percentages).

## Guidelines

<DoDont>
  <Do>
    Specify `locale="en-IN"` and `currency="INR"` for Indian enterprise ERP applications to guarantee correct rupee symbols and lakh/crore commas.
  </Do>
  <Dont>
    Never hardcode currency symbols into input value strings manually; let `NumberField`'s `format` prop handle internationalisation.
  </Dont>
</DoDont>

<DoDont>
  <Do>
    Set sensible `min` bounds (such as `min={0}` or `min={1}`) to prevent invalid negative quantities on purchase orders.
  </Do>
  <Dont>
    Never leave numeric bounds open when negative values would break downstream accounting workflows.
  </Dont>
</DoDont>
