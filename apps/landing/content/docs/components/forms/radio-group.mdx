## Import

```tsx
import { Radio, RadioGroup } from '@innostes/ui';
```

## Usage

```tsx
<RadioGroup name="plan" defaultValue="business" aria-label="Plan">
  <label className="flex items-center gap-2"><Radio value="starter" /> Starter</label>
  <label className="flex items-center gap-2"><Radio value="business" /> Business</label>
</RadioGroup>
```

Use radios for 2–6 visible options. For longer lists, use [Select](/ui/docs/components/forms/select).
Style a selected option's wrapper with `has-data-checked:` (as in the demo).

## Accessibility

- Arrow keys move and select; Tab enters and leaves the group.
- Label the group (`aria-label`, or `aria-labelledby` pointing at a heading).
