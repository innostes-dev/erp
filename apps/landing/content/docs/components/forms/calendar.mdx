## Import

```tsx
import { Calendar, type DateRange, type Weekday } from '@innostes/ui';
```

## When to use

Use `Calendar` when users need to see an inline month view to choose a single calendar day or an inclusive date range:

- Displaying booking schedules, dispatch timetables, or delivery cutoffs directly on an ERP dashboard.
- Selecting ranges across one or two months when visualising calendar context is essential.
- Building custom date filter panels.

When choosing between date selection patterns:
- Use [Date Picker](/ui/docs/components/forms/date-picker) if the calendar should appear within a compact popover triggered from a form field or table toolbar.
- Use [Date Range Picker](/ui/docs/components/forms/date-picker#date-range-picker-with-presets) if you need preset ranges (such as "Last 30 days" or "This quarter") attached to a popover trigger.
- Use [Input](/ui/docs/components/forms/input) with `type="date"` only when native mobile OS date pickers are explicitly preferred over consistent cross-browser styling.

## Examples

### Single date

By default, `Calendar` runs in single-date mode (`mode="single"`). Provide `value` and `onValueChange` for controlled operation.

```tsx
'use client';

import { useState } from 'react';
import { Calendar } from '@innostes/ui';

export function DispatchDateSelector() {
  const [dispatchDate, setDispatchDate] = useState<Date | null>(new Date());

  return (
    <Calendar
      value={dispatchDate}
      onValueChange={setDispatchDate}
      aria-label="Dispatch schedule"
    />
  );
}
```

### Date range

Set `mode="range"` to allow selecting a start date and an end date. Setting `numberOfMonths={2}` renders two consecutive months side-by-side, which simplifies picking cross-month accounting or reporting cycles.

```tsx
'use client';

import { useState } from 'react';
import { Calendar, type DateRange } from '@innostes/ui';

export function AuditRangeCalendar() {
  const [range, setRange] = useState<DateRange>({
    from: new Date(2026, 3, 1),
    to: new Date(2026, 3, 15),
  });

  return (
    <Calendar
      mode="range"
      numberOfMonths={2}
      value={range}
      onValueChange={setRange}
      aria-label="Audit observation period"
    />
  );
}
```

### Date constraints and disabled dates

Pass `min` and `max` bounds to prevent selecting dates outside allowable fiscal limits. Use `isDateDisabled` to disable specific calendar dates, such as gazetted public holidays or weekend warehouse closures.

```tsx
import { Calendar } from '@innostes/ui';

const isWeekend = (date: Date) => date.getDay() === 0 || date.getDay() === 6;

export function WarehouseCutoffCalendar() {
  return (
    <Calendar
      min={new Date(2026, 0, 1)}
      max={new Date(2026, 11, 31)}
      isDateDisabled={isWeekend}
      aria-label="Warehouse loading date"
    />
  );
}
```

### Dropdown year and month navigation

For dates far in the past or future (such as incorporation dates or employee date of birth), set `captionLayout="dropdown"`. This substitutes plain month header text with accessible select dropdowns for rapid jumping.

```tsx
import { Calendar } from '@innostes/ui';

export function IncorporationCalendar() {
  return (
    <Calendar
      captionLayout="dropdown"
      fromYear={1990}
      toYear={2030}
      aria-label="Entity incorporation date"
    />
  );
}
```

### Locale and week start

Month and weekday labels automatically derive from the user's browser runtime through `Intl.DateTimeFormat`. You can pass an explicit BCP 47 locale tag (`locale="en-IN"`) or override the first day of the week with `weekStartsOn` (where `0` is Sunday and `1` is Monday).

```tsx
import { Calendar } from '@innostes/ui';

export function IndianFiscalCalendar() {
  return (
    <Calendar
      locale="en-IN"
      weekStartsOn={1}
      aria-label="GST filing schedule"
    />
  );
}
```

### Time zones

`Calendar` operates strictly on **local calendar days**:
- Values are native JavaScript `Date` instances clamped to midnight in the local browser runtime.
- The component does not apply UTC hour offsets or time zone translations.
- When sending values to an ERP API, serialise the calendar day to an ISO date string format (`YYYY-MM-DD`) at the application boundary, rather than sending a raw UTC timestamp that could shift the calendar day across midnight in eastern or western longitudes.

## Accessibility

`Calendar` implements the W3C WAI-ARIA Date Picker Grid design pattern.

### Keyboard navigation

The calendar grid is a single tab stop with roving tabindex across days.

### Screen readers

- The month table uses `role="grid"` with column headers denoting abbreviated and full weekday names (`abbr` attribute).
- Each cell has a full textual accessible label (e.g., "Thursday, 15 October 2026").
- The current calendar date is marked with `aria-current="date"`.
- Selected dates communicate their status through `aria-selected="true"`.
- Disabled days maintain keyboard focusability to allow navigating across weeks without breaking roving focus, marked with `aria-disabled="true"`.
