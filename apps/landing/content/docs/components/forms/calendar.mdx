## Import

```tsx
import { Calendar, type DateRange } from '@innostes/ui';
```

## Usage

```tsx
<Calendar value={date} onValueChange={setDate} />
<Calendar mode="range" numberOfMonths={2} value={range} onValueChange={setRange} />
<Calendar isDateDisabled={(d) => d.getDay() === 0 || d.getDay() === 6} min={new Date()} />
<Calendar captionLayout="dropdown" fromYear={1950} toYear={2010} />   {/* month & year selects */}
```

For a field that opens a calendar, use [Date Picker](/ui/docs/components/forms/date-picker).

## Locale

Month and weekday names come from `Intl` in the user's language. The first day of the week follows
the locale (Monday for most of the world, Sunday for `en-US`); override it with `weekStartsOn`.
Labels of the navigation buttons can be translated with `labels`.

## Dates and time zones

The calendar works with **local calendar days**: values are `Date` objects at local midnight.
Convert to and from your API's format at the edges, e.g. with `toISOString().slice(0, 10)` or the
`YYYY-MM-DD` value the date pickers submit.

## Keyboard

| Key | Action |
| --- | --- |
| Arrow keys | Previous / next day and week |
| Home / End | Start / end of the week |
| Page Up / Page Down | Previous / next month |
| Shift + Page Up / Page Down | Previous / next year |
| Enter / Space | Select the focused day |

## Accessibility

- Follows the WAI-ARIA date picker grid pattern: one tab stop, roving focus, `aria-selected`,
  `aria-current="date"` for today, and full dates as labels ("Thursday, October 15, 2026").
- Disabled days stay focusable (so keyboard users can move past them) and are marked `aria-disabled`.
