## Import

```tsx
import {
  DatePicker,
  DateRangePicker,
  defaultDateRangePresets,
  type DateRange,
  type DateRangePreset,
} from '@innostes/ui';
```

## When to use

Use `DatePicker` or `DateRangePicker` when users need to select dates within forms, query bars, or filter headers without taking up permanent layout space:

- Setting invoice due dates, quotation validity periods, or purchase order delivery dates.
- Selecting custom reporting intervals or quick presets (such as "Last 30 days" or "This month") in financial analytics.
- Capturing personal dates like date of birth using year/month dropdown navigation.

When choosing between date components:
- Use [Calendar](/ui/docs/components/forms/calendar) directly when you want the month grid permanently visible inline on the page (such as a resource booking calendar or dispatch dashboard).
- Use `DatePicker` for selecting an isolated point in time (e.g. `dueDate`).
- Use `DateRangePicker` when querying date spans bounded by start and end dates.
- Use [Input](/ui/docs/components/forms/input) with `type="date"` if minimal JavaScript bundle size on legacy mobile browsers takes precedence over styling consistency.

## Examples

### Basic date picker

Render `DatePicker` with an accessible label or `aria-label`. Use `value` and `onValueChange` for controlled state.

```tsx
'use client';

import { useState } from 'react';
import { DatePicker, Label } from '@innostes/ui';

export function InvoiceDueDate() {
  const [dueDate, setDueDate] = useState<Date | null>(new Date());

  return (
    <div className="flex flex-col gap-2">
      <Label htmlFor="invoice-due">Payment due date</Label>
      <DatePicker
        id="invoice-due"
        name="dueDate"
        value={dueDate}
        onValueChange={setDueDate}
      />
    </div>
  );
}
```

### Date formatting and locale

The trigger formats dates using `Intl.DateTimeFormat` with `dateStyle: 'medium'` by default. You can supply custom `Intl.DateTimeFormatOptions` or a custom formatting function via the `format` prop. Pass `locale` to ensure month and day names correspond to the user's regional dialect.

```tsx
import { DatePicker } from '@innostes/ui';

export function FormattedDatePicker() {
  return (
    <DatePicker
      locale="en-IN"
      format={{ day: '2-digit', month: 'short', year: 'numeric' }}
      aria-label="Voucher date"
    />
  );
}
```

### Date constraints and disabled days

Bound selectable dates using `min` and `max`. Use `isDateDisabled` to disable specific dates such as regional holidays or non-working days.

```tsx
import { DatePicker } from '@innostes/ui';

const isSunday = (date: Date) => date.getDay() === 0;

export function DeliverySlotPicker() {
  return (
    <DatePicker
      min={new Date()}
      isDateDisabled={isSunday}
      placeholder="Select working day"
      aria-label="Delivery slot"
    />
  );
}
```

### Month and year dropdown navigation

Set `captionLayout="dropdown"` to display dropdown selectors for year and month inside the popover calendar. This is ideal for historical dates such as employee date of birth or company incorporation.

```tsx
import { DatePicker } from '@innostes/ui';

export function DateOfBirthPicker() {
  return (
    <DatePicker
      captionLayout="dropdown"
      fromYear={1950}
      toYear={2010}
      placeholder="Select date of birth"
      aria-label="Date of birth"
    />
  );
}
```

### Date range picker with presets

`DateRangePicker` renders a popover with dual-month navigation alongside quick preset selections (e.g., "Today", "Last 7 days", "Last 30 days", "This month"). The `onValueChange` callback triggers when both `from` and `to` dates are chosen, or immediately when a preset button is clicked.

```tsx
'use client';

import { useState } from 'react';
import { DateRangePicker, type DateRange } from '@innostes/ui';

export function TaxPeriodFilter() {
  const [period, setPeriod] = useState<DateRange>({
    from: new Date(2026, 3, 1),
    to: new Date(2026, 3, 30),
  });

  return (
    <DateRangePicker
      value={period}
      onValueChange={setPeriod}
      startName="startDate"
      endName="endDate"
      aria-label="GST tax period"
    />
  );
}
```

You can define custom presets or pass an empty array (`presets={[]}`) to remove the preset column:

```tsx
import { DateRangePicker, defaultDateRangePresets } from '@innostes/ui';

const fiscalPresets = [
  {
    label: 'Q1 (Apr–Jun)',
    range: () => ({ from: new Date(2026, 3, 1), to: new Date(2026, 5, 30) }),
  },
  ...defaultDateRangePresets,
];

export function CustomPresetsDemo() {
  return <DateRangePicker presets={fiscalPresets} aria-label="Fiscal period" />;
}
```

### Form integration and submission

`DatePicker` renders a hidden `<input type="hidden">` with the chosen date formatted as `YYYY-MM-DD` under the given `name` prop. `DateRangePicker` accepts `startName` and `endName` to submit both dates in standard HTML forms and server actions.

```tsx
import { DatePicker, Field, FieldLabel, FieldError } from '@innostes/ui';

export function FormDatePickerExample() {
  return (
    <form action="/api/v1/invoices" method="POST">
      <Field>
        <FieldLabel htmlFor="due-date">Invoice due date</FieldLabel>
        <DatePicker id="due-date" name="dueDate" required />
        <FieldError />
      </Field>
    </form>
  );
}
```

## Accessibility

`DatePicker` and `DateRangePicker` follow WAI-ARIA combobox and popover dialog specifications.

### Screen readers

- The trigger element is an accessible button rendered with `aria-haspopup="dialog"`.
- When opened, focus moves into the calendar grid, which announces the currently focused day with day of week, day number, month, and year.
- Selected dates are announced with `aria-selected="true"`.
- The clear button includes a localized `aria-label` ("Clear date" by default).
