## Import

```tsx
import { Switch } from '@innostes/ui';
```

## Usage

```tsx
<label className="flex items-center gap-3">
  <Switch name="notifications" defaultChecked /> Email notifications
</label>
```

Use a switch when the change takes effect right away. When the user must press Save, a
[Checkbox](/ui/docs/components/forms/checkbox) is clearer.

## Accessibility

- Announced as `role="switch"` with `aria-checked`. Space toggles it.
