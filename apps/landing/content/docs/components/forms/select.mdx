`Select` displays a collapsed trigger button that opens a floating menu of options. Built on Base UI's select primitive, it supports type-ahead search, roving keyboard focus, group dividers, and multi-selection, while integrating directly into `<Field>` for validation.

<ComponentPreview name="forms/select/basic" />

## Import

```tsx
import {
  Select,
  SelectTrigger,
  SelectValue,
  SelectContent,
  SelectItem,
  SelectGroup,
  SelectGroupLabel,
  SelectSeparator,
} from '@innostes/ui';
```

## When to use

- **Use Select** when users need to choose from a predefined list of 5 to 15 items in a compact form layout.
- **Use RadioGroup** when choices are few (2 to 5) and comparing options side-by-side without opening a menu is beneficial.
- **Use SearchableSelect or Combobox** when the list contains more than 15 items or requires fast keyboard typing search.

### Selection control comparison

| Control | Selection count | Number of options | Search filter | Best suited for |
| :--- | :--- | :--- | :--- | :--- |
| **Select** | Single or Multi | 5 to 15 | No (type-ahead only) | Compact predefined lists (e.g. status, tax rate, payment terms) |
| **[RadioGroup](/ui/docs/components/forms/radio-group)** | Single | 2 to 5 | No | Visible choices where side-by-side comparison is essential |
| **[SearchableSelect](/ui/docs/components/forms/searchable-select)** | Single | 15 to 100+ | Yes | Long lists requiring keyboard search filtering (e.g. warehouse depot) |
| **[Combobox](/ui/docs/components/forms/combobox)** | Single or Multi | 50 to 10,000+ | Yes | Large async remote datasets or autocomplete with custom item creation |
| **[TagInput](/ui/docs/components/forms/tag-input)** | Multi | Variable | Yes | Categorical metadata, SKU keywords, and multi-tag filtering |

### Grouped options with separators

Organize related choices using `SelectGroup` and `SelectSeparator`:

```tsx
<Select defaultValue="blr-central">
  <SelectTrigger aria-label="Depot">
    <SelectValue placeholder="Select warehouse depot..." />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectGroupLabel>Karnataka Facilities</SelectGroupLabel>
      <SelectItem value="blr-central">Bengaluru Central Hub</SelectItem>
      <SelectItem value="whitefield">Whitefield Logistics Center</SelectItem>
    </SelectGroup>
    <SelectSeparator />
    <SelectGroup>
      <SelectGroupLabel>Maharashtra Facilities</SelectGroupLabel>
      <SelectItem value="mumbai-port">Mumbai JNPT Port Depot</SelectItem>
      <SelectItem value="pune-chakan">Pune Chakan Industrial Hub</SelectItem>
    </SelectGroup>
  </SelectContent>
</Select>
```

### Multiple selection

Set `multiple` on the root `Select` component to allow choosing multiple items:

```tsx
const [selectedCurrencies, setSelectedCurrencies] = useState(['INR', 'USD']);

<Select multiple value={selectedCurrencies} onValueChange={setSelectedCurrencies}>
  <SelectTrigger aria-label="Settlement currencies">
    <SelectValue placeholder="Select currencies..." />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="INR">Indian Rupee (INR)</SelectItem>
    <SelectItem value="USD">US Dollar (USD)</SelectItem>
    <SelectItem value="EUR">Euro (EUR)</SelectItem>
    <SelectItem value="GBP">British Pound (GBP)</SelectItem>
  </SelectContent>
</Select>
```

### Screen readers and ARIA

- **`role="combobox"`**: Emitted on `<SelectTrigger>` alongside `aria-expanded` and `aria-haspopup="listbox"`.
- **`role="listbox"` & `role="option"`**: Assigned to the content popup and individual items.
- **Active descendant**: Communicates the currently focused option to screen readers using standard ARIA patterns.

## Guidelines

<DoDont>
  <Do>
    Use `Select` for bounded, predictable lists where users already know what options to expect.
  </Do>
  <Dont>
    Never use `Select` for massive datasets (e.g. 500+ postal codes); use `Combobox` or `SearchableSelect` instead.
  </Dont>
</DoDont>

<DoDont>
  <Do>
    Provide an informative placeholder on `<SelectValue placeholder="Select supplier..." />`.
  </Do>
  <Dont>
    Never leave the trigger blank when no default value is selected.
  </Dont>
</DoDont>
