innostes UI is the component library behind every innostes product. It gives you everything an admin
panel needs (forms, tables, dialogs, navigation and an app shell), with one consistent API and
your own theme.

<ComponentPreview name="examples/dashboard" align="start" className="p-0 sm:p-0" />

## Why innostes UI

<Cards>
  <Card icon={<Accessibility />} title="Accessible by default" href="/ui/docs/resources/conventions#accessibility">
    Built on Base UI: keyboard support, focus management and ARIA follow WAI-ARIA, and every
    component is tested for it.
  </Card>
  <Card icon={<Palette />} title="Your theme, everywhere" href="/ui/docs/theming">
    Semantic design tokens with Tailwind defaults. Change a token once and every component follows,
    including dark mode.
  </Card>
  <Card icon={<Wind />} title="With or without Tailwind" href="/ui/docs/installation">
    Tailwind apps share their theme with the components. Other apps import one stylesheet.
  </Card>
  <Card icon={<Terminal />} title="Made for developers" href="/ui/docs/resources/conventions">
    Typed props with TSDoc, controlled or uncontrolled state, `render` composition, and `className`
    that always wins.
  </Card>
</Cards>
