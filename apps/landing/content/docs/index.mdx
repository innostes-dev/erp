`@innostes/ui` is an enterprise component library engineered specifically for back-office applications, enterprise resource planning (ERP) consoles, and high-density operations dashboards.

Designed to meet the demands of operations teams such as Northwind Traders Pvt Ltd, the library provides keyboard-first interaction models, strict type safety, predictable state composition, and full token-based styling.

## Architectural foundation

`@innostes/ui` combines unstyled accessible primitives with token-driven design:

- **Base UI primitives**: Dropdowns, dialogs, popovers, and form fields rely on Base UI for focus trapping, keyboard navigation, and ARIA state management.
- **Tailwind CSS design tokens**: Every colour, spacing increment, and typography rule maps to semantic CSS custom properties defined in OKLCH colour space.
- **Render prop composition**: Clean component substitution using the `render` prop pattern without invalid DOM nesting or ref-forwarding errors.
- **Zero runtime CSS injection**: Styles compile ahead of time through PostCSS and Tailwind, eliminating hydration mismatches and runtime CSS-in-JS overhead.

## Package entry points

The library is organised into four distinct entry points to keep application bundles minimal:

```
@innostes/ui          -> Core UI primitives, forms, data display, and overlays
@innostes/ui/widgets  -> Administrative cards, kanban boards, and audit feeds
@innostes/ui/charts   -> Data visualisation components (requires Recharts)
@innostes/ui/editor   -> Rich text document editing (requires Tiptap)
```

| Entry point | Typical use cases | Peer dependencies |
| :--- | :--- | :--- |
| `@innostes/ui` | Buttons, tables, modals, form inputs, navigation layouts | React, React DOM, Lucide React |
| `@innostes/ui/widgets` | `MetricCard`, `KanbanBoard`, `PermissionMatrix`, `ChangeLog` | None beyond `@innostes/ui` |
| `@innostes/ui/charts` | `CartesianCharts` (bar, line, area), `DonutChart` | `recharts` (>= 2.12.0) |
| `@innostes/ui/editor` | `RichTextEditor`, formatting toolbars, document authoring | `@tiptap/react`, `@tiptap/pm` |
