# Data management

High-volume operations at Northwind Traders Pvt Ltd involve browsing, filtering, and updating thousands of shipment records and customer accounts. The data management pattern defines how `DataTable`, `Pagination`, search bars, and batch action toolbars collaborate.

## Key considerations

- **Server-driven state**: Sorting, pagination, and multi-field filtering query the backend directly, preserving URL search parameters for link sharing.
- **Batch execution**: Selection toolbars appear upon selecting records, allowing bulk state transitions (e.g. "Approve selected", "Export to CSV").
- **Responsive fallback**: On narrow mobile viewports, tables adapt into card lists or horizontally scrollable containers with pinned identity columns.
