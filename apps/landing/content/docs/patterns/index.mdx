# Patterns

Patterns document established combinations of primitives and widgets that resolve recurrent enterprise challenges at Northwind Traders Pvt Ltd. Rather than prescribing rigid page templates, patterns offer composable blueprints for forms, data tables, and application shells.

## Core patterns

- **Complex forms**: Multi-section data entry, conditional validation with Zod, unsaved changes detection, and accessible error summaries.
- **Data management**: High-density server tables, compound filtering drawers, batch selection workflows, and export pipelines.
- **Application shell**: Responsive dual-tier navigation, persistent command bars, collapsible sidebars, and contextual breadcrumbs.
