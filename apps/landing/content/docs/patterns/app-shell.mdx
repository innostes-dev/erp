# Application shell

The application shell provides the structural frame within which ERP modules operate. Comprising `AppRail`, `Sidebar`, `TopBar`, and `PageHeader`, it maintains continuous context, breadcrumb paths, and user account actions.

## Structure

1. **Primary rail**: High-level module switching (Procurement, Inventory, Finance, Human Resources).
2. **Context sidebar**: Deep navigational trees, collapsible folders, and saved view bookmarks.
3. **Top bar**: Global command palette trigger, notification bell, and user profile switcher.
4. **Canvas**: Main content region with dynamic page headers and breadcrumbs.
